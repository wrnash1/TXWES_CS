# Online Course Map: CIS-3322_Advanced_Networking
**Target Certification:** Cisco CCNA (200-301)

## 16-Week Breakdown

### Weeks 1–4: Network Foundations and Addressing
*   **Module 01:** Network Architectures & Topologies — Three-tier, collapsed core, spine-leaf; CCNA domain: Network Fundamentals (20%)
*   **Module 02:** Subnetting and VLSM — Binary subnetting, CIDR prefix matching, efficient IP allocation; CCNA domain: Network Fundamentals / IP Connectivity
*   **Module 03:** IPv6 Addressing and Configuration — Global unicast, link-local, SLAAC, EUI-64, static routing; CCNA domain: Network Fundamentals / IP Connectivity
*   **Module 04:** Switching Concepts & VLANs — 802.1Q trunking, VLAN membership, native VLAN, DTP; CCNA domain: Network Access (20%)

### Weeks 5–8: Switching, Routing Protocols, and WAN
*   **Module 05:** Spanning Tree Protocol (STP & RSTP) — Root bridge election, port roles, 802.1D vs 802.1w, PortFast/BPDU Guard; CCNA domain: Network Access
*   **Module 06:** EtherChannel Link Aggregation — LACP vs PAgP, port-channel configuration, load balancing; CCNA domain: Network Access
*   **Module 07:** Inter-VLAN Routing Solutions — Router-on-a-stick, subinterfaces, Layer 3 switch SVIs; CCNA domain: IP Connectivity (25%)
*   **Module 08:** OSPFv2 Routing Concepts & Setup — Neighbor states, LSAs, area boundaries, wildcard masks, DR/BDR election; CCNA domain: IP Connectivity

### Weeks 9–12: WAN, Security, and Services
*   **Module 09:** WAN Technologies & VPNs — Metro Ethernet, GRE tunnels, IPsec (AH vs ESP), site-to-site VPN; CCNA domains: WAN Technologies / Security Fundamentals (15%)
*   **Module 10:** Access Control Lists (ACLs) — Standard vs extended ACLs, wildcard filtering, implicit deny, placement rules; CCNA domain: Security Fundamentals
*   **Module 11:** NAT and PAT Configurations — Static NAT, dynamic NAT, PAT/overload, inside local/global terminology; CCNA domain: IP Services (10%)
*   **Module 12:** Wireless LANs (WLAN) & WLC — Autonomous vs lightweight APs, CAPWAP, WLC configuration, WPA2 vs WPA3; CCNA domain: Network Access

### Weeks 13–15: QoS, Automation, and Exam Readiness
*   **Module 13:** Quality of Service (QoS) Fundamentals — CoS/DSCP marking, FIFO/WFQ/LLQ queuing, WRED congestion avoidance, MQC framework; CCNA domain: IP Services
*   **Module 14:** Network Automation & REST APIs — SDN controller architecture, northbound/southbound APIs, JSON/XML, Ansible/Puppet/Chef; CCNA domain: Automation and Programmability (10%)
*   **Module 15:** CCNA Review and Diagnostics — OSI troubleshooting methodology, interface states, routing loop diagnosis, mismatch symptoms, verification commands

### Week 16: Certification
*   **Module 16:** Final Exam Prep & Cisco CCNA 200-301 Certification — Full domain review, exam strategy, practice simulations, Pearson VUE exam scheduling
