**Question 1**
What wildcard mask corresponds to a standard subnet mask of `255.255.255.252`?
*   A) 0.0.0.3
*   B) 0.0.0.255
*   C) 255.255.255.255
*   D) 0.0.0.7
*   **Correct Answer:** A) Subtracting `255.255.255.252` from `255.255.255.255` yields wildcard `0.0.0.3`.
*   **Distractor Analysis:**
    *   *Why correct:* Subtracting `255.255.255.252` from `255.255.255.255` yields wildcard `0.0.0.3`.
    *   0.0.0.255 is for /24. 0.0.0.7 is for /29.

**Question 2**
Which of the following most accurately describes a **Link-State Advertisement (LSA)** in OSPF?
*   A) A packet generated by each OSPF router to describe its connected links, their costs, and neighbor relationships, which is flooded throughout the area so all routers can build an identical Link-State Database.
*   B) A hello packet sent every 10 seconds on broadcast networks to discover neighbors and maintain adjacency by confirming that a neighbor is still reachable before the dead interval expires.
*   C) A routing update sent by a distance-vector protocol containing the full routing table, periodically broadcast to all directly connected neighbors to share reachability information.
*   D) A data table stored in a router listing destination networks, next-hop IP addresses, exit interfaces, and administrative distances computed by the routing protocol.
*   **Correct Answer:** A) A packet generated by each OSPF router to describe its connected links, their costs, and neighbor relationships, which is flooded throughout the area so all routers can build an identical Link-State Database.
*   **Distractor Analysis:**
    * *Why A is correct:* LSAs are the core mechanism by which OSPF routers share topology information. All routers in an area collect LSAs to build an identical LSDB, then each independently runs Dijkstra's SPF algorithm.
    * *Why B is incorrect:* This describes an OSPF Hello packet, which is a separate packet type used for neighbor discovery and adjacency maintenance — not an LSA.
    * *Why C is incorrect:* This describes a distance-vector routing update (like RIP), not an OSPF LSA. OSPF is link-state, not distance-vector.
    * *Why D is incorrect:* This describes a routing table (RIB), which is the output of SPF computation, not the LSA input.

**Question 4**
While working on **OSPFv2 Routing Concepts & Setup** in a production environment, you encounter a system alert indicating a **IP Address Conflict** error. Which of the following is the most effective troubleshooting action to resolve this issue?
B) Change the local network interface settings to use a public DNS resolver like 8.8.8.8 or 1.1.1.1.
A) Release and renew the DHCP lease, or configure a unique static IP address outside the DHCP pool range.
D) Reboot the physical machine and wait for services to reload.
C) Correct the subnet mask configuration on the interface to match the network segment parameters.
*   **Correct Answer:** A) Release and renew the DHCP lease, or configure a unique static IP address outside the DHCP pool range.
*   **Distractor Analysis:**
    * *Why B is incorrect:* This action does not resolve the root cause of IP Address Conflict.
    * *Why A is correct:* Because Two devices on the same physical or logical network segment are configured with the identical IP address. The appropriate fix is to Release and renew the DHCP lease, or configure a unique static IP address outside the DHCP pool range.
    * *Why D is incorrect:* This action does not resolve the root cause of IP Address Conflict.
    * *Why C is incorrect:* This action does not resolve the root cause of IP Address Conflict.

**Question 5**
When configuring **OSPFv2**, you must mitigate the risk of **Attackers capturing plaintext management passwords or session data using network sniffers.**. Which of the following security configurations or controls represents the best practice to implement?
B) Implement switch Port Security to restrict access to switch ports based on approved MAC addresses.
D) Configure OSPF MD5 or SHA authentication on all OSPF interfaces to prevent injection of fraudulent LSAs.
C) Enable `ip ospf passive-interface` on all interfaces that do not connect to OSPF neighbors to prevent hello packets from leaving those interfaces.
A) Configure SSH (port 22) for terminal access and HTTPS (port 443) for web interfaces, disabling Telnet and HTTP.
*   **Correct Answer:** A) Configure SSH (port 22) for terminal access and HTTPS (port 443) for web interfaces, disabling Telnet and HTTP.
*   **Distractor Analysis:**
    * *Why A is correct:* SSH encrypts interactive management sessions, preventing plaintext password and command capture by packet sniffers on the network.
    * *Why B is incorrect:* Port Security restricts access by MAC address but does not encrypt management traffic in transit.
    * *Why D is incorrect:* OSPF authentication protects the routing protocol from rogue router injection, but does not address management session credential exposure.
    * *Why C is incorrect:* Passive interfaces prevent OSPF hello transmission on stub networks (a good practice), but this has no effect on management session security.
