**Question 1**
In a Use Case diagram, which relationship is used when a use case requires the mandatory execution of another use case?
*   A) <<extend>>
*   B) <<include>>
*   C) <<generalize>>
*   D) <<dependency>>
*   **Correct Answer:** B) The <<include>> relationship indicates that the base use case incorporates the behavior of the target use case as a mandatory step.
*   **Distractor Analysis:**
    *   *Why correct:* The <<include>> relationship indicates that the base use case incorporates the behavior of the target use case as a mandatory step.
    *   <<extend>> marks optional behaviors triggered only under specific conditions.

**Question 4**
While working on **Use Case Analysis** in a production environment, you encounter a system alert indicating a **SLA Breach Alert** error. Which of the following is the most effective troubleshooting action to resolve this issue?
B) Implement strict change control boards (CCB) and re-baseline the project constraints.
A) Optimize service resources, implement load balancing, or update failover mechanisms.

    * *Why C is incorrect:* This action does not resolve the root cause of SLA Breach Alert.
    * *Why D is incorrect:* This action does not resolve the root cause of SLA Breach Alert.
