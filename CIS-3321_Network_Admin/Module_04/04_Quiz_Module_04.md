**Question 1**

Which of the following security controls operates at Layer 7 of the OSI model to inspect application payload for malicious signatures and actively drop matching traffic?

A) Stateless packet-filtering firewall

B) Intrusion Detection System (IDS)

C) Intrusion Prevention System (IPS)

D) Layer 3 access control list (ACL)

- **Correct Answer:** C) Intrusion Prevention System (IPS)
- **Distractor Analysis:**
  - *Why A is incorrect:* A stateless firewall examines only IP addresses and port numbers at Layers 3 and 4 — it does not inspect application-layer payload content.
  - *Why B is incorrect:* An IDS monitors and alerts on suspicious traffic but does not actively block or drop packets. Only an IPS takes inline preventive action.
  - *Why C is correct:* An IPS operates inline, inspects packets at the application layer (Layer 7), and actively drops or modifies packets matching known malicious signatures or behavioral anomalies.
  - *Why D is incorrect:* A Layer 3 ACL filters traffic based on IP address and protocol number — it operates at Layer 3 and cannot inspect application-layer content.

**Question 2**

An IPv6-enabled workstation automatically generates a link-local address without any DHCP server or manual configuration. Which prefix identifies this auto-generated address?

A) 2001:db8::/32

B) fc00::/7

C) fe80::/10

D) ff02::/16

- **Correct Answer:** C) fe80::/10
- **Distractor Analysis:**
  - *Why A is incorrect:* 2001:db8::/32 is the documentation/example prefix reserved for use in examples and documentation (similar to RFC 5737 ranges); it is not an auto-generated link-local prefix.
  - *Why B is incorrect:* fc00::/7 (implemented as fd00::/8) is the Unique Local Address prefix — IPv6's equivalent of RFC 1918 private addresses, not auto-generated link-local.
  - *Why C is correct:* fe80::/10 is the link-local prefix. Every IPv6-enabled interface automatically generates a link-local address in this range without requiring any router or DHCP server. Link-local addresses are scoped to the local segment only.
  - *Why D is incorrect:* ff02:: is the link-scope multicast prefix used for group communication; it is not a unicast address auto-generated by a host interface.

**Question 3**

A network administrator needs to query DNS to verify that a hostname resolves to the correct IP address. Which command is most appropriate?

A) nslookup

B) traceroute

C) ping

D) netstat -ano

- **Correct Answer:** A) nslookup
- **Distractor Analysis:**
  - *Why A is correct:* nslookup is specifically designed to query DNS servers and retrieve resource records. It allows the administrator to inspect A, AAAA, MX, CNAME, and other record types directly.
  - *Why B is incorrect:* traceroute maps the router-hop path packets take to reach a destination; it does not query DNS resource records.
  - *Why C is incorrect:* ping tests basic ICMP reachability and performs a DNS lookup to resolve a hostname, but does not allow inspection of specific DNS record types or the ability to query multiple record types.
  - *Why D is incorrect:* netstat -ano displays active TCP/UDP connections and listening ports on the local machine; it has no DNS query capability.

**Question 4**

A company is migrating from IPv4 to IPv6 and wants both protocols to operate simultaneously on all devices during the transition period. Which transition technology best supports this requirement?

A) NAT64 — translates between IPv6 client addresses and IPv4 server addresses at the network border

B) 6to4 tunneling — encapsulates IPv6 packets inside IPv4 headers to cross IPv4-only segments

C) Dual stack — runs both IPv4 and IPv6 natively on the same interface simultaneously

D) Teredo — tunnels IPv6 traffic through IPv4 NAT devices using UDP encapsulation

- **Correct Answer:** C) Dual stack — runs both IPv4 and IPv6 natively on the same interface simultaneously
- **Distractor Analysis:**
  - *Why A is incorrect:* NAT64 is used when IPv6-only clients must reach IPv4-only servers; it does not allow simultaneous native operation of both protocols on all devices.
  - *Why B is incorrect:* 6to4 tunneling wraps IPv6 in IPv4 to cross incompatible infrastructure; it is a workaround for legacy segments, not a clean simultaneous dual-protocol deployment.
  - *Why C is correct:* Dual stack allows a device to have both an IPv4 address and an IPv6 address on the same interface and communicate natively using whichever protocol is appropriate. This is the preferred migration strategy for networks supporting both protocol versions.
  - *Why D is incorrect:* Teredo is a last-resort tunneling mechanism for hosts behind IPv4 NAT devices; it does not represent a clean simultaneous dual-protocol deployment.

**Question 5**

A security policy requires that all IPv6 network devices must enforce authentication before granting access, and that management traffic must be encrypted. Which combination of controls best satisfies both requirements?

A) Implement 802.1X port-based Network Access Control with EAP-TLS for authentication and SSH/TLS for encrypted management sessions.

B) Deploy SLAAC on all interfaces to auto-configure addresses and disable DHCPv6 to reduce attack surface.

C) Enable full disk encryption on all servers storing network configuration files.

D) Configure IPv6 ACLs to block all traffic from fe80::/10 link-local addresses on routed interfaces.

- **Correct Answer:** A) Implement 802.1X port-based Network Access Control with EAP-TLS for authentication and SSH/TLS for encrypted management sessions.
- **Distractor Analysis:**
  - *Why A is correct:* 802.1X with EAP-TLS provides certificate-based device authentication before network access is granted, and SSH/TLS encrypts all management traffic — directly satisfying both requirements.
  - *Why B is incorrect:* SLAAC configures IPv6 addresses automatically but provides no authentication or encryption for access control or management traffic.
  - *Why C is incorrect:* Full disk encryption protects data at rest on storage devices but does not address network authentication or management traffic encryption in transit.
  - *Why D is incorrect:* Blocking link-local addresses on routed interfaces is a routing design choice that affects NDP functionality and is not a standard security control for authenticating devices or encrypting management sessions.

**Question 6**

Which of the following correctly describes the IPv6 loopback address?

A) ::1/128 — used to test the local host's IPv6 stack without transmitting traffic to the network

B) fe80::1/64 — the default link-local address used when no DHCP server is available

C) 2001:db8::1/128 — the documentation prefix used in examples and should not appear on a production network

D) ff02::1/128 — the all-nodes multicast address used to reach every IPv6 host on the local segment

- **Correct Answer:** A) ::1/128 — used to test the local host's IPv6 stack without transmitting traffic to the network
- **Distractor Analysis:**
  - *Why A is correct:* ::1/128 is the IPv6 loopback address, equivalent to 127.0.0.1 in IPv4. Pinging ::1 confirms the local IPv6 stack is functional without generating any network traffic.
  - *Why B is incorrect:* fe80::1 would be a link-local address (fe80::/10 prefix), not the loopback. Link-local addresses are auto-generated from the MAC address, not assigned as a fixed default.
  - *Why C is incorrect:* 2001:db8::/32 is the documentation prefix, not the loopback. The documentation prefix should not appear on production networks, but it is not the loopback address.
  - *Why D is incorrect:* ff02::1 is the all-nodes link-scope multicast address, which allows a device to reach all IPv6 hosts on the local segment. It is not a loopback address.

**Question 7**

A host has MAC address 00:1A:2B:3C:4D:5E and is using SLAAC to configure its IPv6 address. After applying the EUI-64 process, which value will appear in the middle of the 64-bit interface identifier?

A) 00:00

B) FF:FE

C) 7F:7F

D) The MAC address is used unchanged

- **Correct Answer:** B) FF:FE
- **Distractor Analysis:**
  - *Why A is incorrect:* 00:00 is not inserted in the EUI-64 process. A string of zeros would not extend a MAC to 64 bits or provide the unique modification that EUI-64 defines.
  - *Why B is correct:* The EUI-64 process splits the 48-bit MAC at the midpoint and inserts the two bytes FF:FE between the halves, extending the address to 64 bits. This is the defining characteristic of EUI-64 and a reliable exam fact.
  - *Why C is incorrect:* 7F:7F has no role in the EUI-64 process or IPv6 addressing.
  - *Why D is incorrect:* The MAC address is modified in three ways: it is split, FF:FE is inserted, and the seventh bit is flipped. It is not used unchanged.

**Question 8**

A network uses SLAAC for IPv6 address assignment. Users report that they have IPv6 addresses and can reach other hosts on the local segment, but they cannot resolve hostnames or reach the internet. What is the most likely missing configuration?

A) The router has not been configured to send Router Advertisement messages.

B) No DNS server address was provided to the clients; SLAAC does not provide DNS by default without RDNSS or DHCPv6.

C) The clients do not have a MAC address configured, so EUI-64 cannot generate an interface identifier.

D) Link-local addresses are blocking internet traffic because they are not globally routable.

- **Correct Answer:** B) No DNS server address was provided to the clients; SLAAC does not provide DNS by default without RDNSS or DHCPv6.
- **Distractor Analysis:**
  - *Why A is incorrect:* The clients have IPv6 addresses and can reach local hosts, which confirms Router Advertisements are being sent and SLAAC is working. The RA is not the problem.
  - *Why B is correct:* SLAAC provides the network prefix and default gateway through Router Advertisements, but does not natively provide DNS server information. Without DNS (provided by RDNSS options in the RA or stateless DHCPv6), clients cannot resolve hostnames.
  - *Why C is incorrect:* The question states clients have IPv6 addresses, which means EUI-64 (or random interface ID generation) has already succeeded. MAC addresses are present.
  - *Why D is incorrect:* Link-local addresses (fe80::) are used for NDP and local communication, not for internet traffic. Global unicast addresses handle internet traffic; the symptom described (can reach local but not internet) points to DNS, not link-local scope limitation.

**Question 9**

An organization needs IPv6-only hosts to access legacy IPv4-only web servers on the internet. Which transition technology is the most appropriate solution?

A) Dual stack — both IPv4 and IPv6 are assigned to each host

B) 6to4 tunneling — wraps IPv6 packets in IPv4 headers

C) NAT64 — translates between IPv6 and IPv4 addresses at the network border

D) ISATAP — tunnels IPv6 over an IPv4 intranet

- **Correct Answer:** C) NAT64 — translates between IPv6 and IPv4 addresses at the network border
- **Distractor Analysis:**
  - *Why A is incorrect:* Dual stack requires IPv4 addresses on the hosts, but the scenario specifies IPv6-only hosts. If hosts have no IPv4 addresses, dual stack cannot be used.
  - *Why B is incorrect:* 6to4 tunneling carries IPv6 packets over IPv4 infrastructure — it still requires the destination to be an IPv6 host. It does not translate to IPv4 servers.
  - *Why C is correct:* NAT64 provides protocol translation at the network border, allowing IPv6-only clients to communicate with IPv4-only servers. The border device translates IPv6 addresses to IPv4 addresses and vice versa.
  - *Why D is incorrect:* ISATAP tunnels IPv6 over an IPv4 intranet within an organization. It does not translate between the two protocols and does not enable IPv6 hosts to reach IPv4 servers.

**Question 10**

Which IPv6 mechanism has completely replaced the function of IPv4's ARP (Address Resolution Protocol) for resolving layer 3 addresses to layer 2 MAC addresses on a local segment?

A) DHCPv6 Stateful — the DHCPv6 server maintains a mapping of IPv6 addresses to MAC addresses

B) NDP (Neighbor Discovery Protocol) — uses ICMPv6 Neighbor Solicitation and Neighbor Advertisement messages

C) SLAAC — the EUI-64 process derives MAC addresses directly from IPv6 interface identifiers

D) DNS AAAA records — IPv6 addresses include embedded MAC information for resolution

- **Correct Answer:** B) NDP (Neighbor Discovery Protocol) — uses ICMPv6 Neighbor Solicitation and Neighbor Advertisement messages
- **Distractor Analysis:**
  - *Why A is incorrect:* DHCPv6 assigns IPv6 addresses but does not perform link-layer address resolution. It does not replace ARP's function of mapping a known IP to an unknown MAC.
  - *Why B is correct:* NDP replaces ARP in IPv6. When a host needs the MAC address for a known IPv6 address, it sends an ICMPv6 Neighbor Solicitation to the solicited-node multicast address. The target responds with a Neighbor Advertisement containing its MAC address.
  - *Why C is incorrect:* SLAAC uses EUI-64 to generate an interface identifier for address configuration purposes — it does not perform on-demand address resolution of neighbor IPv6 addresses to MAC addresses.
  - *Why D is incorrect:* DNS AAAA records map hostnames to IPv6 addresses — they are a Layer 7 name resolution mechanism and do not contain MAC address information.
