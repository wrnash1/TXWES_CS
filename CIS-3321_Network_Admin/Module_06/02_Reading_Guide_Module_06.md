### Introduction
Welcome to **Module 06 - Wireless**! This week's study material focuses on the core foundations and configuration mechanics of **Wireless** as aligned with the **3321_Network_Admin - CompTIA Network+ (N10-008)** certification framework. Understanding these topics is essential not only for passing the certification exam but also for administering enterprise systems in real-world environments.

As a student, you will learn the primary operational roles, command syntaxes, and troubleshooting parameters needed to design, configure, and maintain these services. We will explore how different protocols establish connections, how configurations manage resource allocation, and how security controls prevent access breaches. Make sure to complete the checklists and review the glossary terms in detail before beginning the lab activity.

---

### 1. High-Yield Glossary
Review these essential definitions carefully. The certification exam expects you to know these concepts inside and out:

*   **Captive Portals**: A web page that intercepts traffic to force users to agree to Terms of Service before accessing public Wi-Fi.
*   **EAP / 802.1X**: Enterprise authentication where users log into Wi-Fi using their Active Directory usernames instead of a shared password.
*   **Focus Area**: Pay close attention to how these configurations behave by default. The exam frequently features questions on default ports, configuration file paths, and diagnostic console commands.
*   **Scenario Trap**: Watch out for questions asking you to troubleshoot a failing service. Always verify if basic network connectivity, local port conflicts, or permissions are violated first.
*   **Study Resource**: To reinforce these concepts visually, review this targeted search query: [Professor Messer's CompTIA Network+ Course Playlist - Wireless](https://www.youtube.com/playlist?list=PLG49S3nxzAnmpm1HP80g85VIyFCxs34ee).
