# Course Administration Pack: CIS-4330_Intro_to_AI
**Target Certification:** Microsoft Azure AI Fundamentals (AI-900)

## Course Description
This course covers the fundamentals of artificial intelligence and machine learning on Microsoft Azure. It is aligned directly with the Microsoft Azure AI Fundamentals (AI-900) exam blueprint, preparing students to describe AI workloads, identify appropriate Azure AI services for given scenarios, explain how machine learning works, and apply Microsoft's Responsible AI principles.

## Required Materials
1. **Zero Textbook Cost (ZTC):** All required reading materials, official documentation, and study guides are provided completely free within the Canvas course modules or via the integrated module study resources. No textbook purchase is required.
2. A computer capable of running basic lab environments or accessing cloud portals.
