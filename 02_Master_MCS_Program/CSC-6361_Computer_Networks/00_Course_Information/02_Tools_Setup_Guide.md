## 💻 Required Software: Cisco Packet Tracer (Desktop Application)

All hands-on laboratory exercises in Modules 01 through 07 require **Cisco Packet Tracer (v8.2 or higher)**.

### Step-by-Step Installation Instructions:
1. **Access the Free Introductory Tutorial:**  
   Navigate to the official Cisco Skills for All portal:  
   👉 [Cisco Skills for All: Getting Started with Cisco Packet Tracer](https://skillsforall.com/course/getting-started-cisco-packet-tracer)
2. **Create Your Free Account:**  
   Click **"Get Started"** or **"Sign In"** and register a free account using your Texas Wesleyan email (`@txwes.edu`).
3. **Download the Desktop Installer:**  
   Select the official installer matching your workstation operating system:
   * **Windows:** Cisco Packet Tracer 8.2+ (64-bit Desktop)
   * **macOS:** Cisco Packet Tracer 8.2+ for macOS (Intel or Apple Silicon M1/M2/M3)
   * **Linux:** Ubuntu 64-bit (.deb package)
4. **First-Time Launch & One-Time Activation:**  
   * Launch Cisco Packet Tracer.
   * When prompted with the login dialog, select **"Skills for All"** or **"Cisco Networking Academy"**.
   * Check the box **"Keep me logged in"** (maintains your active login token for 3 months without re-prompting).
   * Enter your free account credentials. The application workspace will open immediately.

## 📝 Hands-On Lab Workflow & Submission Format

For every weekly module lab (Modules 01–07):
1. **Build the Topology:** Open Packet Tracer and construct the required multi-router/switch enterprise topology according to the lab brief.
2. **Configure Protocols:** Implement routing protocols (OSPF, EIGRP, BGP), campus switching (VLANs, MSTP, EtherChannel), WAN tunneling (GRE, IPsec), security controls (CoPP, DAI), or QoS policies.
3. **Verify Functionality:** Run Cisco IOS verification commands (`show ip ospf neighbor`, `show ip bgp summary`, `ping`, etc.) to confirm end-to-end convergence.
4. **Submit to Canvas:** Every lab requires two mandatory deliverables uploaded directly to the Canvas assignment:
   * **The `.pkt` topology file:** Complete, saved Packet Tracer project.
   * **The Lab Report (PDF):** Document containing topology diagrams, configuration listings, verification output screenshots, and graduate-level analytical responses.
