## Course Overview

### Course Description
This course provides comprehensive training in Linux operating system administration, aligned with the CompTIA Linux+ (XK0-005) certification exam blueprint. Students will develop hands-on proficiency with the Linux command line, filesystem navigation, user and group management, shell scripting, package management, system services, networking, storage, and security hardening. The course prepares students for real-world Linux system administration roles and the official CompTIA Linux+ certification exam.

### Course Objectives / Student Learning Outcomes
By the end of this course, students will be able to:
1. Explain and configure core Linux system administration principles aligned with the **CompTIA Linux+ (XK0-005)** exam domains, including system management, security, scripting, and troubleshooting.
2. Formulate, execute, and verify terminal-based commands and administrative configurations that match production-level Linux operations, including service management, storage provisioning, and network configuration.
3. Critically analyze Linux system failures and security vulnerabilities, and propose and implement mitigation strategies using tools such as SELinux, AppArmor, Ansible, and SSH hardening techniques.
4. Prepare for and demonstrate competency aligned with the official **CompTIA Linux+ (XK0-005)** certification exam blueprint across all four exam domains: System Management, Security, Scripting/Containers/Automation, and Troubleshooting.
