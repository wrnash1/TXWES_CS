## Scenario Background

Pinnacle Health System (a fictional organization) is implementing a new telehealth platform. The project has a Budget at Completion (BAC) of $750,000 and a planned 12-month schedule. You are the project manager reviewing the project status at the end of Month 6.

Status at Month 6 status date:

- Work planned to be complete by Month 6: 55% of total scope
- Work actually completed as of Month 6: 48% of total scope
- Actual money spent through Month 6: $390,000

Additional budget information:

- The project budget includes $60,000 set aside for identified risks documented in the risk register
- An additional $40,000 is held by the VP of IT Operations for completely unforeseen project issues
- The BAC of $750,000 represents only the approved project work budget (does not include the $40,000 held by the VP)

## Part 3: EVM Decision Analysis

### Part 3 Objective

Use the EVM results from Part 2 to make a management recommendation and evaluate a proposed corrective action.

### Part 3 Instructions

Write a 250–350 word executive status memo to the Pinnacle Health System VP of IT Operations. The memo must address the following:

Section A — Current Project Status (one paragraph):

Summarize the project's cost and schedule status using the EVM metrics from Part 2. Use plain language — write as if the VP does not know EVM formulas. State specifically whether the project is over or under budget and ahead or behind schedule, by how much, and what the current forecast says about total project cost.

Section B — Recommended Corrective Action (one paragraph):

The project is currently behind schedule. Propose one specific corrective action the project manager should take to recover schedule. Your recommendation must:

- Name the corrective action (crashing, fast-tracking, resource reallocation, scope reduction, or another justified option)
- Explain how it addresses the schedule performance problem
- Acknowledge any trade-offs (cost impact, quality risk, or scope impact)

Section C — Reserve Recommendation (one paragraph):

Given the current cost variance, does the project need to draw on the contingency reserve? Justify your answer using the CV result from Part 2. If the reserve should be used, specify what it would cover and confirm it is within the PM's authority to release it.

**Part 3 Point Value:** 30 points

Grading breakdown:

- Section A status summary (10 pts): Accurate EVM-based summary in plain language; correct interpretation of over/under budget and ahead/behind schedule
- Section B corrective action (10 pts): Appropriate recommendation with named technique; accurate trade-off acknowledgment
- Section C reserve analysis (10 pts): Correct determination of whether contingency reserve is warranted; demonstrates understanding of PM authority over contingency vs. management reserve

## Part 9 — Challenge Exercise

This section is optional for students seeking additional depth and exam preparation. It is not graded as part of the standard 100-point lab but may be used for extra credit at the instructor's discretion.

### Challenge Step 1: EAC Sensitivity Comparison

Using the EVM values from Part 2 of this lab, calculate THREE different EAC values using the three standard formulas:

- EAC₁ = BAC / CPI (current variance will continue)
- EAC₂ = AC + (BAC - EV) (current variance is atypical)
- EAC₃ = AC + [(BAC - EV) / CPI] (both CPI and SPI persist)

Present all three values in a table. Write a paragraph (5–7 sentences) explaining which estimate you would recommend presenting to the project sponsor and why — considering the project's current cost and schedule status.

### Challenge Step 2: TCPI Decision Point

Calculate the TCPI for the project in Part 2 using TCPI = (BAC - EV) / (BAC - AC). Then interpret the result: can the project team realistically achieve this performance level? If the TCPI exceeds 1.20, write a one-paragraph recommendation for re-baselining the project budget (revising the EAC as the new target). Explain what governance steps are required to re-baseline under PMI methodology.

### Challenge Step 3: Stakeholder Cost Report Narrative

Draft a brief (8–10 sentence) written cost status report as if you were the project manager presenting to an executive sponsor with no EVM background. Translate the CPI, SPI, CV, SV, EAC, and VAC values from Part 2 into plain English without using any EVM abbreviations. The goal is to communicate project financial health clearly to a non-technical decision-maker — a critical PM communication skill tested in Project+ Domain 3.
