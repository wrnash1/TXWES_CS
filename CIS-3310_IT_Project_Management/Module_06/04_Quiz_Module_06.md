**Question 1**
Which cost estimation technique uses historical data from similar projects as the basis for the current estimate?
*   A) Parametric Estimating
*   B) Analogous (Top-down) Estimating
*   C) Bottom-up Estimating
*   D) Three-point Estimating
*   **Correct Answer:** B) Analogous estimating uses actual cost or duration data from similar past projects to estimate the current project; it is quick but less precise than other techniques.
*   **Distractor Analysis:**
    *   *Why B is correct:* Analogous estimating requires minimal information and relies on expert judgment to compare the current project to historical projects. It is most useful in early phases when detailed data is unavailable.
    *   *Why A is incorrect:* Parametric estimating uses a statistical relationship between project variables and historical data (e.g., cost per server, hours per module)—it does not simply compare to past projects as a whole.
    *   *Why C is incorrect:* Bottom-up estimating builds costs from the work package level upward; it is the most accurate technique but requires a complete WBS, not just reference to a prior project.
    *   *Why D is incorrect:* Three-point estimating calculates a weighted average of optimistic (O), most likely (M), and pessimistic (P) estimates (PERT formula: (O + 4M + P) / 6); it addresses uncertainty, not historical project comparison.

**Question 2**
Which of the following best defines **Bottom-Up Estimation** in project cost management?
*   A) An estimating technique that builds the project budget by estimating the cost of each individual work package and then summing those estimates up through the WBS hierarchy.
*   B) An estimating technique that uses the total cost of a previous similar project as the basis for the current project's budget without breaking down individual components.
*   C) A technique that applies a statistical formula (such as cost per unit) to derive a total cost estimate from measurable project parameters.
*   D) A rough estimate prepared during project initiating that carries an accuracy range of −25% to +75%.
*   **Correct Answer:** A) An estimating technique that builds the project budget by estimating the cost of each individual work package and then summing those estimates up through the WBS hierarchy.
*   **Distractor Analysis:**
    *   *Why A is correct:* Bottom-up estimating is the most accurate cost estimating technique because every component of work is individually analyzed. The granular estimates roll up to give a detailed, defensible total budget.
    *   *Why B is incorrect:* Using a previous project's total cost as the basis without decomposing components describes analogous (top-down) estimating, not bottom-up.
    *   *Why C is incorrect:* Applying a cost-per-unit statistical formula describes parametric estimating; it relies on unit rates rather than WBS decomposition.
    *   *Why D is incorrect:* A rough estimate with a −25% to +75% accuracy range describes a Rough Order of Magnitude (ROM) estimate, typically used during the Initiating process group when limited scope detail is available.

**Question 3**
A project manager is setting aside an additional $15,000 in the project budget specifically to cover identified risks that have been documented in the Risk Register. What type of reserve is this?
*   A) Management Reserve
*   B) Contingency Reserve
*   C) Operational Reserve
*   D) Cost Baseline Surplus
*   **Correct Answer:** B) A Contingency Reserve is budget held within the project's cost baseline to address identified risks (known unknowns) documented in the Risk Register; it is controlled by the project manager.
*   **Distractor Analysis:**
    *   *Why B is correct:* Contingency reserves are specifically set aside for known risks. The PM can release these funds without executive approval when a documented risk occurs.
    *   *Why A is incorrect:* Management Reserves are funds held by management outside the cost baseline to handle completely unforeseen events (unknown unknowns). The PM must request management reserve from senior leadership; it is not pre-allocated to identified risks.
    *   *Why C is incorrect:* "Operational Reserve" is not a standard PMI term; it does not appear in the PMBOK or Project+ exam objectives.
    *   *Why D is incorrect:* A "Cost Baseline Surplus" would mean the project came in under budget at completion; it is not a planning-time reserve category.

**Question 4**
The project sponsor asks for the most accurate cost estimate possible before construction of a new data center begins. The project team has a fully developed WBS with detailed work packages. Which estimating technique should the PM use?
*   A) Analogous Estimating
*   B) ROM (Rough Order of Magnitude)
*   C) Parametric Estimating
*   D) Bottom-Up Estimating
*   **Correct Answer:** D) Bottom-Up Estimating is the most accurate technique and should be used when a detailed WBS is available and a high-accuracy estimate is required.
*   **Distractor Analysis:**
    *   *Why D is correct:* With a complete WBS at hand and a requirement for maximum accuracy, bottom-up estimating is the correct choice. Each work package is individually estimated and summed for the total.
    *   *Why A is incorrect:* Analogous estimating would be used in early project stages when only limited scope information is available, not when a detailed WBS exists and accuracy is required.
    *   *Why B is incorrect:* ROM is the least accurate estimate (−25% to +75%) and is used only for initial feasibility analysis, not when the sponsor explicitly requires high accuracy.
    *   *Why C is incorrect:* Parametric estimating applies statistical rates and is moderately accurate; it is less accurate than bottom-up and is most useful when reliable unit cost data is available but WBS-level detail is not fully developed.

**Question 5**
During project planning, what does the **Cost Baseline** represent?
*   A) The highest possible expenditure the project sponsor will approve under any circumstances.
*   B) The approved time-phased budget that is used as the reference point for measuring and reporting project cost performance.
*   C) The total amount of contingency and management reserves combined.
*   D) The final invoice submitted to the client at project closeout.
*   **Correct Answer:** B) The Cost Baseline is the approved, time-phased budget that serves as the comparison standard for measuring actual cost performance throughout the project.
*   **Distractor Analysis:**
    *   *Why B is correct:* The Cost Baseline is established at the end of Planning and is used in EVM calculations (PV is derived from it). Changes to the cost baseline require a formal change request and approval.
    *   *Why A is incorrect:* The cost baseline is not a spending ceiling; it is a performance measurement reference. The spending ceiling is governed by the project budget (which includes management reserves on top of the baseline).
    *   *Why C is incorrect:* The cost baseline includes contingency reserves but does NOT include management reserves. Management reserves are held outside the baseline.
    *   *Why D is incorrect:* A final invoice is a financial closing document, not a planning baseline. The cost baseline exists from the time it is approved in Planning through project closeout.
