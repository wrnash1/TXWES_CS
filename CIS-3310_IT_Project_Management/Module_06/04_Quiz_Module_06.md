## Question 1

Which cost estimation technique uses historical data from similar projects as the basis for the current estimate?

- A) Parametric Estimating
- B) Analogous (Top-down) Estimating
- C) Bottom-up Estimating
- D) Three-point Estimating

Correct Answer: B) Analogous estimating uses actual cost or duration data from similar past projects to estimate the current project; it is quick but less precise than other techniques.

Distractor Analysis:

- *Why B is correct:* Analogous estimating requires minimal information and relies on expert judgment to compare the current project to historical projects. It is most useful in early phases when detailed data is unavailable.
- *Why A is incorrect:* Parametric estimating uses a statistical relationship between project variables and historical data (cost per server, hours per module) — it does not simply compare to a past project as a whole.
- *Why C is incorrect:* Bottom-up estimating builds costs from the work package level upward; it is the most accurate technique but requires a complete WBS.
- *Why D is incorrect:* Three-point estimating calculates a weighted average of optimistic, most likely, and pessimistic estimates; it addresses uncertainty in individual estimates, not historical project comparison.

## Question 2

Which of the following best defines Bottom-Up Estimation in project cost management?

- A) An estimating technique that builds the project budget by estimating the cost of each individual work package and then summing those estimates up through the WBS hierarchy.
- B) An estimating technique that uses the total cost of a previous similar project as the basis for the current project's budget.
- C) A technique that applies a statistical formula (such as cost per unit) to derive a total cost estimate from measurable project parameters.
- D) A rough estimate prepared during project initiating that carries an accuracy range of -25% to +75%.

Correct Answer: A) An estimating technique that builds the project budget by estimating the cost of each individual work package and then summing those estimates up through the WBS hierarchy.

Distractor Analysis:

- *Why A is correct:* Bottom-up estimating is the most accurate cost estimating technique because every component of work is individually analyzed. The granular estimates roll up to give a detailed, defensible total budget.
- *Why B is incorrect:* Using a previous project's total cost as the basis describes analogous (top-down) estimating, not bottom-up.
- *Why C is incorrect:* Applying a cost-per-unit statistical formula describes parametric estimating.
- *Why D is incorrect:* A rough estimate with -25% to +75% accuracy describes a Rough Order of Magnitude (ROM) estimate, typically used during Initiating.

## Question 3

A project manager is setting aside an additional $15,000 in the project budget specifically to cover identified risks documented in the Risk Register. What type of reserve is this?

- A) Management Reserve
- B) Contingency Reserve
- C) Operational Reserve
- D) Cost Baseline Surplus

Correct Answer: B) A Contingency Reserve is budget held within the Cost Baseline to address identified risks (known unknowns) documented in the Risk Register; it is controlled by the project manager.

Distractor Analysis:

- *Why B is correct:* Contingency reserves are set aside for known risks. The PM can release these funds without executive approval when a documented risk occurs.
- *Why A is incorrect:* Management Reserves are held by management outside the Cost Baseline for completely unforeseen events (unknown unknowns). The PM must request management reserve from senior leadership.
- *Why C is incorrect:* "Operational Reserve" is not a standard PMI term and does not appear in PMBOK or Project+ exam objectives.
- *Why D is incorrect:* A "Cost Baseline Surplus" would mean the project came in under budget at completion; it is not a planning-time reserve category.

## Question 4

The project sponsor asks for the most accurate cost estimate possible before construction of a new data center begins. The project team has a fully developed WBS with detailed work packages. Which estimating technique should the PM use?

- A) Analogous Estimating
- B) ROM (Rough Order of Magnitude)
- C) Parametric Estimating
- D) Bottom-Up Estimating

Correct Answer: D) Bottom-Up Estimating is the most accurate technique and should be used when a detailed WBS is available and high-accuracy is required.

Distractor Analysis:

- *Why D is correct:* With a complete WBS and a requirement for maximum accuracy, bottom-up estimating is the correct choice. Each work package is individually estimated and summed for the total.
- *Why A is incorrect:* Analogous estimating would be used in early project stages when only limited scope information is available, not when a detailed WBS exists.
- *Why B is incorrect:* ROM is the least accurate estimate (-25% to +75%) and is used only for initial feasibility analysis.
- *Why C is incorrect:* Parametric estimating is moderately accurate but less accurate than bottom-up and is most useful when reliable unit cost data is available without full WBS detail.

## Question 5

During project planning, what does the Cost Baseline represent?

- A) The highest possible expenditure the project sponsor will approve under any circumstances.
- B) The approved time-phased budget used as the reference point for measuring and reporting project cost performance.
- C) The total amount of contingency and management reserves combined.
- D) The final invoice submitted to the client at project closeout.

Correct Answer: B) The Cost Baseline is the approved, time-phased budget that serves as the comparison standard for measuring actual cost performance throughout the project.

Distractor Analysis:

- *Why B is correct:* The Cost Baseline is established at the end of Planning and is used in EVM calculations (PV is derived from it). Changes require a formal change request and approval.
- *Why A is incorrect:* The cost baseline is not a spending ceiling; the project budget (baseline + management reserves) represents the total authorized funding.
- *Why C is incorrect:* The Cost Baseline includes contingency reserves but does NOT include management reserves. Management reserves are held outside the baseline.
- *Why D is incorrect:* A final invoice is a financial closing document, not a planning baseline.

## Question 6

What is the main focus of Quality Assurance (QA) compared to Quality Control (QC)?

- A) QA focuses on preventing defects in processes, while QC focuses on identifying defects in deliverables
- B) QA runs automated unit tests; QC manages project budgets
- C) QC manages project budgets; QA is only performed by external auditors
- D) QA is done only by project managers; QC is done only by developers

Correct Answer: A) QA is process-oriented and proactive (preventing defects through process improvements); QC is product-oriented and reactive (inspecting deliverables to find defects).

Distractor Analysis:

- *Why A is correct:* The QA vs. QC distinction is one of the most tested quality concepts. QA audits processes to prevent defects from occurring. QC inspects outputs to detect defects after they have been produced.
- *Why B is incorrect:* Running automated unit tests is a QC activity (testing a product); QC has nothing to do with budget management.
- *Why C is incorrect:* QC is product inspection, not budget management. QA can be performed by internal team members — it is not restricted to external auditors.
- *Why D is incorrect:* Both QA and QC can be performed by various roles depending on the organization. Neither is restricted to a single role type.

## Question 7

Which of the following best defines a Check Sheet in quality management?

- A) A simple data collection form used to record the frequency of defects or observations in real time during quality control activities.
- B) A hierarchical diagram that shows all the potential causes of a quality defect organized by major categories.
- C) A bar chart that ranks defect categories from most to least frequent to help teams focus on the highest-impact issues.
- D) A formal document that lists all quality standards applicable to the project and how the team will meet them.

Correct Answer: A) A check sheet is a simple, structured data collection form used to record how often specific defects or events occur as observations are made.

Distractor Analysis:

- *Why A is correct:* Check sheets enable real-time data collection during QC activities. The tally marks are later analyzed using other tools such as histograms or Pareto charts.
- *Why B is incorrect:* A hierarchical diagram showing categories of potential causes describes an Ishikawa (Fishbone) Diagram, not a check sheet.
- *Why C is incorrect:* A bar chart ranking defect categories by frequency describes a Pareto Chart.
- *Why D is incorrect:* A document listing quality standards and compliance approaches describes the Quality Management Plan.

## Question 8

A software project team conducts a mid-project review of their development process to verify that all coding practices comply with the organization's security standards. What type of quality activity is this?

- A) Quality Control — because they are reviewing the code itself
- B) Quality Assurance — because they are auditing the process to ensure it meets defined standards
- C) Scope Validation — because they are confirming deliverables are complete
- D) Risk Monitoring — because they are checking for security vulnerabilities

Correct Answer: B) Quality Assurance — auditing the development process to verify it conforms to defined standards is proactive, process-focused quality work.

Distractor Analysis:

- *Why B is correct:* Process audits against defined standards are the hallmark of QA. The team is not inspecting a specific code deliverable for defects; they are checking whether the team's process itself is compliant.
- *Why A is incorrect:* QC inspects finished products (running tests on completed code to find bugs), not the process used to build them.
- *Why C is incorrect:* Scope Validation is the process of formally accepting completed deliverables with the customer — different from an internal process audit.
- *Why D is incorrect:* Risk Monitoring tracks identified risks and watches for new ones; a process compliance review is a quality activity, not a risk response activity.

## Question 9

A project manager is using a Pareto Chart to analyze help desk ticket categories after a system deployment. The chart shows that password resets (45%), access permission errors (30%), and printer issues (15%) together account for 90% of all tickets. What action does the Pareto analysis suggest?

- A) Address all ticket categories equally to ensure comprehensive coverage
- B) Focus first on resolving the password reset and access permission processes, as they account for 75% of the problem
- C) Ignore the minor categories entirely, as they are too small to matter
- D) Replace the help desk team, since high ticket volume indicates poor performance

Correct Answer: B) Pareto analysis directs the team to focus on the "vital few" causes — password resets and access permissions together cause 75% of tickets, so fixing those processes delivers the most impact.

Distractor Analysis:

- *Why B is correct:* The 80/20 rule underlying Pareto analysis says roughly 80% of effects come from 20% of causes. Focusing resources on the highest-frequency categories delivers disproportionate improvement.
- *Why A is incorrect:* Spreading effort equally ignores the Pareto principle and wastes resources on low-impact issues while high-impact ones persist.
- *Why C is incorrect:* Minor categories should not be completely ignored — they may still affect users and could grow. The Pareto principle prioritizes, not eliminates, lower-frequency items.
- *Why D is incorrect:* High ticket volume after deployment may reflect a configuration issue or training gap, not poor help desk performance.

## Question 10

Which quality tool would a project manager use to test whether a relationship exists between the number of lines of code changed per sprint and the number of defects reported the following week?

- A) Pareto Chart
- B) Control Chart
- C) Scatter Diagram
- D) Fishbone Diagram

Correct Answer: C) A Scatter Diagram plots two variables against each other to reveal whether a correlation exists between them.

Distractor Analysis:

- *Why C is correct:* The Scatter Diagram is specifically used to test correlation between two variables. Plotting "lines of code changed" vs. "defects reported the following week" on a scatter diagram reveals whether the relationship is positive, negative, or non-existent.
- *Why A is incorrect:* A Pareto Chart ranks defect categories by frequency. It does not test the relationship between two continuous variables.
- *Why B is incorrect:* A Control Chart monitors process performance over time against control limits. It tracks a single variable over time, not the correlation between two variables.
- *Why D is incorrect:* A Fishbone Diagram identifies and categorizes potential causes of a specific defect. It is a brainstorming tool, not a statistical correlation analysis tool.
