**Question 1**
What is the primary role of a Change Control Board (CCB) in project management?
*   A) To write programming code and implement technical changes
*   B) To review, evaluate, and approve or reject requested project scope modifications
*   C) To purchase software licenses and negotiate vendor contracts
*   D) To hire and onboard new project team members
*   **Correct Answer:** B) The CCB is a formal governance body of stakeholders that reviews change requests, evaluates their impact on project baselines, and makes approval/rejection decisions before changes are implemented.
*   **Distractor Analysis:**
    *   *Why B is correct:* The CCB's function is scope governance, not technical execution. It protects project baselines from unauthorized changes and ensures all modifications are assessed for cost, schedule, and risk impact.
    *   *Why A is incorrect:* Writing code and implementing changes is the work of the development team; the CCB makes governance decisions about whether changes should be made, not how to make them technically.
    *   *Why C is incorrect:* Purchasing licenses and negotiating contracts is the domain of Procurement Management, not the CCB. The CCB focuses on scope control.
    *   *Why D is incorrect:* Hiring and onboarding team members is a human resource management activity. The CCB is not involved in staffing decisions.

**Question 2**
Which of the following best defines an **Impact Assessment** in the change control process?
*   A) The process of evaluating how a proposed change would affect the project's scope, schedule, cost, quality, and risk before a decision is made to approve or reject it.
*   B) A formal document listing all risks that have occurred during the project, their actual impacts, and the effectiveness of response strategies.
*   C) A financial analysis comparing the cost of implementing a change to the cost of not implementing it.
*   D) An audit conducted after project closure to assess whether the project delivered its intended business benefits.
*   **Correct Answer:** A) An Impact Assessment evaluates all the effects a proposed change would have on every aspect of the project before the CCB decides whether to approve it.
*   **Distractor Analysis:**
    *   *Why A is correct:* A complete impact assessment is the critical input to CCB decision-making. It prevents well-meaning changes from creating unintended damage to the project schedule, budget, or quality.
    *   *Why B is incorrect:* Documenting risks that have occurred and assessing response effectiveness describes risk monitoring or a risk retrospective, not a change control impact assessment.
    *   *Why C is incorrect:* A cost comparison (cost to implement vs. cost not to implement) is one element of an impact assessment but describes the business case or return on investment analysis more than the full scope of an impact assessment.
    *   *Why D is incorrect:* Assessing whether the project delivered its business benefits after closure describes a post-implementation review or benefits realization analysis, not a change control impact assessment.

**Question 3**
A stakeholder informally asks a developer to add a new feature to a software system that is currently in testing. The developer implements the feature without a change request. What term describes this situation and what should the project manager do?
*   A) This is gold plating; the PM should accept it if the feature works correctly.
*   B) This is scope creep; the PM should stop the unauthorized work, assess the impact, and route a formal change request through the CCB.
*   C) This is a schedule risk; the PM should log it in the risk register and monitor for impact.
*   D) This is a quality improvement; the PM should document it in the lessons learned register.
*   **Correct Answer:** B) Unauthorized implementation of scope additions is scope creep. The correct response is to halt the work, perform an impact assessment, and submit a formal change request.
*   **Distractor Analysis:**
    *   *Why B is correct:* Regardless of whether a change is beneficial, bypassing the change control process creates uncontrolled scope, schedule, and budget impacts. The PM must enforce the process, even if it means temporarily rolling back the change.
    *   *Why A is incorrect:* Gold plating describes the team adding features beyond requirements, often with good intent. While this is a related concept, the correct action is not to accept it—even gold plating should be controlled through formal change management.
    *   *Why C is incorrect:* While unauthorized changes do create schedule risk, the correct immediate response is to address the change control violation, not simply log a risk and monitor.
    *   *Why D is incorrect:* Documenting it in lessons learned is appropriate eventually, but the immediate action must be to stop the unauthorized work and enforce the change control process.

**Question 4**
During which step of the change control process should the project manager assess how a requested change will affect the project's cost, schedule, and scope before presenting it to the CCB?
*   A) After CCB approval, during the implementation phase
*   B) After the change is implemented, to validate the impact was as expected
*   C) Before the CCB review, as the critical input that enables the CCB to make an informed decision
*   D) During project closure, as part of the lessons learned documentation
*   **Correct Answer:** C) The impact assessment must be completed before the CCB review—it is the information the CCB needs to make an informed decision about whether to approve or reject the change.
*   **Distractor Analysis:**
    *   *Why C is correct:* The change control sequence is: Request → Impact Assessment → CCB Review → Approval/Rejection → Implementation (if approved) → Baseline Update. The impact assessment is a prerequisite for the CCB meeting.
    *   *Why A is incorrect:* Assessing impact after CCB approval and during implementation is too late—the change is already in motion. The CCB cannot make a sound decision without impact data.
    *   *Why B is incorrect:* Post-implementation validation confirms the change had the expected effect; it is not the impact assessment performed before approval.
    *   *Why D is incorrect:* Lessons learned documentation occurs at closure; impact assessments are conducted during the active change control process, not after the project ends.

**Question 5**
A project manager discovers that a software component that was previously approved and baselined has been modified by a developer without a change request, and the modified version has been released to users. Which discipline should have prevented this?
*   A) Quality Control – through more rigorous testing of the component
*   B) Configuration Management – through version control and access controls on approved deliverables
*   C) Risk Management – by identifying the risk of unauthorized modifications in the Risk Register
*   D) Resource Management – by restricting which team members have development access
*   **Correct Answer:** B) Configuration Management controls the versioning, integrity, and access to approved deliverables. Proper configuration management would have flagged or prevented unauthorized modifications to a baselined component.
*   **Distractor Analysis:**
    *   *Why B is correct:* Configuration management uses version control systems, access controls, and baseline locks to ensure only approved versions of deliverables are changed. An unauthorized modification to a baselined deliverable is a configuration management failure.
    *   *Why A is incorrect:* QC testing could detect a modification after it happens, but it does not prevent unauthorized changes. Configuration management is the preventive control.
    *   *Why C is incorrect:* While the risk of unauthorized modifications could be documented, risk management is a planning and monitoring discipline—not the technical control that would have prevented the modification from happening.
    *   *Why D is incorrect:* Restricting developer access is an element of configuration management and IT security, not a separate resource management activity. The broader answer is configuration management.
