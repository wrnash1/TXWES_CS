## Question 1

What is the lowest level of decomposition in a Work Breakdown Structure (WBS) called?

- A) Sub-project
- B) Task group
- C) Work Package
- D) Milestone

Correct Answer: C) Work packages are the granular, deliverable-oriented units at the bottom of the WBS tree, from which schedule activities and cost estimates are derived.

Distractor Analysis:

- *Why C is correct:* The WBS 100% Rule requires all project work to be represented, and work packages are the lowest-level components. Each work package can be owned, estimated, and scheduled by a single team.
- *Why A is incorrect:* A sub-project is a separately managed section of a large project; it is not the lowest level of WBS decomposition.
- *Why B is incorrect:* "Task group" is not a standard PMI WBS term; it is informal language sometimes used in scheduling tools.
- *Why D is incorrect:* Milestones are significant points with zero duration; they are schedule artifacts, not WBS decomposition levels.

## Question 2

Which of the following best defines a Work Package in project scope management?

- A) The lowest-level WBS component representing a unit of work that can be assigned, estimated, and controlled by a single person or team.
- B) A high-level summary of all deliverables produced during the Initiating Process Group.
- C) A legal contract signed between the project sponsor and the performing organization before work begins.
- D) A visual diagram showing the sequence of activities from project start to completion.

Correct Answer: A) The lowest-level WBS component representing a unit of work that can be assigned, estimated, and controlled by a single person or team.

Distractor Analysis:

- *Why A is correct:* Work packages are the actionable building blocks of the WBS. They are the point at which cost and schedule estimates are developed, and each is small enough to be reliably tracked.
- *Why B is incorrect:* A high-level summary of deliverables describes the project scope statement or charter, not a work package.
- *Why C is incorrect:* A legal contract is a procurement document, not a WBS component.
- *Why D is incorrect:* A visual diagram showing activity sequence describes a network diagram or schedule, not a work package.

## Question 3

A developer on a software project starts adding extra reporting features that were never in the approved scope, claiming stakeholders "mentioned they would be nice to have." Which term best describes this situation?

- A) Fast-tracking
- B) Gold plating
- C) Scope creep
- D) Risk acceptance

Correct Answer: B) Gold plating — the project team voluntarily adding features beyond what was requested, without authorization.

Distractor Analysis:

- *Why B is correct:* Gold plating is when the team adds extras on their own initiative, often with good intentions, but without going through change control. The developer here is acting on an informal comment, not an approved change request.
- *Why A is incorrect:* Fast-tracking is a schedule compression technique where overlapping tasks are performed in parallel; it has nothing to do with unauthorized feature additions.
- *Why C is incorrect:* Scope creep typically involves informal requests from outside the team (a stakeholder or client pushing for additions). Here the developer is taking initiative internally — the classic gold-plating scenario.
- *Why D is incorrect:* Risk acceptance is a risk response strategy; it is completely unrelated to unauthorized scope additions.

## Question 4

The project team has completed the WBS for a network infrastructure upgrade. The project manager discovers that server decommissioning activities were accidentally omitted. Which WBS principle does this violation break?

- A) The decomposition rule
- B) The 100% Rule
- C) The work package ownership rule
- D) The scope baseline rule

Correct Answer: B) The 100% Rule requires that the WBS include 100% of the project scope — every deliverable and outcome — with nothing missing.

Distractor Analysis:

- *Why B is correct:* Omitting server decommissioning means the WBS does not capture 100% of the work. Missing WBS elements mean missing cost estimates, missing schedule activities, and invisible deliverables.
- *Why A is incorrect:* The decomposition rule addresses how far down to break work packages, not whether scope is complete.
- *Why C is incorrect:* The work package ownership rule addresses assignment of responsibility; it is not about scope completeness.
- *Why D is incorrect:* The scope baseline is a document set; the issue here is about the content of the WBS being incomplete, which is specifically the 100% Rule.

## Question 5

A project manager wants to add information to the WBS for each element, including descriptions of work, acceptance criteria, and the responsible team. What document should the PM create?

- A) Project Charter
- B) Communications Management Plan
- C) WBS Dictionary
- D) Risk Register

Correct Answer: C) The WBS Dictionary is a companion document to the WBS that provides detailed descriptions, acceptance criteria, owners, and other information for each WBS element.

Distractor Analysis:

- *Why C is correct:* The WBS Dictionary transforms the WBS from a visual outline into a fully documented scope reference. It is part of the Scope Baseline alongside the WBS and Scope Statement.
- *Why A is incorrect:* The Project Charter is an authorization document created during Initiating; it does not contain detailed decomposition or acceptance criteria for individual work packages.
- *Why B is incorrect:* The Communications Management Plan defines how project information will be distributed; it does not define scope elements or acceptance criteria.
- *Why D is incorrect:* The Risk Register identifies and tracks risks; it contains no information about WBS element descriptions or acceptance criteria.

## Question 6

Which three documents together form the Scope Baseline?

- A) Project Charter, Risk Register, and WBS
- B) Project Scope Statement, WBS, and WBS Dictionary
- C) Requirements Documentation, WBS, and Project Management Plan
- D) Scope Statement, Stakeholder Register, and Communications Plan

Correct Answer: B) The Scope Baseline consists of the Project Scope Statement, the WBS, and the WBS Dictionary — all three together.

Distractor Analysis:

- *Why B is correct:* PMI defines the Scope Baseline as exactly these three documents. The Scope Statement defines what will be delivered; the WBS decomposes it; the WBS Dictionary details each element. All scope change requests are measured against this baseline.
- *Why A is incorrect:* The Project Charter is an Initiating document, not part of the Scope Baseline. The Risk Register is a risk management document, not a scope document.
- *Why C is incorrect:* Requirements Documentation and the Project Management Plan are inputs to scope planning, not components of the Scope Baseline itself.
- *Why D is incorrect:* The Stakeholder Register records stakeholder information and the Communications Plan defines communication channels — neither is part of the Scope Baseline.

## Question 7

A project sponsor emails the project manager asking to add a user analytics dashboard to a payroll system that is currently in development. The PM has not seen a formal change request. What should the PM do?

- A) Tell the developer to add it immediately since the sponsor requested it
- B) Add it to the WBS on the PM's own authority since the sponsor requested it
- C) Acknowledge the request, explain the change control process, and ask the sponsor to submit a formal change request
- D) Ignore the request because it did not come through the proper channel

Correct Answer: C) Acknowledge the request, explain the change control process, and ask the sponsor to submit a formal change request.

Distractor Analysis:

- *Why C is correct:* Even when the sponsor requests a change, it must go through the formal change control process. The PM acknowledges the request professionally, explains the process, and facilitates the proper submission — without simply refusing or blindly complying.
- *Why A is incorrect:* Implementing scope changes without a change request — even sponsor-initiated ones — creates uncontrolled impacts on schedule, cost, and quality. This is scope creep regardless of who asked.
- *Why B is incorrect:* The PM does not have unilateral authority to expand scope. Adding deliverables to the WBS without an approved change request violates the Scope Baseline.
- *Why D is incorrect:* Ignoring a sponsor request is unprofessional and counterproductive. The correct approach is to redirect the request through proper channels, not dismiss it.

## Question 8

The Validate Scope process results in which primary output?

- A) Approved change requests
- B) Accepted deliverables
- C) Updated risk register
- D) Revised project schedule

Correct Answer: B) Accepted deliverables — formal acknowledgment from the customer or sponsor that completed deliverables meet the acceptance criteria.

Distractor Analysis:

- *Why B is correct:* Validate Scope is performed when deliverables are complete. The customer or sponsor inspects the work against acceptance criteria and formally accepts (or rejects) it. Accepted deliverables are the primary output.
- *Why A is incorrect:* Approved change requests are outputs of Integrated Change Control, not Validate Scope. Validate Scope may generate change requests if defects are found, but approved changes come from the CCB.
- *Why C is incorrect:* Risk register updates occur in risk monitoring processes, not in Validate Scope. Scope validation is about deliverable acceptance, not risk tracking.
- *Why D is incorrect:* The project schedule is managed through Schedule Management processes. A scope validation meeting does not revise the schedule directly.

## Question 9

A project manager is reviewing the WBS and notices that several entries are written as: "Install network switches," "Configure firewalls," and "Train help desk staff." What is the problem with these WBS entries?

- A) They are too detailed to be Level 2 WBS entries
- B) They are written as tasks (verbs), not as deliverables (noun phrases) — violating WBS structure rules
- C) They belong in the Risk Register, not the WBS
- D) They should be added to the Project Charter instead

Correct Answer: B) They are written as tasks (verbs), not as deliverables (noun phrases) — violating WBS structure rules.

Distractor Analysis:

- *Why B is correct:* A properly built WBS uses deliverable-oriented noun phrases ("Network switch installation," "Configured firewall," "Help desk training program"). Verb-based entries describe activities, which belong in the activity list created during Schedule Management, not the WBS.
- *Why A is incorrect:* The issue is not about decomposition level — it is about the fundamental nature of WBS entries. A WBS can have these concepts at any level as long as they are phrased as deliverables.
- *Why C is incorrect:* The Risk Register tracks potential adverse events. "Install network switches" is not a risk — it is a scope element described incorrectly.
- *Why D is incorrect:* The Project Charter provides high-level authorization information, not decomposed scope elements. Moving these to the charter would not fix the structural problem.

## Question 10

A requirements traceability matrix (RTM) connects which two things?

- A) Risk events to risk owners and mitigation strategies
- B) Project requirements to the WBS elements and tests that validate them
- C) Stakeholders to the communication channels assigned to them
- D) Work packages to the team members responsible for completing them

Correct Answer: B) Project requirements to the WBS elements and tests that validate them.

Distractor Analysis:

- *Why B is correct:* The RTM is a traceability tool that links each requirement from its source through the WBS element that delivers it to the test case that validates it. It ensures no requirement is dropped or delivered unvalidated.
- *Why A is incorrect:* Connecting risk events to owners and mitigations describes the Risk Register, not an RTM.
- *Why C is incorrect:* Connecting stakeholders to communication channels describes the Communications Management Plan or the Stakeholder Register.
- *Why D is incorrect:* Connecting work packages to responsible team members describes a responsibility assignment matrix (RAM) or RACI chart, not an RTM.
