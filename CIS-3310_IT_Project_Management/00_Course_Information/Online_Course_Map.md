# Online Course Map: CIS-3310 IT Project Management
**Texas Wesleyan University – 16-Week Semester**
**Target Certification:** CompTIA Project+ (PK0-005)

---

## How to Read This Map

This course map shows the complete 16-week learning journey. Each module builds on the previous one. The **Lab Thread** column shows how hands-on labs across the semester connect into a single cumulative IT project simulation portfolio. The **Exam Domain Coverage** column shows which CompTIA Project+ PK0-005 exam domain each module primarily addresses.

## Week-by-Week Module Breakdown

| Week | Module | Topic | Key Concepts | Lab Activity | Exam Domain |
|---|---|---|---|---|---|
| 1 | Module 01 | Introduction to Project Management and PMI Framework | Project vs. operations, triple constraint, lifecycle phases, PM role, stakeholder overview | Draft a project charter template; identify constraints for an IT upgrade | Domain 1: Project Management Concepts |
| 2 | Module 02 | Project Lifecycle and Process Groups | Project charter, business case, project objectives, stakeholder register, PMI 5 process groups | Write a project charter for a server migration; build a stakeholder register | Domain 2: Project Life Cycle Phases (Initiating) |
| 3 | Module 03 | Scope Management – WBS and Scope Statement | WBS, decomposition, work packages, scope creep, WBS dictionary, 100% Rule | Decompose a software project into 3-level WBS; write WBS dictionary entries | Domain 2: Project Life Cycle Phases (Planning) |
| 4 | Module 04 | Schedule Management – Gantt Charts and CPM | Activity sequencing, dependency types (FS/SS/FF/SF), Gantt charts, lead and lag, milestones | Create an activity list; build a Gantt chart with FS dependencies | Domain 2: Project Life Cycle Phases (Planning) |
| 5 | Module 05 | Cost Management – Budgeting and EVM | Network diagram, forward/backward pass, float/slack, critical path, EVM formulas | Calculate CPM for a 6-activity network; identify zero-float critical path | Domain 1: Project Management Concepts (EVM) |
| 6 | Module 06 | Quality Management | Analogous/parametric/bottom-up estimating, contingency reserves, cost baseline | Parametric cost estimate; bottom-up budget rollup; determine reserve levels | Domain 2: Project Life Cycle Phases (Planning) |
| 7 | Module 07 | Resource Management and Team Building | Quality planning, QA vs. QC, Pareto charts, check sheets, Tuckman's model | Quality management plan; Pareto chart analysis; check sheet template | Domain 1: Project Management Concepts (Quality) |
| 8 | Module 08 | Communications Management | Resource loading, resource leveling, RACI matrix, resource conflicts, communication channels | RACI matrix; resolve over-allocation conflict; communication channel calculations | Domain 4: Communication and Stakeholder Engagement |
| 9 | Module 09 | Risk Management – Identification and Response | Communication channels formula, communication plan parameters, stakeholder registers, Power/Interest grid | Communication matrix; stakeholder register; channel calculation scenarios | Domain 4: Communication and Stakeholder Engagement |
| 10 | Module 10 | Procurement Management | Risk register, qualitative analysis (P×I matrix), risk response strategies (Avoid/Transfer/Mitigate/Accept), risk triggers | Build a risk register; risk score ranking; mitigation workflow for top 3 risks | Domain 1: Project Management Concepts (Risk) |
| 11 | Module 11 | Stakeholder Management | RFP, contract types (FFP/CR/T&M), SLA terms, vendor management, Power/Interest engagement grid | Review a sample SLA; compare contract scenarios; draft contract parameters | Domain 3: Project Execution (Procurement) |
| 12 | Module 12 | Agile and Scrum Methodologies | Agile vs. Waterfall, sprint cycles, Kanban boards, velocity metrics, Scrum roles/ceremonies/artifacts, adaptive planning | Sprint planning for a mobile app; Kanban board simulation; product backlog creation | Domain 1: Project Management Concepts (Agile) |
| 13 | Module 13 | IT Project Integration | EVM (PV/AC/EV/CV/SV/CPI/SPI/EAC), S-curves, directing project work, Executing process group | Calculate CV, SV, CPI, SPI, EAC for a given scenario; create an S-curve | Domain 2: Project Life Cycle Phases (Executing) |
| 14 | Module 14 | Project Closing and Lessons Learned | Change requests, CCB, configuration management, impact assessment, change control process | Draft a change request form; impact assessment; CCB approval flowchart | Domain 2: Project Life Cycle Phases (M&C) |
| 15 | Module 15 | Portfolio and Program Management | Administrative closure, project handoff, contract closeout, lessons learned, post-mortem reports, portfolio/program/project hierarchy | Lessons learned survey; acceptance sign-off document; post-mortem outline | Domain 2: Project Life Cycle Phases (Closing) |
| 16 | Module 16 | Final Exam Prep & Project+ Certification | Full domain review, formula drill, exam strategies, timed practice exam, concept mapping | 90-question timed practice exam; formula drill; knowledge area concept map | All Domains (Comprehensive Review) |

## Recommended Study Schedule

For students targeting the **CompTIA Project+ (PK0-005)** certification alongside the course:

- **Weeks 1–4:** Focus on PMI fundamentals, process groups, scope, and schedule concepts. These are Domain 2 (30%) topics.
- **Weeks 5–8:** Focus on cost/EVM formulas, quality, and resource management. These are Domain 1 (33%) topics. Begin formula drills.
- **Weeks 9–12:** Focus on risk management, procurement, stakeholder, and Agile. Complete a first practice exam to identify weak domains.
- **Weeks 13–15:** Final review pass. Focus on EVM calculations, CPM, Agile/Scrum roles and ceremonies, and change control.
- **Week 16:** Timed full practice exam. Register for the official CompTIA Project+ exam within 30–60 days of course completion.

| Certification | After CIS-3310 |
|---|---|

| PMI CAPM | Strongly prepared — requires 23 hours documented PM education (this course qualifies) + CAPM application |
| PMI PMP | Long-term goal — requires 36 months PM experience (or 24 months with degree); this course builds the knowledge foundation |
