# Quiz: Module 02 - Project Lifecycle and Process Groups
## Course: CIS-3310_IT_Project_Management (CompTIA Project+ / PMI CAPM)

**Question 1**
Which document authorizes the formal existence of a project and gives the project manager authority to apply resources?
*   A) Project Scope Statement
*   B) Project Charter
*   C) Work Breakdown Structure
*   D) Statement of Work (SOW)
*   **Correct Answer:** B) The Project Charter is signed by the project sponsor during the Initiating process group to formally authorize the project and grant the PM authority to commit resources.
*   **Distractor Analysis:**
    *   *Why B is correct:* The Project Charter is the definitive authorization document in PMI methodology. No other document serves this specific function.
    *   *Why A is incorrect:* The Scope Statement defines the project's deliverables and boundaries—it is a Planning output, not an authorization document.
    *   *Why C is incorrect:* The WBS is a scope decomposition tool created in the Planning process group; it defines work, not authority.
    *   *Why D is incorrect:* A Statement of Work describes the work to be performed (often in a procurement context) but does not formally authorize a project or grant PM authority over organizational resources.

**Question 2**
Which of the following best defines a **Stakeholder Register** in project management?
*   A) A project document that records all identified stakeholders, including their roles, interests, influence levels, and engagement strategies.
*   B) A financial spreadsheet used to track project expenditures against the approved budget baseline.
*   C) A schedule artifact that lists all project activities, their durations, and assigned resources.
*   D) A contract document signed by vendors before they begin delivering goods or services to the project.
*   **Correct Answer:** A) A project document that records all identified stakeholders, including their roles, interests, influence levels, and engagement strategies.
*   **Distractor Analysis:**
    *   *Why A is correct:* The Stakeholder Register is a living document created during Initiating and updated throughout the project. It captures who the stakeholders are, what they want, and how the PM should engage them.
    *   *Why B is incorrect:* Tracking expenditures against a budget describes the cost management plan or a budget baseline—a different document entirely.
    *   *Why C is incorrect:* Listing activities, durations, and resources describes an activity list or resource management plan, not a stakeholder register.
    *   *Why D is incorrect:* A vendor agreement is a contract or purchase order, part of Procurement Management, not stakeholder documentation.

**Question 3**
A project sponsor tells the project manager to begin work immediately on a new software deployment before the project charter has been approved. What is the best response?
*   A) Begin work immediately to meet the sponsor's deadline; the charter can be signed later.
*   B) Politely explain that formal project authorization via a signed charter is required before committing resources, and request expedited approval.
*   C) Escalate the situation to senior IT leadership and pause all communication with the sponsor.
*   D) Start work but keep no records until the charter is signed to avoid liability.
*   **Correct Answer:** B) Politely explain that formal project authorization via a signed charter is required before committing resources, and request expedited approval.
*   **Distractor Analysis:**
    *   *Why B is correct:* PMI methodology requires a signed charter before work begins. Beginning work without authorization exposes the organization to uncontrolled costs, undefined scope, and legal risk. The correct approach is to expedite approval, not bypass it.
    *   *Why A is incorrect:* Beginning unauthorized work is a recognized PM antipattern. It creates scope and budget accountability problems.
    *   *Why C is incorrect:* Escalating immediately and halting communication is an overreaction. The PM should first discuss the requirement for authorization with the sponsor directly.
    *   *Why D is incorrect:* Keeping no records creates serious governance and audit problems; this approach is never recommended.

**Question 4**
During which PMI Process Group is the Project Management Plan created?
*   A) Initiating
*   B) Planning
*   C) Executing
*   D) Closing
*   **Correct Answer:** B) The Project Management Plan is the primary output of the Planning process group and serves as the guide for executing and controlling the project.
*   **Distractor Analysis:**
    *   *Why B is correct:* Planning produces the Project Management Plan, which integrates subsidiary plans for scope, schedule, cost, quality, resources, communications, risk, procurement, and stakeholders.
    *   *Why A is incorrect:* Initiating produces the Project Charter and Stakeholder Register, not the detailed management plan.
    *   *Why C is incorrect:* Executing carries out the work defined in the plan; it does not create the plan itself.
    *   *Why D is incorrect:* Closing formalizes project completion, archives documents, and releases resources; it does not create a management plan.

**Question 5**
A business analyst completes a cost-benefit analysis recommending a cloud migration project based on projected 3-year savings. Which project initiation document does this analysis most directly support?
*   A) Risk Register
*   B) Project Schedule
*   C) Business Case
*   D) Change Request Form
*   **Correct Answer:** C) A Business Case justifies the investment in a project by documenting expected benefits, costs, risks, and the recommended option.
*   **Distractor Analysis:**
    *   *Why C is correct:* The Business Case is prepared before or during project initiation to justify why the project should be approved and funded. A cost-benefit analysis is a core component of the Business Case.
    *   *Why A is incorrect:* A Risk Register identifies and analyzes risks after the project is approved; it does not justify the initial investment.
    *   *Why B is incorrect:* A Project Schedule defines the timeline for approved project work; it is created during Planning, not as a justification for starting the project.
    *   *Why D is incorrect:* A Change Request Form is used to request modifications to an already-approved and in-progress project, not to propose a new project.
