## Scenario Background

DataBridge Technologies (a fictional company) is implementing a new enterprise data warehouse for a retail client. The project team includes the following people:

- Sandra Chen — Project Manager
- Priya Kapoor — Database Architect (Technical Lead)
- James Okonkwo — ETL Developer
- Maria Salazar — Business Analyst
- Derek Williams — QA Engineer
- Linda Park — IT Operations Manager (functional manager; not dedicated to project)
- Tom Harrington — Project Sponsor (VP of IT, retail client)
- Ananya Patel — Change Management Lead

The project includes the following key tasks and deliverables:

1. Approve project charter
2. Gather business requirements
3. Design data warehouse schema
4. Develop ETL pipelines
5. Conduct data quality testing
6. Train end users
7. Approve go-live
8. Complete project closure documentation
