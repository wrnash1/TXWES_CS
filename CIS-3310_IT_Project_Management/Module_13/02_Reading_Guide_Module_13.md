### Introduction
Welcome to **Module 13 - IT Project Integration**! Project Integration Management is the knowledge area that coordinates and unifies all other knowledge areas into a cohesive whole. The Project Manager is ultimately responsible for ensuring that all the pieces—scope, schedule, cost, quality, resources, communications, risk, procurement, and stakeholder engagement—work together and support the project objectives. This module covers the integration tools and techniques used during project execution and monitoring, with a focus on Earned Value Management (EVM) as the primary performance measurement framework.

EVM is one of the most calculation-dense topics on both Project+ and CAPM. Plan to spend additional study time on the formulas before the quiz.

### 1. High-Yield Glossary
Review these essential definitions carefully. The certification exam expects you to know these concepts inside and out:

*   **Earned Value Management (EVM)**: A project performance measurement technique that integrates scope, schedule, and cost data to objectively assess project health at any point in time. EVM compares the value of work actually completed (Earned Value) to the value of work that was planned to be done (Planned Value) and to what was actually spent (Actual Cost). The result reveals whether the project is ahead or behind schedule and over or under budget.
*   **Planned Value (PV)**: The authorized budget assigned to scheduled work—the amount of value the project was supposed to have earned by the current date according to the project plan. PV is sometimes called the Budgeted Cost of Work Scheduled (BCWS) in older terminology.
*   **Actual Cost (AC)**: The total cost actually incurred in accomplishing the work performed during a given time period. AC is what has been spent, regardless of the value of the work that was completed. Also called Actual Cost of Work Performed (ACWP).
*   **Earned Value (EV)**: The measure of work performed expressed in terms of the budget authorized for that work—the value of the work that has actually been completed, expressed as a dollar figure. EV = % complete × BAC. Also called Budgeted Cost of Work Performed (BCWP).
*   **Cost Variance (CV) / Schedule Variance (SV) / CPI / SPI**: The four key EVM performance metrics. CV = EV - AC (negative = over budget). SV = EV - PV (negative = behind schedule). CPI = EV/AC (below 1.0 = over budget). SPI = EV/PV (below 1.0 = behind schedule). CPI and SPI above 1.0 are favorable; below 1.0 are unfavorable.

### 2. Certification Exam Tips
*   **Project+ Tip – EVM Formula Memory Device**: Use the "EV is always first" rule. CV = EV - AC (EV first). SV = EV - PV (EV first). CPI = EV/AC (EV on top). SPI = EV/PV (EV on top). This pattern makes the formulas easy to reconstruct under exam pressure.
*   **CAPM Tip – EAC Formulas**: The CAPM tests multiple EAC (Estimate at Completion) formulas. EAC = BAC/CPI assumes current efficiency continues. EAC = AC + BAC - EV assumes the remaining work will be done at the original budgeted rate. Know which formula is appropriate based on the scenario context.
*   **Scenario Trap**: A project with SPI = 1.15 and CPI = 0.75 is ahead of schedule but over budget. A question that asks "is the project doing well?" requires you to evaluate both indexes separately—do not let a positive SPI distract from a severely negative CPI. Both values matter.
*   **Study Resource**: For a complete EVM formula reference sheet and worked calculation examples, search [YouTube: Earned Value Management EVM Formulas PMP CAPM Tutorial](https://www.youtube.com/results?search_query=earned+value+management+EVM+formulas+PMP+CAPM+worked+examples). Download a formula sheet and practice with it until all calculations are automatic.

### Lab & Command Integration
In this week's hands-on lab, you will perform the following steps to apply these concepts:
*   **Calculate Cost Variance (CV) and Schedule Variance (SV)**: Given a project scenario with PV = $80,000, EV = $72,000, and AC = $85,000, calculate CV and SV and state in plain language whether the project is over/under budget and ahead/behind schedule.
*   **Determine project budget health using CPI and SPI indexes**: Using the same data, calculate CPI and SPI, interpret each value, and forecast the Estimate at Completion (EAC) using EAC = BAC/CPI (BAC = $200,000).
*   **Analyze performance charts**: Create a simple S-curve chart (using a spreadsheet) plotting PV, EV, and AC over four time periods using provided data, and write a two-sentence interpretation of what the chart reveals about project performance.
