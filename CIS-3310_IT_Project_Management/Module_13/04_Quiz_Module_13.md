**Question 1**
A project has a Cost Performance Index (CPI) of 0.85 and a Schedule Performance Index (SPI) of 1.10. What is the project's current status?
*   A) Under budget and ahead of schedule
*   B) Over budget and behind schedule
*   C) Over budget and ahead of schedule
*   D) Under budget and behind schedule
*   **Correct Answer:** C) CPI = 0.85 means the project is spending more than the value earned (over budget). SPI = 1.10 means more work has been completed than was planned for this date (ahead of schedule).
*   **Distractor Analysis:**
    *   *Why C is correct:* CPI < 1.0 indicates over budget (spending more than earned); SPI > 1.0 indicates ahead of schedule (completing more work than planned). These two can occur simultaneously.
    *   *Why A is incorrect:* Under budget requires CPI > 1.0. A CPI of 0.85 is below 1.0, indicating an over-budget condition.
    *   *Why B is incorrect:* Behind schedule requires SPI < 1.0. An SPI of 1.10 is above 1.0, indicating an ahead-of-schedule condition.
    *   *Why D is incorrect:* Under budget requires CPI > 1.0 (not 0.85). This answer gets the schedule interpretation correct (behind = SPI < 1.0) but inverts the CPI interpretation.

**Question 2**
Which of the following best defines **Earned Value (EV)** in project performance measurement?
*   A) The measure of work actually performed, expressed as the budgeted value of that work (EV = % complete × BAC).
*   B) The actual total cost incurred to complete the work performed during a given time period.
*   C) The authorized budget assigned to the work that was scheduled to be done by the current date.
*   D) The projected total cost of the project if current spending efficiency continues to the end.
*   **Correct Answer:** A) Earned Value (EV) is the budgeted value of the work actually completed—it translates physical progress (% complete) into a dollar figure for performance comparison.
*   **Distractor Analysis:**
    *   *Why A is correct:* EV = % Complete × BAC. It answers "how much value have we actually produced?" This is distinct from what was planned (PV) and what was spent (AC). EV is the pivot point for all EVM calculations.
    *   *Why B is incorrect:* The actual total cost incurred describes Actual Cost (AC)—how much money has actually been spent, regardless of how much work was completed.
    *   *Why C is incorrect:* The authorized budget for scheduled work describes Planned Value (PV)—the baseline expectation of value earned by the current date.
    *   *Why D is incorrect:* The projected total cost at current efficiency describes Estimate at Completion (EAC = BAC/CPI)—a forecast output derived from EVM data, not EV itself.

**Question 3**
A project has a Budget at Completion (BAC) of $300,000. After 6 months, the project team reports that 40% of the work is complete, and $135,000 has been spent. What is the Cost Variance (CV)?
*   A) CV = +$15,000 (under budget)
*   B) CV = −$15,000 (over budget)
*   C) CV = −$15,000 (ahead of schedule)
*   D) CV = +$15,000 (behind schedule)
*   **Correct Answer:** B) EV = 40% × $300,000 = $120,000. CV = EV − AC = $120,000 − $135,000 = −$15,000. Negative CV means over budget.
*   **Distractor Analysis:**
    *   *Why B is correct:* CV = EV - AC = $120,000 - $135,000 = -$15,000. The project has spent $15,000 more than the value of work it has completed. Negative CV always means over budget.
    *   *Why A is incorrect:* A positive $15,000 would require EV > AC ($120,000 > $135,000), which is false. The project has spent more than it has earned.
    *   *Why C is incorrect:* CV measures cost performance, not schedule performance. "Ahead of schedule" describes SPI, not CV. The sign on CV indicates budget status only.
    *   *Why D is incorrect:* A +$15,000 result would require EV > AC, and "behind schedule" would describe a negative SV, not CV. This answer confuses cost and schedule variance formulas.

**Question 4**
A project manager is preparing a performance report showing how the project is performing relative to the cost and schedule baselines. Which project management tool presents PV, EV, and AC on a single chart over time to visualize project trends?
*   A) Network Diagram (PDM)
*   B) S-Curve (EVM Performance Chart)
*   C) Risk Matrix
*   D) Gantt Chart
*   **Correct Answer:** B) An S-Curve is a standard EVM visual that plots PV (the baseline), EV (value earned), and AC (actual costs) over time, making it easy to see budget and schedule variances at a glance.
*   **Distractor Analysis:**
    *   *Why B is correct:* The S-Curve is named for the characteristic S-shape of cumulative planned value (slow start, fast middle, slow finish). Plotting PV, EV, and AC on the same S-Curve instantly reveals cost and schedule variance visually.
    *   *Why A is incorrect:* A Network Diagram (PDM) shows activity dependencies and the critical path; it does not display cost or EVM metrics.
    *   *Why C is incorrect:* A Risk Matrix (Probability × Impact grid) is used to prioritize risks; it is not an EVM visualization tool.
    *   *Why D is incorrect:* A Gantt chart shows the schedule (task durations and timelines); while it can display progress, it does not natively plot EV, PV, and AC on a single chart the way an S-Curve does.

**Question 5**
During an IT infrastructure rollout, the project manager needs to direct and manage the execution of the work according to the Project Management Plan. Which PMI process group does this activity belong to?
*   A) Initiating
*   B) Planning
*   C) Executing
*   D) Monitoring and Controlling
*   **Correct Answer:** C) Directing and managing project work—actually performing the tasks described in the plan—is the primary activity of the Executing process group.
*   **Distractor Analysis:**
    *   *Why C is correct:* The Executing process group is where the project work is carried out according to the plan. The PM directs team members, manages vendors, ensures quality, and implements approved changes during execution.
    *   *Why A is incorrect:* Initiating authorizes the project and identifies stakeholders—no work is performed during initiation.
    *   *Why B is incorrect:* Planning develops the Project Management Plan and all subsidiary plans; it defines what work will be done but does not do the work itself.
    *   *Why D is incorrect:* Monitoring and Controlling tracks progress against the plan, identifies variances, and takes corrective action—it runs in parallel with executing but is distinct from the act of doing the work.
