# Quiz: Module 02 — Security Strategy and Business Alignment

## Course: CIS-4315 Cyber Governance, Risk, and Compliance

## Texas Wesleyan University | Professor Nash

## CISM Domain Alignment: Domain 1 — Information Security Governance

---

### Question 1

A newly appointed CISO at a healthcare organization is asked to develop the company's first formal information security strategy. What should the CISO do first?

- A) Select a security framework such as NIST CSF and begin mapping controls
- B) Analyze the business objectives, threat landscape, regulatory environment, and current security posture
- C) Draft an information security policy and submit it to the board for approval
- D) Conduct a penetration test to identify the most critical vulnerabilities

Correct Answer: B — The CISO must understand the business context before developing any strategy. Selecting frameworks, writing policies, or running technical assessments before this analysis produces a strategy that is misaligned with organizational needs.

Distractor Analysis: A is incorrect because framework selection comes after business context analysis; selecting a framework first creates a solution looking for a problem. C is incorrect because policy development follows strategy; a policy without a strategic foundation lacks coherent direction. D is incorrect because penetration testing is a tactical assessment activity that may inform strategy but is not the first step.

### Question 2

A CISO presents the security strategy to the board of directors. Which approach best demonstrates effective executive communication of security strategy?

- A) Providing a 60-page technical report documenting all security gaps and remediation steps
- B) Presenting a list of CVEs discovered during the last vulnerability scan along with severity ratings
- C) Mapping the top three strategic security investments to specific business objectives and quantifying the risk reduction each delivers
- D) Describing the technical architecture of the proposed SIEM platform in detail

Correct Answer: C — Executive communication of security strategy requires connecting investments to business objectives and risk reduction in terms executives can act on. Technical reports, CVE lists, and architecture details are not board-level governance communication.

Distractor Analysis: A is incorrect because boards require concise, business-language summaries — not 60-page technical documents. B is incorrect because CVE severity ratings are operational metrics, not strategic governance communication. D is incorrect because technical architecture is a management-level detail that is not useful to a board governance discussion.

### Question 3

An organization's security team maintains a detailed security risk register that is never shared with the enterprise risk management function. What is the primary governance problem this creates?

- A) The security team may miscategorize risk severity levels without expert guidance
- B) Security risks are invisible to the enterprise risk governance process, preventing appropriate prioritization and resource allocation
- C) The security risk register may contain duplicate entries if not integrated with other systems
- D) Regulatory examiners will require a combined risk register format

Correct Answer: B — When security risks are maintained in isolation from the enterprise risk management program, they are invisible to the decision-makers who allocate resources and prioritize organizational risk responses.

Distractor Analysis: A is incorrect because the primary governance problem is visibility and integration, not accuracy. C is incorrect because duplicate entries are a data management concern, not a governance problem. D is incorrect because the governance principle at stake is about organizational decision-making, not regulatory format requirements.

### Question 4

A security manager is developing a three-year security roadmap. Two initiatives — implementing multi-factor authentication and deploying an advanced threat hunting platform — are competing for Year 1 placement. Which criterion should drive the prioritization decision?

- A) The initiative with the lower implementation cost should be placed in Year 1
- B) The initiative recommended by the organization's security technology vendor should be placed first
- C) The initiative that addresses the highest-priority risk relative to the organization's business objectives and current threat exposure should be placed first
- D) The initiative that the security team finds technically more interesting should be placed first

Correct Answer: C — Security roadmap prioritization must be driven by risk reduction value relative to the organization's business objectives and threat exposure — not by cost, vendor preference, or internal interest.

Distractor Analysis: A is incorrect because a low-cost initiative addressing a low-priority risk is less valuable than a higher-cost initiative closing a critical gap. B is incorrect because vendor recommendations reflect commercial interest, not organizational risk analysis. D is incorrect because technical interest has no place in governance-level security strategy decisions.

### Question 5

Which of the following most accurately describes the relationship between an organization's risk appetite and its information security strategy?

- A) The security strategy sets the risk appetite, which the board then reviews and approves
- B) Risk appetite and security strategy are independent — security strategy does not need to reference risk appetite
- C) The security strategy must be designed and scoped to operate within the risk appetite established by the board
- D) Risk appetite applies only to financial risk and is not relevant to information security programs

Correct Answer: C — The board sets risk appetite as a governance-level policy. The CISO's security strategy must be calibrated to ensure the security program operates within those boundaries.

Distractor Analysis: A is incorrect because it reverses the correct relationship; the board sets risk appetite and the CISO develops strategy within it. B is incorrect because security strategy that ignores risk appetite is not aligned with governance direction. D is incorrect because risk appetite applies to all categories of organizational risk, including information security.

### Question 6

A financial institution is planning to acquire a smaller regional bank. Which security strategy consideration is most important during the acquisition planning phase?

- A) Immediately transferring the acquired bank's security budget to the parent company's security program
- B) Conducting a security due diligence assessment of the target organization's posture, controls, and risk exposures before closing
- C) Requiring the acquired bank to adopt all parent company security policies within 30 days of acquisition
- D) Replacing the acquired bank's security team with staff from the parent company

Correct Answer: B — Security due diligence during acquisition planning allows the acquiring organization to understand inherited risks before closing and factor them into both the acquisition price and the post-acquisition integration plan.

Distractor Analysis: A is incorrect because budget transfers are a management action, not a strategic security consideration during acquisition planning. C is incorrect because forcing immediate policy adoption without understanding the acquired entity's environment is operationally disruptive and strategically premature. D is incorrect because personnel decisions are HR matters and do not address the fundamental security risk question raised by the acquisition.

### Question 7

A security strategy document contains vision, objectives, current state assessment, and a roadmap, but no resource requirements section. What is the most significant consequence of this omission?

- A) The document cannot be submitted for ISO 27001 certification review
- B) The security strategy cannot be connected to the organization's financial planning and budget processes, reducing the likelihood it will be funded and executed
- C) The roadmap initiatives will automatically be assigned to the IT department
- D) The steering committee will be required to approve each initiative separately

Correct Answer: B — A security strategy without resource requirements cannot be translated into budget requests. Without budget, the roadmap remains aspirational and disconnected from organizational financial planning cycles.

Distractor Analysis: A is incorrect because ISO 27001 does not require a specific strategy document format. C is incorrect because responsibility assignment is a governance decision unrelated to the resource requirements section. D is incorrect because steering committee approval processes are not determined by whether a strategy document includes a resource section.

### Question 8

A CISO wants to demonstrate that the security program delivers business value, not just risk reduction. Which of the following best illustrates security delivering business value?

- A) The security team patched 98 percent of critical vulnerabilities within the SLA window last quarter
- B) The implementation of a compliant security framework enabled the organization to win a government contract that required NIST SP 800-171 compliance
- C) The security operations center detected and contained a phishing campaign before any accounts were compromised
- D) The organization's firewall blocked 14 million unauthorized connection attempts last month

Correct Answer: B — Business value means security enables the organization to pursue and achieve business objectives it could not otherwise achieve. Winning a contract that required security compliance is a direct example of security delivering business enablement value.

Distractor Analysis: A is incorrect because patch SLA performance measures security efficiency but does not demonstrate business value the board connects to business outcomes. C is incorrect because detecting a phishing campaign demonstrates risk reduction, not business enablement. D is incorrect because firewall block counts are technical operational statistics with no direct connection to business outcomes.

### Question 9

A security manager reviewing the organization's five-year business plan finds that the company plans to enter the European Union market within two years. What should the security strategy include in response?

- A) No change — business expansion decisions do not create security program requirements
- B) A Year 2 initiative to implement GDPR compliance controls and privacy-by-design requirements ahead of the EU market entry
- C) A request to delay the EU expansion until the current security program is fully optimized
- D) A recommendation that EU operations use a separate security program managed locally

Correct Answer: B — Security strategy must anticipate business moves and include initiatives that address the security and compliance requirements those moves create. GDPR compliance is a legal requirement for processing EU resident data.

Distractor Analysis: A is incorrect because business expansion into regulated markets creates concrete and legally mandated security requirements. C is incorrect because security managers do not have the authority or appropriate governance role to recommend delaying business strategy decisions. D is incorrect because separate security programs for different regions creates governance fragmentation and inconsistent risk management.

### Question 10

Which of the following best describes the purpose of a current state assessment in security strategy development?

- A) To document all vendor contracts currently in place for security tools and services
- B) To establish an honest baseline of existing capabilities, gaps, and risk exposures from which strategy priorities can be determined
- C) To produce a formal compliance report for submission to regulatory examiners
- D) To justify the existing security team's budget allocation for the coming fiscal year

Correct Answer: B — The current state assessment establishes the starting point for strategy development. Without an honest baseline, it is impossible to identify the most important gaps to close or to sequence strategic initiatives rationally.

Distractor Analysis: A is incorrect because vendor contract documentation is a procurement management function, not a strategic current state assessment. C is incorrect because a compliance report serves a regulatory audience, while a current state assessment serves the CISO and governance bodies developing internal strategy. D is incorrect because budget justification is a management function; a current state assessment serves strategy development, not budget defense.
