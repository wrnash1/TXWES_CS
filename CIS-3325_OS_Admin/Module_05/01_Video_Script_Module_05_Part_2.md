**High-Yield Concepts:** 
*   **Variables:** Assigned without spaces (`NAME="John"`) and called with a dollar sign (`echo $NAME`).
*   **Execution:** A script must be made executable using `chmod +x script.sh` before it can be run using `./script.sh`.
