## Question 1

How many wires does the I2C communication protocol use, and what are they called?

- A) One wire for combined data and clock
- B) Two wires: SDA (Serial Data) and SCL (Serial Clock)
- C) Four wires: MOSI, MISO, SCK, and CS
- D) Three wires: TX, RX, and GND

**Correct Answer:** B

**Distractor Analysis:**

- A is incorrect: 1-Wire is a separate protocol (used by the DS18B20 sensor) that combines data and power on a single line. I2C requires two separate lines.
- B is correct: I2C uses exactly two wires — SDA carries data bidirectionally, and SCL carries the clock generated by the master. Multiple devices share both lines using unique 7-bit addresses.
- C is incorrect: MOSI, MISO, SCK, and CS describe the SPI bus, which uses four wires plus one additional CS line per slave device.
- D is incorrect: TX and RX are UART (serial) lines, an asynchronous protocol unrelated to I2C.

## Question 2

An Arduino Uno's ADC is 10 bits wide and uses a 5V reference voltage. What is the voltage represented by a raw ADC reading of 512?

- A) 2.5V
- B) 5.0V
- C) 1.0V
- D) 0.5V

**Correct Answer:** A

**Distractor Analysis:**

- A is correct: voltage = (512 / 1023) × 5.0 = approximately 2.5V. A reading of 512 is roughly half the maximum value of 1023, corresponding to half the reference voltage.
- B is incorrect: 5.0V corresponds to the maximum reading of 1023, not 512.
- C is incorrect: 1.0V would correspond to a reading of approximately 204 (1.0 / 5.0 × 1023).
- D is incorrect: 0.5V would correspond to a reading of approximately 102.

## Question 3

A developer needs to connect a high-speed SPI display and three I2C temperature sensors to a single Raspberry Pi. Which statement is accurate?

- A) SPI and I2C cannot operate simultaneously on the same Raspberry Pi.
- B) The three I2C sensors must each have unique 7-bit addresses; the SPI display uses a dedicated chip-select line and they can coexist.
- C) I2C requires four wires per device; SPI requires only two.
- D) SPI supports up to 127 devices on a single bus without additional chip-select lines.

**Correct Answer:** B

**Distractor Analysis:**

- A is incorrect: The Raspberry Pi exposes both I2C and SPI buses simultaneously on the 40-pin GPIO header. They operate on entirely separate hardware peripherals and do not interfere with each other.
- B is correct: I2C uses addressing (up to 127 unique 7-bit addresses per bus), so all three sensors can share SDA and SCL as long as their addresses differ. SPI slaves are selected by pulling their dedicated CS pin LOW. Both buses can coexist on the same Raspberry Pi.
- C is incorrect: I2C uses only 2 shared wires for all devices. SPI requires 4 wires plus one additional CS per slave.
- D is incorrect: SPI has no built-in device addressing. Every additional SPI slave device requires its own dedicated GPIO chip-select pin.

## Question 4

An embedded IoT device ships from the factory with an accessible UART header that provides a Linux root shell to anyone with a USB-to-UART adapter. Which OWASP IoT Top 10 item does this represent?

- A) OWASP IoT #1 – Weak, Guessable, or Hardcoded Passwords
- B) OWASP IoT #3 – Insecure Ecosystem Interfaces
- C) OWASP IoT #10 – Lack of Physical Hardening
- D) OWASP IoT #7 – Insecure Data Transfer and Storage

**Correct Answer:** C

**Distractor Analysis:**

- A is incorrect: Item 1 addresses password-based authentication weaknesses on network-accessible services, not physical debug port exposure.
- B is incorrect: Item 3 refers to insecure web UIs, mobile apps, and cloud API interfaces — software interfaces, not physical hardware ports.
- C is correct: OWASP IoT #10 specifically covers exposed debug interfaces (UART, JTAG), unencrypted flash storage accessible via physical probing, and lack of tamper detection. An accessible UART root shell is a textbook example.
- D is incorrect: Item 7 addresses unencrypted data in transit and at rest, not exposed physical debug ports.

## Question 5

A battery-powered remote sensor must operate for 12 months on a single AA battery. Which platform selection and justification is correct?

- A) Raspberry Pi 4, because it runs a full Linux OS and supports HTTPS natively.
- B) Arduino (ATmega328P), because microcontrollers can enter deep sleep drawing under 1 microamp between readings while Linux SBCs draw hundreds of milliamps continuously.
- C) Raspberry Pi Zero W, because its small physical size reduces battery consumption proportional to its footprint.
- D) Arduino Mega, because additional GPIO pins provide redundant power paths that extend battery life.

**Correct Answer:** B

**Distractor Analysis:**

- A is incorrect: A Raspberry Pi 4 draws approximately 600 mA idle. A single AA battery has roughly 2,500 mAh of capacity — at that draw rate the battery would last about 4 hours, not 12 months.
- B is correct: The ATmega328P in power-down sleep mode draws approximately 0.1 microamps. Waking briefly once per minute to take a reading makes 12-month AA battery life achievable. This is the fundamental reason microcontrollers dominate battery-powered IoT sensor designs.
- C is incorrect: Physical size and power consumption are unrelated. A Raspberry Pi Zero W still runs Linux and draws 80–150 mA regardless of its smaller board dimensions.
- D is incorrect: Additional GPIO pins have no effect on power consumption. The Arduino Mega actually draws slightly more current than the Uno due to its larger ATmega2560 chip.

## Question 6

Which function in an Arduino sketch runs exactly once when the board powers on or resets?

- A) `main()`
- B) `loop()`
- C) `begin()`
- D) `setup()`

**Correct Answer:** D

**Distractor Analysis:**

- A is incorrect: While `main()` does exist in the Arduino framework's underlying C++ runtime, it is hidden from the programmer. The Arduino environment calls `setup()` and `loop()` from `main()` automatically.
- B is incorrect: `loop()` runs repeatedly and continuously after `setup()` completes. It is the main program cycle, not the one-time initialization function.
- C is incorrect: `begin()` is a method commonly called on library objects within `setup()` (for example, `Serial.begin(9600)`) but it is not the sketch lifecycle function that runs once on startup.
- D is correct: `setup()` is called exactly once by the Arduino runtime immediately after power-on or reset. It is the correct place to call `pinMode()`, `Serial.begin()`, and any other one-time initialization.

## Question 7

A Raspberry Pi Python GPIO script does not call `GPIO.cleanup()` before exiting. What is the most likely consequence?

- A) The script will throw a syntax error the next time it runs.
- B) GPIO pins configured as OUTPUT may remain driven HIGH, potentially damaging connected components and causing unpredictable behavior on the next script execution.
- C) The Raspberry Pi will automatically reboot to reset pin states.
- D) The RPi.GPIO library will log a warning to syslog but no hardware damage will occur.

**Correct Answer:** B

**Distractor Analysis:**

- A is incorrect: `GPIO.cleanup()` is a runtime function call, not syntax. Its omission does not produce a syntax error.
- B is correct: Without `GPIO.cleanup()`, pins left in OUTPUT mode retain their last driven state. A pin held HIGH after script exit could keep a connected LED lit, hold a relay energized, or feed voltage into another component unexpectedly. On the next execution, RPi.GPIO may also issue a channel-already-in-use warning that obscures real errors.
- C is incorrect: The Raspberry Pi operating system does not automatically reboot to reset GPIO states. GPIO state persists until explicitly cleared or the board is power-cycled.
- D is incorrect: While RPi.GPIO does issue a runtime warning, hardware damage from a persistently driven OUTPUT pin is a real and documented risk, not merely a logging event.

## Question 8

What is the purpose of calling `GPIO.setmode(GPIO.BCM)` in a Raspberry Pi Python script?

- A) It enables the SPI bus for high-speed peripheral communication.
- B) It tells the RPi.GPIO library to use Broadcom chip GPIO signal numbers rather than physical pin position numbers on the header.
- C) It configures all GPIO pins as inputs by default for safety.
- D) It sets the GPIO operating voltage to 3.3V instead of the default 5V.

**Correct Answer:** B

**Distractor Analysis:**

- A is incorrect: Enabling SPI is a separate configuration step performed in `raspi-config` or by loading the SPI kernel module. `GPIO.setmode()` has no effect on SPI.
- B is correct: `GPIO.setmode(GPIO.BCM)` instructs the library to interpret pin numbers using the Broadcom SoC signal numbering (BCM), which is the system used in all Raspberry Pi pinout diagrams and official documentation. The alternative `GPIO.BOARD` uses the physical pin position number on the 40-pin connector.
- C is incorrect: `GPIO.setmode()` only selects the numbering scheme. Individual pin directions are set by separate `GPIO.setup()` calls.
- D is incorrect: Raspberry Pi GPIO voltage is fixed at 3.3V by the hardware design. No software call changes the operating voltage.

## Question 9

On an Arduino Uno, which pins support PWM output?

- A) All 14 digital pins (D0 through D13).
- B) Only the six analog input pins (A0 through A5).
- C) Digital pins 3, 5, 6, 9, 10, and 11 only.
- D) Digital pins 0, 1, 2, 4, 7, and 8 only.

**Correct Answer:** C

**Distractor Analysis:**

- A is incorrect: Only 6 of the 14 digital pins on the Arduino Uno support PWM. The others can only output a static HIGH or LOW.
- B is incorrect: The analog pins (A0–A5) connect to the ADC for reading input voltages. They are inputs, not PWM outputs (though some can be used as digital outputs without PWM).
- C is correct: Pins 3, 5, 6, 9, 10, and 11 are marked with a tilde (~) on the Arduino Uno silkscreen indicating PWM capability. These six pins are connected to the ATmega328P's hardware timer/counter modules.
- D is incorrect: Pins 0, 1, 2, 4, 7, and 8 are standard digital I/O only; they have no PWM hardware backing.

## Question 10

A Raspberry Pi GPIO pin is connected directly to the output of a 5V sensor. The sensor output is pulled HIGH to 5V during a measurement. What is the likely result?

- A) The Raspberry Pi will read the correct logical HIGH value since 5V exceeds the 3.3V HIGH threshold.
- B) The GPIO input will be clamped to 3.3V internally by the protection diodes, with no damage.
- C) The GPIO pin will be permanently damaged because Raspberry Pi GPIO pins are rated for 3.3V maximum input.
- D) The GPIO pin will automatically switch to 5V mode to match the sensor voltage.

**Correct Answer:** C

**Distractor Analysis:**

- A is incorrect: While 5V does exceed the 3.3V logic HIGH threshold, the Broadcom SoC's GPIO input protection circuitry is not designed to continuously clamp 5V. The overvoltage will damage the input buffer of the pin.
- B is incorrect: The protection diodes on Raspberry Pi GPIO inputs can absorb brief transients but are not rated for sustained overvoltage. Continuous 5V input will exceed their clamping capacity and cause permanent damage.
- C is correct: Raspberry Pi GPIO input pins are rated for a maximum of 3.3V. Applying 5V directly will damage or destroy the GPIO circuitry. A voltage divider or dedicated level-shifter IC must be used to reduce 5V signals to 3.3V before connecting to Raspberry Pi GPIO.
- D is incorrect: Raspberry Pi GPIO pins have no automatic voltage level switching capability. The input voltage tolerance is a fixed hardware characteristic of the Broadcom SoC.
