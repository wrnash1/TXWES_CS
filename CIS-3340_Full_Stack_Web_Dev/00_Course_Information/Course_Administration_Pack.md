## Course Description

CIS-3340 Full Stack Web Development is a 16-week, three-credit-hour course that prepares students to design, build, and deploy complete web applications spanning the full technology stack — from browser-side HTML, CSS, and JavaScript through server-side Node.js APIs, relational and NoSQL databases, to cloud deployment on Amazon Web Services. The course is structured around the **AWS Certified Developer – Associate (DVA-C02)** certification framework, ensuring that technical skills map directly to industry-recognized competencies.

Students will build progressively complex projects beginning with static HTML/CSS layouts and concluding with a fully deployed serverless application using AWS Lambda, API Gateway, and DynamoDB. All required reading materials are **Zero Textbook Cost (ZTC)** open educational resources.

**Credits:** 3
**Delivery Format:** Online (asynchronous with optional synchronous review sessions)
**Prerequisites:** CIS-1320 Introduction to JavaScript (or equivalent programming experience)

## Grading Policy

| Assessment Category | Weight | Description |
|---------------------|--------|-------------|
| Module Quizzes (×16) | 20% | Five-question multiple-choice quiz per module, completed in Canvas. Open-note but timed (20 minutes). Lowest quiz grade is dropped. |
| Hands-On Labs (×15) | 30% | Weekly lab activity submitted as a GitHub repository URL or deployed application link. Graded on functionality, code quality, and adherence to the lab requirements. No lab drop — all 15 count. |
| Discussion Posts (×8) | 20% | Eight graded discussion boards across the 16 modules (every other week). Initial post due by Wednesday, two peer responses due by Sunday. Graded on depth, accuracy, and engagement. |
| Final Exam | 30% | Cumulative exam in Canvas (Module 16) — 65 questions mirroring the DVA-C02 format (multiple-choice and multiple-response). Open-note, 130-minute time limit. Covers all modules with emphasis on AWS service topics (Modules 10–16). |
| **Total** | **100%** | |

### Late Work Policy
- Lab assignments submitted up to 48 hours late receive a maximum score of 75%.
- Lab assignments submitted more than 48 hours late receive a maximum score of 50%.
- Quizzes and discussion posts have a 48-hour late window with a 10% penalty per day.
- Contact the instructor before the deadline if extenuating circumstances apply.

## Academic Integrity

All code submitted for labs must be your own work. You may use AI coding assistants (GitHub Copilot, ChatGPT, etc.) as a learning aid, but you must understand every line of code you submit and be able to explain your implementation choices. Submitting code that you cannot explain is a violation of the course's academic integrity policy.

All submitted labs will be checked for originality. Sharing your lab solutions with classmates before the submission deadline is not permitted.

## Accessibility and Accommodations

Students requiring academic accommodations must contact the Texas Wesleyan Office of Disability Services and provide documentation to the instructor within the first two weeks of the semester. All course materials are designed with WCAG 2.1 accessibility guidelines in mind. If you encounter accessibility barriers in any course material, contact the instructor immediately.
