**Question 1**
Which HTML5 tag is considered a semantic element?
*   A) <div>
*   B) <span>
*   C) <article>
*   D) <b>
*   **Correct Answer:** C) <article> has semantic meaning, telling the browser and search engines about the nature of the enclosed text content.
*   **Distractor Analysis:**
    *   *Why correct:* <article> has semantic meaning, telling the browser and search engines about the nature of the enclosed text content.
    *   div and span are generic container tags with no semantic value.
