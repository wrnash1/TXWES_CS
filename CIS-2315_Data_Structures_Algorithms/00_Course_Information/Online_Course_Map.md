# Online Course Map: CIS-2315 Data Structures & Algorithms
**Target Certification:** Technical Interview Readiness (LeetCode / HackerRank)

## 16-Week Breakdown

*   **Modules 1–3: Foundations**
    *   Module 01: Big-O Notation and Complexity Analysis
    *   Module 02: Arrays and Dynamic Arrays
    *   Module 03: Linked Lists – Singly and Doubly

*   **Modules 4–5: Linear Abstract Data Types**
    *   Module 04: Stacks and Queues
    *   Module 05: Hash Tables and Hash Maps

*   **Modules 6–8: Trees and Priority Structures**
    *   Module 06: Binary Trees and Tree Traversal
    *   Module 07: Binary Search Trees (BST)
    *   Module 08: Heaps and Priority Queues

*   **Modules 9–10: Graphs and Sorting**
    *   Module 09: Graphs – Representation and BFS/DFS
    *   Module 10: Sorting Algorithms – Bubble, Merge, Quick

*   **Modules 11–12: Search and Recursion**
    *   Module 11: Searching – Binary Search and Variants
    *   Module 12: Recursion and Backtracking

*   **Modules 13–14: Optimization Techniques**
    *   Module 13: Dynamic Programming – Memoization and Tabulation
    *   Module 14: Greedy Algorithms

*   **Modules 15–16: Advanced Topics and Final Assessment**
    *   Module 15: Advanced Topics – Tries, Segment Trees
    *   Module 16: Final Exam Prep & Coding Interview Practice
