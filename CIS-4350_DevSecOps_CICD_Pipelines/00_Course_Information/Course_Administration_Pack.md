---

## Course Description

CIS-4350 introduces students to the principles, tools, and practices of DevSecOps — the discipline of integrating security controls, scanning, and shared responsibility into every stage of a modern CI/CD pipeline. Students progress from foundational DevOps culture and Git-based automation through container security, infrastructure as code scanning, secrets management, policy enforcement, and compliance metrics. The course is structured around the Certified DevSecOps Professional (CDP) certification framework published by Practical DevSecOps.

By the end of this course, students will be able to design, implement, and evaluate a complete DevSecOps pipeline that incorporates SAST, DAST, SCA, container image scanning, IaC security scanning, secrets management, and compliance-as-code controls — using exclusively free and open-source tools available at no cost.

### Required Reading Materials (All Open Access)

All required readings are from the following free, open-access sources:

* **OWASP DevSecOps Guideline**: [https://owasp.org/www-project-devsecops-guideline/](https://owasp.org/www-project-devsecops-guideline/) — the primary reference for DevSecOps pipeline integration patterns and security tool selection, maintained by the Open Web Application Security Project.
* **GitHub Actions Documentation**: [https://docs.github.com/en/actions](https://docs.github.com/en/actions) — the official reference for GitHub Actions workflow syntax, trigger events, runner environments, and security hardening guidance.
* **Kubernetes Documentation**: [https://kubernetes.io/docs/](https://kubernetes.io/docs/) — the official reference for Kubernetes security concepts including RBAC, Network Policies, and Pod Security Standards.
* **OWASP Cheat Sheet Series**: [https://cheatsheetseries.owasp.org](https://cheatsheetseries.owasp.org) — concise, practitioner-oriented security guidance for specific topics (threat modeling, injection prevention, authentication).

## Academic Integrity

All lab work must represent the student's own configuration and analysis. Students may collaborate on conceptual understanding but must submit their own lab screenshots, reports, and written analyses. Use of AI tools to generate lab reports without personal engagement with the tools is a violation of academic integrity policy.

## CDP Certification Information

The Certified DevSecOps Professional (CDP) certification is offered by Practical DevSecOps ([https://www.practical-devsecops.com/certified-devsecops-professional/](https://www.practical-devsecops.com/certified-devsecops-professional/)). This course prepares students for the CDP exam but does not include the certification exam fee. Students who wish to sit for the CDP exam after completing this course should review the current exam registration information at the Practical DevSecOps website. Exam vouchers are available for purchase independently.
