## Scenario A — The Small Office Upgrade

A 30-person accounting firm has outgrown its original network. The current setup uses a consumer-grade wireless router provided by the ISP, one unmanaged 8-port switch, and no dedicated WAP. The owner wants to add 20 more workstations, deploy Wi-Fi throughout three meeting rooms, power IP phones without running electrical cables, and be able to segment the network so that the accounting servers are on a separate subnet from general workstations.

1. Identify which current devices need to be replaced or supplemented and what enterprise-grade devices would replace them. For each device you recommend adding or replacing, state the specific function it provides that the current setup lacks.
2. Which device would you use to create separate subnets for accounting servers and general workstations, and at which OSI layer does subnet separation occur?
3. The owner asks whether PoE can power the IP phones and which IEEE standard is sufficient for a standard desk VoIP phone drawing 7 W. Name the standard and its maximum wattage.

## Scenario B — The Wiring Closet Problem

A university IT department receives a help desk ticket: "Twelve students in Lab 204 have no network connectivity. The computers were working yesterday." A technician goes to the wiring closet and finds that someone reorganized the rack and moved several patch cables. The managed switch shows all 24 ports as active with green LEDs. The students' computers show "Network cable unplugged."

1. Explain how a patch panel and a managed switch work together in a structured cabling installation. Why would moving patch cables in the wiring closet cause workstations in a classroom to lose connectivity even though the switch shows active ports?
2. The technician suspects the patch cables from the Lab 204 wall jack ports are now plugged into the wrong switch ports — ports assigned to a different VLAN. Explain what a VLAN is, which device enforces VLAN segmentation, and why a workstation on the wrong VLAN would show "Network cable unplugged" rather than just "No internet access."
3. What documentation should the IT department maintain to prevent this type of problem from recurring, and what labeling practice should be applied to patch panel ports?

## Scenario C — The Branch Office Deployment

A company is opening a new branch office with 15 wired workstations, ceiling-mounted WAPs in three conference rooms, eight IP cameras in the parking lot (each rated at 18 W), and a direct fiber connection to the ISP. The branch must be protected by a firewall and all internal devices must receive IP addresses automatically.

1. List every infrastructure device needed at this branch (modem/ONT, firewall, router, switch, patch panel, WAPs) and for each device state exactly one function it performs that no other device on the list can perform.
2. The IT manager wants to know which single switch specification is most critical for the IP camera deployment. Identify the relevant IEEE PoE standard needed for an 18 W device, and calculate the minimum PoE budget the switch must have to power all eight cameras simultaneously.
3. The WAPs will be ceiling-mounted and connected to the switch via cable runs of 35–60 meters. Which PoE standard covers a typical enterprise WAP drawing 20 W, and does the cable run length affect which PoE standard is needed?
