### Question 1

What does a blank screen with continuous short beeps during startup typically indicate?

- A) The OS is corrupted and must be reinstalled from recovery media
- B) POST has failed — beep codes are diagnostic indicators emitted by the BIOS/UEFI when it detects a hardware component failure such as missing RAM or a motherboard fault
- C) The monitor is unplugged and the beeps are a display-not-found warning
- D) The keyboard is disconnected and the system cannot complete boot without keyboard input

**Correct Answer:** B — Beep codes are emitted during the Power-On Self-Test (POST) phase, before the OS is ever loaded. Continuous or repeating beeps indicate a hardware initialization failure detected by the BIOS/UEFI firmware.

**Distractor Analysis:**

- *Why A is incorrect:* OS corruption occurs after POST completes successfully. A system that fails POST with a blank screen never reaches the bootloader or OS loading stage.
- *Why C is incorrect:* A disconnected monitor produces a blank screen but no beep codes. Beep codes are generated by the BIOS speaker on the motherboard and are triggered by hardware initialization failures, not display detection.
- *Why D is incorrect:* Modern systems complete POST and boot without a keyboard connected. A missing keyboard may produce a warning on screen after POST, but it does not cause continuous beep codes or a completely blank screen.

### Question 2

In the context of PC hardware, which of the following most accurately describes POST errors?

- A) Diagnostic fault codes produced by the BIOS/UEFI during the Power-On Self-Test when it detects a hardware component failure — such as missing RAM, failed GPU, or no boot device — causing the system to halt before the OS loads and reporting the fault via on-screen codes, beep patterns, or LED indicators
- B) Error messages generated by the Windows kernel after the OS has fully loaded, indicating that a software driver has caused a memory access violation and the system must restart
- C) Fault codes recorded in the Windows Event Log after a scheduled task fails to execute, used by administrators to identify services that did not start correctly during the last boot cycle
- D) Hardware error alerts generated by the operating system's device manager when a newly installed peripheral driver conflicts with an existing driver already loaded in memory

**Correct Answer:** A — POST errors are pre-OS hardware diagnostics generated by firmware. The BIOS/UEFI tests critical components (RAM, CPU, GPU, storage) before any OS is loaded, and reports failures via beep codes, on-screen codes, or diagnostic LEDs.

**Distractor Analysis:**

- *Why B is incorrect:* This describes a BSOD (Blue Screen of Death) — a kernel-level error that occurs after the OS has loaded, not during the hardware initialization phase of POST.
- *Why C is incorrect:* Windows Event Log entries are software-level OS records generated after boot completes; they are unrelated to the firmware POST process.
- *Why D is incorrect:* Device Manager driver conflicts are OS-level software events; POST occurs before any operating system or driver is loaded.

### Question 3

A technician powers on a PC and hears three beeps followed by a pause, then three more beeps repeating. The screen remains completely blank. Which action is the most appropriate first diagnostic step?

- A) Reinstall Windows from a USB recovery drive because the repeating beep pattern confirms the OS bootloader is corrupt
- B) Look up the beep code pattern in the motherboard manual or manufacturer's website to identify which hardware component POST is reporting as failed
- C) Replace the power supply immediately because repeating beep patterns always indicate insufficient wattage reaching the motherboard
- D) Connect the monitor to a different video output port on the GPU because the beep pattern indicates the current port has failed

**Correct Answer:** B — Beep codes are manufacturer-specific; the same pattern means different things on AMI versus Award versus Phoenix BIOS. The correct first step is always to identify what the specific code means for that motherboard before taking any corrective action.

**Distractor Analysis:**

- *Why A is incorrect:* The screen is blank because POST has not completed and the GPU has not been initialized. The OS bootloader is never reached during a POST failure, so reinstalling Windows cannot address the problem.
- *Why C is incorrect:* PSU failure typically causes no power at all or immediate shutdown. A system that reaches the POST beep-code stage has sufficient power to run the motherboard and initiate firmware execution.
- *Why D is incorrect:* A GPU port failure would produce POST completion with no display output afterward, not a repeating beep code before any display signal is established.

### Question 4

A Windows PC that was working normally suddenly displays a blue screen with the stop code "INACCESSIBLE_BOOT_DEVICE" every time it starts. The system restarts automatically and shows the same BSOD in a loop. What is the most likely cause and correct first step?

- A) The monitor cable is loose; reseat the HDMI connection between the GPU and the monitor to restore display output
- B) The system's boot drive has failed or become disconnected, or the Windows boot partition is corrupted; boot from Windows installation media and run Startup Repair or check the drive connection
- C) The CPU thermal paste has dried out causing thermal throttling at POST; replace the thermal paste and reseat the CPU cooler before attempting to boot again
- D) The RAM modules need to be upgraded to DDR5 because the INACCESSIBLE_BOOT_DEVICE error code specifically indicates a memory generation mismatch

**Correct Answer:** B — INACCESSIBLE_BOOT_DEVICE is a BSOD stop code meaning Windows cannot access the partition containing the OS. The most common causes are a disconnected or failed boot drive, a corrupted boot sector, or a changed SATA/AHCI/RAID mode in BIOS.

**Distractor Analysis:**

- *Why A is incorrect:* A loose monitor cable causes no display but does not generate a BSOD stop code. The fact that a BSOD is visible at all confirms video output is functional.
- *Why C is incorrect:* Thermal paste degradation causes thermal throttling or shutdown under sustained load — not a specific BSOD stop code referencing boot device access.
- *Why D is incorrect:* INACCESSIBLE_BOOT_DEVICE is a storage and boot partition error with a specific technical meaning unrelated to RAM generation compatibility.

### Question 5

A technician installs a new NVMe SSD in a PC, clones the OS from the old SATA drive, and removes the old drive. On reboot, the system displays "No bootable device found." The new NVMe drive is physically seated and detected in BIOS. What is the most likely fix?

- A) The NVMe drive must be reformatted because cloned drives are never bootable and a fresh Windows installation is required
- B) The BIOS/UEFI boot order still lists the old SATA drive as the first boot device; update the boot priority to set the new NVMe SSD as the first boot device
- C) The NVMe drive must be moved to a different M.2 slot because the current slot does not support booting, only data storage
- D) The system requires a BIOS firmware update before NVMe boot support is available on any motherboard manufactured before 2020

**Correct Answer:** B — When a drive is replaced, the BIOS/UEFI boot order retains the old device entry. Since the old drive is removed, the firmware finds nothing at the first boot priority position and reports "no bootable device." Updating boot priority to the NVMe SSD resolves this immediately.

**Distractor Analysis:**

- *Why A is incorrect:* Cloned drives are fully bootable when the clone operation preserves the boot partition and MBR/GPT structure. Drive cloning is a standard and valid OS migration method.
- *Why C is incorrect:* M.2 slot boot capability depends on the motherboard's UEFI configuration, not the physical slot position. The scenario confirms the drive is already detected in BIOS, indicating the slot and controller are functional.
- *Why D is incorrect:* NVMe boot support has been available on consumer motherboards since approximately 2015. The drive being detected in BIOS confirms NVMe support is present without a firmware update.

### Question 6

A technician boots a PC and the screen displays: "Operating System not found." The system has a single SATA SSD installed. The BIOS correctly detects the drive. What is the most likely explanation?

- A) The SATA SSD is physically failing and must be replaced immediately before any software fix is attempted
- B) The SSD is detected by the BIOS but its boot partition (MBR or GPT) is missing or corrupted, so the firmware can identify the drive as hardware but cannot find a valid boot record on it
- C) The BIOS has been reset to factory defaults and now requires a firmware update before it can read SATA drives
- D) The display adapter is failing, causing the screen to show incorrect text that does not represent the actual system state

**Correct Answer:** B — BIOS detecting a drive means the hardware connection is functional. "Operating System not found" specifically means the firmware found the drive but could not locate a valid boot sector (MBR or GPT). This is caused by a missing or corrupted boot record, not physical drive failure.

**Distractor Analysis:**

- *Why A is incorrect:* Physical SSD failure typically causes the BIOS to fail to detect the drive entirely. A drive cleanly detected by BIOS but lacking a boot record points to a software or partition issue.
- *Why C is incorrect:* A BIOS factory reset changes settings such as boot order and AHCI/IDE mode but does not prevent SATA drive detection. The drive is already detected, confirming the controller is functioning.
- *Why D is incorrect:* A failing display adapter would prevent display output entirely. A specific, readable text error message confirms the display subsystem is functional.

### Question 7

During POST on a recently assembled PC, the BIOS speaker emits one long beep followed by two short beeps (AMI BIOS). Which component should the technician check first?

- A) The CPU, because one long and two short beeps on AMI BIOS indicates a CPU thermal sensor fault
- B) The video card (GPU), because one long beep followed by two short beeps on AMI BIOS typically indicates a video subsystem failure
- C) The power supply, because this beep pattern specifically identifies an undervoltage condition on the +12V rail
- D) The hard drive, because the beep pattern indicates the BIOS cannot detect a bootable storage device

**Correct Answer:** B — On AMI BIOS, one long beep followed by two short beeps is the standard code for a video card or GPU initialization failure. The technician should reseat the GPU, verify the PCIe power connectors are attached, and test with a known-good card if reseating does not resolve the issue.

**Distractor Analysis:**

- *Why A is incorrect:* AMI BIOS CPU-related beep codes use different patterns. Thermal sensor faults typically cause system shutdown under load, not a specific POST beep sequence before initialization completes.
- *Why C is incorrect:* PSU voltage rail issues do not produce specific beep codes. They cause the system to fail to power on at all, restart immediately, or shut down under load. A system that reaches POST beep codes has sufficient power.
- *Why D is incorrect:* "No boot device" errors occur after POST completes successfully. They are displayed as on-screen text messages, not beep codes generated during hardware initialization.

### Question 8

A technician is troubleshooting a PC that powers on (fans spin, LEDs light up) but displays nothing on the monitor. Swapping the monitor and cable confirms both are functional. The GPU has a diagnostic LED on the motherboard that is lit red. What should the technician try first?

- A) Flash the BIOS to the latest version using a USB drive because the GPU diagnostic LED always indicates a firmware incompatibility
- B) Reseat the GPU in the PCIe slot, verify the PCIe power connectors are fully seated, and confirm the monitor is connected to the GPU's output rather than the motherboard's integrated graphics output
- C) Replace the CPU because a red GPU diagnostic LED is caused by the CPU's PCIe controller failing to initialize the graphics bus
- D) Replace the RAM modules because the GPU diagnostic LED activates when the system cannot allocate sufficient system memory for the GPU's frame buffer

**Correct Answer:** B — A red GPU diagnostic LED indicates the system has detected a problem initializing the video subsystem. The most common physical causes are an unseated GPU, a PCIe power connector not fully plugged in, or the monitor being connected to the motherboard's integrated graphics port instead of the GPU.

**Distractor Analysis:**

- *Why A is incorrect:* BIOS flashing is an advanced step that should not be the first response to a physical seating or connection issue. A GPU diagnostic LED does not specifically indicate a firmware incompatibility.
- *Why C is incorrect:* While PCIe controller faults can cause GPU initialization failures, CPU replacement is an extreme and expensive step. Physical reseating and connection verification must be exhausted first.
- *Why D is incorrect:* GPU memory allocation issues manifest as display artifacts or driver errors after POST, not as a diagnostic LED during hardware initialization.

### Question 9

A Windows PC boots normally but intermittently freezes with a blue screen showing the stop code "MEMORY_MANAGEMENT." The freezes occur randomly, not under load. What is the most appropriate diagnostic step?

- A) Reinstall the graphics drivers because the MEMORY_MANAGEMENT stop code is exclusively caused by GPU driver conflicts
- B) Run MemTest86 (bootable RAM diagnostic) to test the physical RAM modules for errors, as MEMORY_MANAGEMENT commonly indicates a RAM hardware fault
- C) Increase the Windows virtual memory page file size because the stop code indicates the page file has run out of space
- D) Replace the hard drive because MEMORY_MANAGEMENT errors are caused by the storage subsystem corrupting data as it is read into RAM

**Correct Answer:** B — MEMORY_MANAGEMENT is a BSOD stop code that frequently indicates failing RAM modules. MemTest86 is the standard bootable diagnostic tool that tests RAM independently of the OS, making it the appropriate first step for isolating a potential RAM hardware fault.

**Distractor Analysis:**

- *Why A is incorrect:* GPU driver conflicts produce different stop codes such as VIDEO_TDR_FAILURE. MEMORY_MANAGEMENT is not exclusively a GPU driver issue, and random occurrences not correlated with GPU activity make a driver cause less likely.
- *Why C is incorrect:* Windows page file exhaustion produces a different warning. MEMORY_MANAGEMENT specifically refers to the physical memory management subsystem encountering an error, not a virtual memory space shortage.
- *Why D is incorrect:* Storage subsystem errors produce stop codes such as INACCESSIBLE_BOOT_DEVICE or CRITICAL_PROCESS_DIED. RAM hardware testing should be performed first as it is the more common cause of this specific stop code.

### Question 10

A technician discovers that a PC's BIOS settings reset to defaults every time the system is powered off completely and unplugged for more than an hour. The time and date also reset to January 1, 2000. What is the most likely cause?

- A) The BIOS firmware is corrupt and needs to be reflashed because valid firmware retains settings permanently in non-volatile EEPROM
- B) The CMOS battery (typically a CR2032 coin cell) is dead or missing; it provides the small continuous voltage that maintains BIOS settings and the real-time clock when the system is unplugged
- C) The motherboard's BIOS chip has failed and the entire motherboard must be replaced because CMOS settings cannot be preserved without a functional BIOS chip
- D) The power supply is providing insufficient +5VSB standby voltage, causing CMOS RAM to lose its charge whenever the system is completely powered down

**Correct Answer:** B — The CMOS battery (usually a CR2032 coin cell on the motherboard) provides low-level continuous power to maintain BIOS settings and the real-time clock when the system is unplugged. A dead or missing CMOS battery causes exactly this symptom: settings and time reset whenever main power is removed.

**Distractor Analysis:**

- *Why A is incorrect:* BIOS/UEFI firmware code is stored in non-volatile flash memory that does not require power to retain the firmware itself. User-configurable BIOS settings are stored separately in CMOS RAM, which does require battery power to persist.
- *Why C is incorrect:* The BIOS chip retains the firmware permanently without a battery. Only user-configurable CMOS settings (boot order, date/time, voltages) require the CMOS battery to persist between power cycles.
- *Why D is incorrect:* While +5VSB powers certain always-on motherboard functions, CMOS RAM preservation depends specifically on the dedicated CMOS battery circuit, not the PSU standby rail.

### Question 16

A technician is troubleshooting a PC that fails to POST. The motherboard has a debug LED display showing code "A2." Looking up the manufacturer's POST code table shows A2 means "IDE Detect." The system has no IDE drives — only SATA and NVMe storage. What is the most likely explanation?

- A) The NVMe SSD is incompatible with the motherboard and must be replaced with a SATA SSD that uses the IDE signaling protocol
- B) The POST code display does not necessarily mean the system is halted at that step; POST codes update rapidly and A2 may be the last code displayed before the system failed at a later step
- C) The BIOS has confused the NVMe SSD for an IDE device; this requires a complete BIOS reflash to restore correct device enumeration
- D) The A2 POST code definitively means all storage devices are missing and the technician must reinstall all drives before continuing diagnosis

**Correct Answer:** B — POST code displays update in sequence as the firmware progresses through initialization steps. The code shown is the last code that was written before the failure occurred, which may be one or more steps before the actual fault. A2 being displayed does not necessarily mean IDE detection caused the halt.

**Distractor Analysis:**

- *Why A is incorrect:* NVMe and SATA are modern storage interfaces that are fully compatible with current motherboards. IDE is a legacy parallel interface; NVMe SSDs do not use or require IDE signaling.
- *Why C is incorrect:* BIOS does not confuse NVMe with IDE at a firmware level; the POST code sequence passes through many codes including legacy ones even on modern systems. A reflash is not indicated by this symptom alone.
- *Why D is incorrect:* A2 in many AMI BIOS implementations represents an initialization phase, not necessarily a definitive "all storage missing" fault. The technician should check the full POST code table and continue systematic diagnosis.

### Question 17

A user's PC experiences a "Windows Boot Manager" error screen with the message: "File: \BCD Status: 0xc0000034 Info: The Boot Configuration Data file is missing or contains errors." Which of the following is the most appropriate repair action?

- A) Replace the RAM modules because 0xc0000034 is a hexadecimal memory address indicating a RAM hardware failure at that physical location
- B) Boot from Windows installation media, open the Recovery Environment, and run the `bootrec /rebuildbcd` command to reconstruct the Boot Configuration Data store
- C) Open the BIOS and disable Secure Boot because the BCD error is caused by Secure Boot blocking the Windows bootloader from executing
- D) Perform a full Windows reinstall from scratch because a missing BCD file cannot be repaired without overwriting all system data

**Correct Answer:** B — The BCD (Boot Configuration Data) store is the Windows boot database that tells the bootloader which OS to load. When it is missing or corrupt, the system cannot boot. The Windows Recovery Environment provides the `bootrec /rebuildbcd` and `bootrec /fixboot` commands specifically for repairing this condition without requiring a fresh OS installation.

**Distractor Analysis:**

- *Why A is incorrect:* 0xc0000034 is a Windows NTSTATUS error code for "object not found" — specifically the BCD file is not found. It is not a RAM memory address.
- *Why C is incorrect:* Secure Boot blocking would produce a different error about an unsigned or untrusted bootloader; it would not cause the BCD file to be missing. BCD corruption is a data integrity issue, not a Secure Boot enforcement issue.
- *Why D is incorrect:* The Windows Recovery Environment's `bootrec` tools are specifically designed to repair BCD without data loss. A full reinstall is unnecessary and would destroy user data.

### Question 18

A technician replaces a failed HDD with a new SSD in a PC that uses UEFI firmware. After a fresh Windows installation, the PC boots correctly. Two weeks later, the PC suddenly will not boot and shows "Secure Boot violation." No hardware changes were made. What is the most likely cause?

- A) The SSD's NAND flash has corrupted the Windows bootloader files due to a firmware bug in the new drive
- B) A Windows Update installed a new bootloader or modified boot-related files that are not signed by a key currently in the UEFI Secure Boot database, causing Secure Boot to block the boot attempt
- C) The CMOS battery died, causing Secure Boot to enable itself automatically and block the previously trusted boot path
- D) The PCIe slot powering the SSD lost contact, causing intermittent data corruption that activated Secure Boot as a protective measure

**Correct Answer:** B — Windows Updates occasionally update bootloader components. If a Secure Boot key database update is pending, or if an update modifies the boot files in a way that creates a temporary signature mismatch, a Secure Boot violation can appear. The fix is typically to update the UEFI Secure Boot keys or temporarily disable Secure Boot to apply the relevant update.

**Distractor Analysis:**

- *Why A is incorrect:* SSD firmware bugs causing bootloader corruption are rare and would produce different errors such as I/O errors or corrupted file errors; they would not trigger a Secure Boot cryptographic signature violation.
- *Why C is incorrect:* A dead CMOS battery resets BIOS settings to defaults, which typically disables Secure Boot (since Secure Boot is not always the factory default). It does not cause Secure Boot to activate spontaneously.
- *Why D is incorrect:* NVMe SSDs use the M.2 slot, not a PCIe expansion slot. More importantly, Secure Boot is a cryptographic signature verification process and cannot be "triggered" by storage errors.

### Question 19

A technician is building a new PC for a client who needs to dual-boot Windows 11 and Ubuntu Linux. After installing both operating systems on separate partitions, the PC only boots directly into Windows and skips the boot menu. What is the most likely fix?

- A) Ubuntu Linux cannot be dual-booted with Windows 11 because UEFI Secure Boot prevents Linux bootloaders from running on the same drive
- B) The Windows Boot Manager has overwritten or is set as the only UEFI boot entry; the technician should use the BIOS/UEFI boot menu to add the Ubuntu EFI boot entry (grubx64.efi) and set it as the default or configure GRUB as the default bootloader
- C) The Ubuntu partition must be placed on a separate physical drive because Windows 11 does not support multi-OS boot entries on a single NVMe SSD
- D) The client must purchase a dual-boot license from Microsoft before Windows 11 will display a boot selection menu for alternate operating systems

**Correct Answer:** B — In UEFI systems, each OS installs its EFI bootloader into the EFI System Partition. Windows Boot Manager often overwrites the default boot entry. The technician needs to add the Ubuntu GRUB EFI entry in the UEFI boot order settings and either set GRUB as the default (which then chains to Windows) or use the UEFI boot menu to select between the two entries.

**Distractor Analysis:**

- *Why A is incorrect:* Ubuntu supports Secure Boot through a Microsoft-signed shim bootloader (shim.efi). Modern Ubuntu distributions install and boot correctly with Secure Boot enabled on UEFI systems.
- *Why C is incorrect:* Dual-booting on a single physical NVMe SSD is a fully supported and common configuration. Windows and Linux use separate partitions and separate EFI boot entries on the same EFI System Partition.
- *Why D is incorrect:* There is no Microsoft dual-boot license. Boot menu configuration is a UEFI firmware and OS bootloader configuration task, not a licensing matter.

### Question 20

A technician performs a RAM upgrade on a desktop PC — replacing two 8 GB sticks with two 16 GB sticks. After the upgrade, the PC boots to a black screen with no POST beeps, no BIOS splash screen, and no display output at all, despite the power LED being on and fans spinning. What should the technician do first?

- A) Reinstall Windows because a RAM capacity increase requires a fresh OS installation to recognize the new memory ceiling
- B) Power off, remove the new RAM, reseat the original 8 GB sticks to verify the system POSTs correctly with the old hardware, then reinstall the new sticks one at a time to isolate whether the issue is a seating problem, a compatibility issue, or a defective module
- C) Update the BIOS/UEFI to the latest version while the new RAM is installed because the black screen confirms the firmware cannot initialize the new capacity without a firmware update
- D) Connect the monitor to the motherboard's integrated graphics port instead of the GPU, as the RAM upgrade has automatically disabled the discrete GPU to conserve memory bandwidth

**Correct Answer:** B — When a RAM upgrade causes a no-POST, no-display condition, the correct first diagnostic step is to reinstall the known-working original modules to confirm the system and display are functioning, then systematically test the new modules to isolate the fault (bad seating, incompatible speed/voltage, or defective stick).

**Distractor Analysis:**

- *Why A is incorrect:* RAM upgrades do not require a Windows reinstall. The OS recognizes new RAM capacity automatically at the next boot without any reinstallation.
- *Why C is incorrect:* Updating BIOS while the system cannot POST is not possible without special recovery procedures (USB BIOS flashback, if supported). More importantly, a no-POST condition should be diagnosed with known-working hardware first before attempting a BIOS update.
- *Why D is incorrect:* RAM upgrades do not automatically disable discrete GPUs or re-route video output. A no-display condition after a RAM upgrade is caused by a RAM initialization failure, not a video routing change.
