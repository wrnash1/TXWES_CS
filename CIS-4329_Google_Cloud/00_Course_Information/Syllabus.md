## Course Overview

### Course Description
This course covers Resource Hierarchy, GKE deployment, Autoscaling, IAM, Google Cloud CLI tools, App Engine, and hybrid cloud.

### Course Objectives / Student Learning Outcomes
By the end of this course, students will be able to:
1. Explain and configure core principles of **Google Cloud Associate Cloud Engineer** in a variety of business and technical scenarios.
2. Formulate, execute, and verify terminal-based commands and administrative configurations matching production-level operations.
3. Critically analyze system failures or security vulnerabilities, and propose mitigation strategies.
4. Prepare for and demonstrate competency aligned with the official **Google Cloud Associate Cloud Engineer** certification exam blueprint.

### Required Materials
*   **Zero Textbook Cost (ZTC):** All required reading materials, video lectures, and study guides are provided completely free within the Canvas LMS course shell. No textbook purchase is required.
*   **Primary OER Resources:**
    *   **Primary Open Textbook:** [Google Cloud Associate Cloud Engineer Documentation](https://cloud.google.com/docs)
    *   **Primary Video Lecture Course:** [Google Cloud ACE Certification Course by freeCodeCamp](https://www.youtube.com/watch?v=UGRDM86MBIQ)
    *   **Official Vendor Reference Portal:** [Google Cloud Architecture Center](https://cloud.google.com/)
*   **Hardware/Software Requirements:** Access to a computer running Windows, macOS, or Linux with terminal access, standard development tools, and high-speed internet.
