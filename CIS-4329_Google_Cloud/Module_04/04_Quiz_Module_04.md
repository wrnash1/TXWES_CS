## Question 1

You want to ensure that your application can survive the failure of a single Compute Engine instance. If an instance crashes or becomes unresponsive, you want Google Cloud to automatically delete the broken instance and replace it with a fresh, identical one. Which feature should you implement?

A. An unmanaged instance group

B. A Managed Instance Group with an autohealing health check

C. A global HTTP(S) load balancer without a backend MIG

D. A Cloud Monitoring alerting policy with an email notification channel

Correct Answer: B

Distractor Analysis:

- Why A is incorrect: Unmanaged instance groups are arbitrary collections of heterogeneous VMs with no autoscaling, autohealing, or automatic instance replacement capability. They exist only for organizing VMs in a load balancer backend — they take no action when a VM fails.
- Why C is incorrect: A load balancer routes traffic away from unhealthy backend instances, but it does not have authority to delete broken VMs and provision replacements. The MIG performs autohealing; the load balancer distributes traffic.
- Why D is incorrect: Alerting policies send notifications (email, Pub/Sub, PagerDuty) when a condition is met but do not take automated remediation actions such as deleting and recreating a VM instance.

## Question 2

Your company requires that all application logs generated by Compute Engine instances be retained for a minimum of five years to meet financial compliance regulations. Cloud Logging retains logs for 30 days by default. What is the most appropriate automated solution?

A. Create a Cloud Monitoring uptime check pointing at each log-generating VM.

B. Take daily snapshots of all Compute Engine boot disks and store them as backups.

C. Create a Log Sink to export logs to a Cloud Storage bucket using the Archive storage class.

D. Write a startup script that emails a daily log digest to the compliance team.

Correct Answer: C

Distractor Analysis:

- Why A is incorrect: Cloud Monitoring uptime checks verify that a URL or TCP port is responding. They have no connection to log retention, log export, or compliance storage requirements.
- Why B is incorrect: Disk snapshots capture full disk state (OS, application binaries, all files) — not structured log data. This approach would be massively expensive for 5 years, produces unsearchable binary blobs, and is not a recognized compliance log storage mechanism.
- Why D is incorrect: Emailing log digests is not secure, not searchable, not auditable, and not a recognized compliance log retention mechanism. Log Sinks natively and automatically route logs to Cloud Storage for low-cost, durable long-term retention.

## Question 3

A Cloud Storage bucket contains project assets actively used during a project lifecycle. After the project closes, the objects must be retained for 90 days and then permanently deleted. Which Cloud Storage feature automates this without manual intervention?

A. Enable object versioning on the bucket and manually delete old versions after 90 days.

B. Configure a lifecycle policy with a `Delete` action and an `age` condition of 90 days.

C. Change the bucket's default storage class to Archive after the project closes.

D. Use `gcloud storage rm` in a manually triggered job 90 days after project close.

Correct Answer: B

Distractor Analysis:

- Why A is incorrect: Object versioning preserves old copies of objects when they are overwritten or deleted. It does not automatically delete objects after a set time period. Manual deletion after 90 days contradicts the requirement for automated behavior.
- Why C is incorrect: Changing the storage class transitions objects to a cheaper tier, which reduces cost, but it does not delete objects after 90 days. The data persists indefinitely in Archive storage until explicitly deleted.
- Why D is incorrect: A manually triggered job relies on a human remembering to run it at the right time 90 days in the future. Lifecycle policies are the native, zero-maintenance, fully automated mechanism for time-based object deletion.

## Question 4

You need to share a private file stored in a Cloud Storage bucket with an external business partner who does not have a Google Account. The access should expire automatically after 24 hours. What is the correct approach?

A. Temporarily make the bucket public by setting its IAM policy to `allUsers` with `roles/storage.objectViewer`.

B. Create a Google Account for the partner and grant them `roles/storage.objectViewer` on the bucket.

C. Generate a signed URL for the specific object with a 24-hour expiration and send it to the partner.

D. Copy the file to a separate public bucket, delete it after 24 hours, and send the partner the public URL.

Correct Answer: C

Distractor Analysis:

- Why A is incorrect: Setting the bucket IAM to `allUsers` exposes every object in the bucket to the entire unauthenticated internet — not just the specific file and not just the one partner. It requires manual reversal and creates a significant security risk.
- Why B is incorrect: Creating a Google Account for each external partner is operationally unsustainable at scale, gives the partner a persistent GCP identity, and does not automatically expire access after 24 hours without manual IAM cleanup.
- Why D is incorrect: Copying to a second public bucket exposes other objects in that bucket, relies on manual 24-hour cleanup, and is architecturally complex. Signed URLs are purpose-built for this exact use case: time-limited access to a specific private object.

## Question 5

Your organization stores financial audit logs in a Cloud Storage bucket. Regulations require that audit logs cannot be deleted or overwritten for at least seven years after creation. Which Cloud Storage feature enforces this immutability requirement?

A. Enable object versioning so that previous versions are always recoverable.

B. Apply a retention policy with a seven-year retention period to the bucket.

C. Set a lifecycle policy to transition objects to Archive storage after one year.

D. Grant only `roles/storage.objectViewer` to all users so no one can delete objects.

Correct Answer: B

Distractor Analysis:

- Why A is incorrect: Object versioning preserves overwritten or deleted objects as noncurrent versions, but a project owner or storage administrator can still permanently delete all versions using the `-a` flag. Versioning does not enforce legal hold-style immutability.
- Why C is incorrect: Transitioning objects to Archive storage changes the cost tier but does not prevent deletion by authorized principals. Archive storage is still mutable — it just costs more to read. Retention requires a dedicated retention policy, not a storage class change.
- Why D is incorrect: Granting only objectViewer to most users prevents casual deletion, but project owners and users with higher roles can override viewer restrictions. A retention policy creates a hard lock that even storage admins and project owners cannot circumvent before the retention period expires.

## Question 6

A development team stores build artifacts in a Cloud Storage bucket. Artifacts older than 30 days are rarely accessed. Artifacts older than 180 days are never accessed. The team wants to minimize storage costs while keeping all artifacts indefinitely accessible. Which lifecycle configuration achieves this?

A. Enable Autoclass on the bucket and do nothing else.

B. Set a lifecycle rule to delete all objects after 30 days.

C. Set a lifecycle rule to transition to Nearline after 30 days, and another rule to transition to Coldline after 180 days.

D. Manually move artifacts to Archive storage whenever an administrator remembers to do so.

Correct Answer: C

Distractor Analysis:

- Why A is incorrect: Autoclass can achieve similar cost optimization automatically, but the question is asking about a specific lifecycle configuration. Additionally, Autoclass transitions objects based on actual access events, while a lifecycle policy makes the transitions deterministically on schedule. Both are valid but C is the more direct answer to the question format.
- Why B is incorrect: Deleting all objects after 30 days contradicts the requirement to keep all artifacts indefinitely accessible. This would destroy every artifact older than 30 days.
- Why D is incorrect: Manual management introduces human error, is not automated, and does not scale. Lifecycle policies are the managed, zero-maintenance solution.

## Question 7

Which statement correctly describes the difference between a Cloud Storage bucket location type of "region" versus "multi-region"?

A. A regional bucket stores data only in a single zone; a multi-region bucket stores data in multiple zones across the world.

B. A regional bucket stores data in one geographic location and replicates across its zones; a multi-region bucket stores data redundantly across a large geographic area such as the entire United States.

C. A multi-region bucket can only be accessed by users in multiple countries simultaneously; a regional bucket restricts access to users in the same region as the bucket.

D. Regional and multi-region buckets are identical in durability and availability — the only difference is price.

Correct Answer: B

Distractor Analysis:

- Why A is incorrect: A regional bucket stores data in multiple zones within a single region — not just one zone. The distinction is between a single geographic region vs. multiple regions spanning a large geography.
- Why C is incorrect: Cloud Storage bucket access is not restricted by the geographic location of the user. Users anywhere in the world can read objects from any bucket, regardless of location type. Location type affects where data is physically stored, not who can access it.
- Why D is incorrect: Regional and multi-region buckets have meaningful differences in availability SLAs, storage cost, and geographic redundancy. Multi-region buckets are more expensive but provide higher availability for globally distributed access patterns.

## Question 8

Your company enables object versioning on a Cloud Storage bucket to protect against accidental file deletion. Six months later, you notice the storage bill has tripled because the bucket contains hundreds of old noncurrent versions. What is the most operationally efficient solution?

A. Disable versioning to stop creating new versions and manually delete the existing noncurrent versions.

B. Add a lifecycle rule to automatically delete noncurrent versions that are older than 30 days and have at least one newer version.

C. Move all noncurrent versions to Archive storage to reduce costs while keeping them accessible.

D. Delete and recreate the bucket without versioning to remove all noncurrent versions at once.

Correct Answer: B

Distractor Analysis:

- Why A is incorrect: Disabling versioning prevents new versions from being created but does not help the team retain recovery capability for future accidental deletions — which was the original purpose of enabling versioning. A lifecycle rule is the automated, ongoing solution.
- Why C is incorrect: Moving noncurrent versions to Archive storage reduces the per-GB cost but does not solve the unbounded accumulation problem. The bucket will continue to grow with hundreds of noncurrent versions at a lower cost-per-GB but with retrieval fees that could exceed the storage savings. Deletion is the more complete solution.
- Why D is incorrect: Deleting and recreating the bucket destroys all existing objects (both live and noncurrent versions). This is a destructive action that likely violates the original purpose of maintaining recovery capability.

## Question 9

A developer runs `gcloud storage rm gs://my-bucket/important-data.csv` against a bucket that has object versioning enabled. What happens to the file?

A. The file and all its versions are permanently deleted immediately.

B. The file becomes noncurrent; the data is still stored in Cloud Storage and can be recovered.

C. The command fails with an error because versioning prevents deletion of live objects.

D. The file is moved to a soft-delete recycle bin for 7 days before permanent deletion.

Correct Answer: B

Distractor Analysis:

- Why A is incorrect: When versioning is enabled, a `gcloud storage rm` without the `-a` flag does not permanently destroy the data. It inserts a delete marker, making the file appear deleted when listed normally, but the actual object data is preserved as a noncurrent version.
- Why C is incorrect: Object versioning does not block deletion commands. It changes the deletion behavior — instead of immediate permanent deletion, it creates a delete marker — but the command succeeds without error.
- Why D is incorrect: Cloud Storage does not have a separate recycle bin or soft-delete folder. Object versioning itself provides the recovery mechanism, but this is controlled by the versioning system, not a separate recycle bin feature.

## Question 10

You are designing a storage architecture for a media company that hosts user-uploaded videos. Videos are watched frequently in the first 30 days after upload. After 30 days, views drop to roughly once per week. After 6 months, videos are almost never watched (less than once per year). The company wants to minimize storage costs while keeping all videos permanently available. Which lifecycle configuration is most cost-effective?

A. Store all videos in Archive storage from the start to minimize cost.

B. Standard storage class for 0–30 days, transition to Nearline at 30 days, transition to Archive at 180 days.

C. Standard storage class forever; optimize costs by deleting videos after 6 months.

D. Enable Autoclass on the bucket to let GCP manage transitions automatically.

Correct Answer: B

Distractor Analysis:

- Why A is incorrect: Archive storage has the lowest per-GB cost but also the highest retrieval cost and a 365-day minimum storage duration. New videos that are watched frequently in the first 30 days would incur enormous retrieval fees in Archive storage, making it far more expensive than Standard for frequently accessed content.
- Why C is incorrect: Deleting videos after 6 months violates the requirement to keep all videos permanently available. Standard storage for all videos would also be very expensive for content that is rarely accessed after 6 months.
- Why D is incorrect: Autoclass is a valid option and would achieve similar cost optimization automatically. However, option B is the more precise and deterministic answer that maps directly to the access frequency pattern described in the scenario and avoids reliance on actual access events to trigger transitions.
