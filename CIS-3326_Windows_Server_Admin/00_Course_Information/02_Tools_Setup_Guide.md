# 🛠️ Tools & Software Setup Guide: CIS-3326

This course utilizes industry-standard, professional development tools. All required software is free or provided through Texas Wesleyan University student licensing.

---

## 💻 Primary Software Tools
* **Required Platforms:** Windows Server 2022 Evaluation VHD, Oracle VirtualBox, PowerShell 7
* **Installation & Access:** Download free 180-day Microsoft Windows Server 2022 ISO/VHD from Microsoft Evaluation Center and run inside VirtualBox with PowerShell automation.
* **Microsoft Office 365:** Free for all TXWES students via your `txwes.edu` portal. Use Word or PowerPoint to export lab reports as PDF documents.

---

## ⚙️ Workstation Hardware Minimums
* **Operating System:** Windows 10/11 64-bit, macOS 12+ (Apple Silicon or Intel), or Linux (Ubuntu/Debian/Fedora).
* **Memory & Storage:** 8 GB RAM minimum (16 GB recommended), 50 GB available SSD storage.
* **Internet:** Broadband connection for Canvas and cloud access.
