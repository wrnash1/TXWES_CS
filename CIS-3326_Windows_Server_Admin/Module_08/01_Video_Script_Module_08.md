# Video Script: CIS-3326_Windows_Server_Admin (Microsoft Windows Server Administration (Active Directory))
## Module 08 - Backups

---

**Audio:** "A server without a backup is a disaster waiting to happen. Windows Server includes the 'Windows Server Backup' feature. For Domain Controllers, backing up files is not enough. You must perform a 'System State' backup. This backs up the Active Directory database (NTDS.DIT) so that if the server crashes, you can restore the entire forest."
