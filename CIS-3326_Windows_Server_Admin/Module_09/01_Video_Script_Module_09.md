**Video Script 9.1: Centralized Patch Management**
*Audio:* "You don't want 500 computers downloading the same 2GB Windows update from the internet simultaneously. WSUS downloads the updates once to a central server, and all clients pull the updates locally. It also allows administrators to test patches before forcing them onto the network."
