### Question 1
In a Software-Defined Networking architecture, which API is used to communicate between the controller and the application layer?

*   A) Southbound API
*   B) Northbound API
*   C) Eastbound API
*   D) OpenFlow

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
Northbound APIs connect the controller to applications and orchestration tools. Southbound APIs connect to network devices.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    OpenFlow is a southbound protocol.
