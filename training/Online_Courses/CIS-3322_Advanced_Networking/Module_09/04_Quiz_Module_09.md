# Quiz: Module 09 - WAN Technologies & VPNs
## Course: CIS-3322_Advanced_Networking (Cisco CCNA (200-301))

---

### Question 1
Which IPsec component provides data integrity and origin authentication without confidentiality (encryption)?

*   A) ESP
*   B) AH
*   C) IKE
*   D) Diffie-Hellman

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
Authentication Header (AH) handles authentication and integrity. Encapsulating Security Payload (ESP) handles encryption.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    ESP provides encryption. IKE negotiates keys.
