### Question 1
What type of machine learning model is a Random Forest?

*   A) Linear Model
*   B) Single Decision Tree
*   C) Ensemble Model
*   D) Neural Network

---

### Answer Key
*   **Correct Option:** **C**

---

### Explanation
A Random Forest is an ensemble model that combines the predictions of multiple decision trees to improve overall stability.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    It is an ensemble (collection) of trees, not a single tree or linear model.
