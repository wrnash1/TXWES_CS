### Question 1
Which model is appropriate for predicting binary (yes/no) output class labels?

*   A) Linear Regression
*   B) Logistic Regression
*   C) K-Means Clustering
*   D) Principal Component Analysis

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
Logistic regression maps output predictions to a probability between 0 and 1, making it ideal for binary classification.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    Linear regression is for continuous variables. K-Means is for grouping.
