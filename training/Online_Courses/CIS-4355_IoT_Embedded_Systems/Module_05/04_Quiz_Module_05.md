### Question 1
What is the communication pattern utilized in the MQTT protocol?

*   A) Client-Server HTTP
*   B) Publish-Subscribe (Pub/Sub)
*   C) Peer-to-Peer streaming
*   D) File Transfer Protocol

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
Clients publish data to topics on a central broker, which routes the messages to subscribed clients.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    HTTP uses a standard Request-Response pattern.
