**Question 1**
What is the communication pattern utilized in the MQTT protocol?
*   A) Client-Server HTTP
*   B) Publish-Subscribe (Pub/Sub)
*   C) Peer-to-Peer streaming
*   D) File Transfer Protocol
*   **Correct Answer:** B) Clients publish data to topics on a central broker, which routes the messages to subscribed clients.
*   **Distractor Analysis:**
    *   *Why correct:* Clients publish data to topics on a central broker, which routes the messages to subscribed clients.
    *   HTTP uses a standard Request-Response pattern.
