### Question 1
Kruskal's algorithm finds the Minimum Spanning Tree by sorting which properties of the graph first?

*   A) Vertex degrees
*   B) Edge weights
*   C) Path lengths
*   D) Adjacency matrices

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
Kruskal's algorithm is a greedy algorithm that processes edges in ascending order of their weights, checking for cycles.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    Prim's algorithm starts from a root node and expands the tree using local minimum edges.
