### Question 1
Which data structure follows the LIFO (Last-In-First-Out) principle?

*   A) Queue
*   B) Priority Queue
*   C) Stack
*   D) Hash Table

---

### Answer Key
*   **Correct Option:** **C**

---

### Explanation
A Stack works by inserting and removing from the same end, matching Last-In-First-Out behavior.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    Queue is FIFO (First-In-First-Out). Priority Queue removes based on key value, not order. Hash Table uses direct keys.
