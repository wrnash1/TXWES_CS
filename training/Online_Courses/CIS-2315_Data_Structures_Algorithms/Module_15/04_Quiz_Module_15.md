### Question 1
Which data structure is most suitable for implementing autocomplete systems or dictionary prefix matching?

*   A) AVL Tree
*   B) Hash Table
*   C) Trie (Prefix Tree)
*   D) Max Heap

---

### Answer Key
*   **Correct Option:** **C**

---

### Explanation
Tries store characters along branches, sharing common prefixes which allows rapid string prefix searches.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    Hash Table can find exact keys, but cannot efficiently match prefixes.
