### Question 1
What HCL parameter is required inside a module block to define the location of the module code?

*   A) path
*   B) source
*   C) location
*   D) directory

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
The `source` parameter defines where the module code lives (local folder or registry URL).

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    path, location, and directory are not valid HCL parameters.
