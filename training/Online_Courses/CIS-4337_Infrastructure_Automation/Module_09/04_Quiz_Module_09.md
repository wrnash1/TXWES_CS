### Question 1
Which built-in Terraform function retrieves a value from a map given its key?

*   A) find()
*   B) lookup()
*   C) element()
*   D) map()

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
The `lookup(map, key, default)` function queries map variables dynamically.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    element() retrieves items from lists. find() is not a Terraform function.
