### Question 1
Which command downloads and installs the provider plugins defined in your Terraform configuration files?

*   A) terraform apply
*   B) terraform init
*   C) terraform plan
*   D) terraform get

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
`terraform init` initializes the folder, creating directory paths and downloading required provider plugins.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    apply deploys resources. plan creates templates. get fetches modules.
