### Question 1
Which file extension is default for storing variable values in a Terraform project?

*   A) .tf
*   B) .tfvars
*   C) .json
*   D) .hcl

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
Terraform automatically loads variables values from files ending with `.tfvars`.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    .tf stores declarations. .json is alternative layout.
