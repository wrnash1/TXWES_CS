### Question 1
How do you access the last element of a list named `my_list`?

*   A) my_list[0]
*   B) my_list[len(my_list)]
*   C) my_list[-1]
*   D) my_list[last]

---

### Answer Key
*   **Correct Option:** **C**

---

### Explanation
Negative indexing starts from the end of the list. `my_list[-1]` retrieves the last element.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    A is the first element. B causes an IndexError because indices are 0-indexed. D is undefined.
