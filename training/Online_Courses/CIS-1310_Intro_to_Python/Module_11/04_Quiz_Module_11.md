### Question 1
What is the output of `'python'.upper()`?

*   A) Python
*   B) PYTHON
*   C) python
*   D) TypeError

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
The `.upper()` method returns a new string with all lowercase characters converted to uppercase.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    Strings are immutable, but methods return new strings instead of modifying them in-place.
