### Question 1
What keyword is required to modify a variable defined at the module level from inside a function?

*   A) nonlocal
*   B) global
*   C) static
*   D) public

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
The `global` keyword declares that a variable inside the function refers to the module-level namespace.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    nonlocal is for nested/closure scopes. static and public are not used in Python variable scoping.
