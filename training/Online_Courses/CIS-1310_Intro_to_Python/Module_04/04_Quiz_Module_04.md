### Question 1
Which keyword is used to represent 'else if' in Python?

*   A) elseif
*   B) else if
*   C) elif
*   D) otherwise

---

### Answer Key
*   **Correct Option:** **C**

---

### Explanation
Python uses `elif` as the syntax-defined keyword for secondary conditional branches.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    elseif and else if are syntax errors in Python. otherwise is not a Python keyword.
