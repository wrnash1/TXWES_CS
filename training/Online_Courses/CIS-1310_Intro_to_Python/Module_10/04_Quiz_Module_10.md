---

### Question 1
Which dictionary method returns both keys and values as tuples?

*   A) keys()
*   B) values()
*   C) items()
*   D) get()

---

### Answer Key
*   **Correct Option:** **C**

---

### Explanation
The `.items()` method returns a view object containing key-value tuples.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    keys() only returns keys. values() only returns values. get() returns the value of a specific key.
