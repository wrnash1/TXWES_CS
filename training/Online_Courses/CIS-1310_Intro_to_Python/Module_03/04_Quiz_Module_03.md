### Question 1
What is the return type of the `input()` function?

*   A) int
*   B) float
*   C) string
*   D) boolean

---

### Answer Key
*   **Correct Option:** **C**

---

### Explanation
`input()` always returns a string. You must explicitly cast it if you need a numeric value.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    Dynamic typing does not automatically convert text input to integers or floats.
