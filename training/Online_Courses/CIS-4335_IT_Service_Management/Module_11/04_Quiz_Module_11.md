**Question 1**
Which of the following is classified as a Service Request rather than an Incident?
*   A) A printer is printing blank pages
*   B) A user forgot their password and needs a reset
*   C) The database server crashed
*   D) A critical application is throwing errors
*   **Correct Answer:** B) Password resets are routine service requests (requests for access/information). The others represent service disruptions (incidents).
*   **Distractor Analysis:**
    *   *Why correct:* Password resets are routine service requests (requests for access/information). The others represent service disruptions (incidents).
    *   Disruptions are incidents. Normal requests are service requests.
