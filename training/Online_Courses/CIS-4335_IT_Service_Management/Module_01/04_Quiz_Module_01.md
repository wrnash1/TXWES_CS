**Question 1**
What is the primary focus of ITIL 4?
*   A) Writing software code
*   B) Co-creating value through service relationships
*   C) Virtualization technologies
*   D) Relational database indexing
*   **Correct Answer:** B) ITIL 4 shifts focus from simple service delivery to active value co-creation between provider and consumer.
*   **Distractor Analysis:**
    *   *Why correct:* ITIL 4 shifts focus from simple service delivery to active value co-creation between provider and consumer.
    *   It is an administrative/managerial framework, not a software development tool.
