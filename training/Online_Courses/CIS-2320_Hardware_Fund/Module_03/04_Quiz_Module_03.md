### Question 1
Which CPU socket type features pins located on the motherboard rather than the processor itself?

*   A) PGA
*   B) LGA
*   C) BGA
*   D) DIP

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
Land Grid Array (LGA) has pins on the socket. Pin Grid Array (PGA) has pins on the CPU.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    BGA is soldered. DIP is an old integrated circuit package format.
