### Question 1
What format is typically used to exchange model prediction input payloads over HTTP APIs?

*   A) XML
*   B) JSON
*   C) CSV
*   D) SQL Data

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
REST APIs typically use JSON format to structure features and return class labels or scores.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    JSON is the standard format for modern HTTP REST requests.
