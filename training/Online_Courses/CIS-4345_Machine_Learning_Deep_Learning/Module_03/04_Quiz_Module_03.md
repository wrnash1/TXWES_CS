### Question 1
Which mathematical function maps real number inputs to a probability value between 0 and 1 in logistic regression?

*   A) Linear function
*   B) Sigmoid (Logistic) function
*   C) Step function
*   D) Relu function

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
The sigmoid function (1 / (1 + e^-x)) outputs values bounded between 0 and 1, representing probabilities.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    Linear function can return infinite outputs. ReLU is max(0, x).
