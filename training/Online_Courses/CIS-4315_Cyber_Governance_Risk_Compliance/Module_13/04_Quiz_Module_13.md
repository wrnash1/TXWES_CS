# Quiz: Module 13 - Vendor Risk Management
## Course: CIS-4315_Cyber_Governance_Risk_Compliance (ISACA Certified Information Security Manager (CISM))

---

### Question 1
What is the key difference between a SOC 2 Type I and a SOC 2 Type II report?

*   A) Type I covers security
*   B) Type I assesses control design at a point in time; Type II evaluates operational effectiveness over a period of time
*   C) Type I is public; Type II is confidential
*   D) Type I is for software; Type II is for hardware

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
Type II reports provide audit evidence confirming that controls were actively working over a testing window (usually 6-12 months).

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    Type I only checks if controls were documented and set up on a specific date.
