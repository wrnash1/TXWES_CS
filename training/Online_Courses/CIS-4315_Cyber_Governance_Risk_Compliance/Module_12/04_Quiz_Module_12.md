# Quiz: Module 12 - Security Auditing Procedures
## Course: CIS-4315_Cyber_Governance_Risk_Compliance (ISACA Certified Information Security Manager (CISM))

---

### Question 1
What is the primary purpose of an IT security audit?

*   A) To write clean code
*   B) To evaluate system operations and verify controls align with regulatory policies and design objectives
*   C) To speed up database loops
*   D) To purchase firewalls

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
Auditors independently verify that documented security policies and control systems are actually operating as intended.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    It is an validation check, not a development or purchasing role.
