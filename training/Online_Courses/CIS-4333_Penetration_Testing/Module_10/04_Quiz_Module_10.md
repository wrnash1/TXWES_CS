### Question 1
What web vulnerability allows an attacker to append file paths to a URL parameter to retrieve unauthorized server files?

*   A) Directory Traversal
*   B) SQL Injection
*   C) Cross-Site Scripting
*   D) Buffer Overflow

---

### Answer Key
*   **Correct Option:** **A**

---

### Explanation
Directory Traversal uses dot-dot-slash (`../`) parameters to escape web document roots.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    SQLi targets sql queries. XSS targets client scripts.
