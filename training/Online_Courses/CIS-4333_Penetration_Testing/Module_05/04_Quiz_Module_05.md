### Question 1
What is it called when a vulnerability scanner reports a security issue that does not actually exist on the target system?

*   A) False Negative
*   B) False Positive
*   C) True Positive
*   D) Null Match

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
False Positives occur when scanning rules mismatch background states and assume a vulnerability is present.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    False Negatives are when real issues are missed by the scanner.
