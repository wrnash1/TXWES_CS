**Question 1**
What does the term Shift-Left mean in DevSecOps methodology?
*   A) Moving the development team to another room
*   B) Integrating security practices, scanning, and testing earlier in the software development lifecycle
*   C) Postponing testing until production
*   D) Aligning script text to the left margin
*   **Correct Answer:** B) Shift-left brings security scanners directly into the developer's commit pipeline, resolving issues before deployments occur.
*   **Distractor Analysis:**
    *   *Why correct:* Shift-left brings security scanners directly into the developer's commit pipeline, resolving issues before deployments occur.
    *   It refers to workflow timing, not physical location or code formatting.
