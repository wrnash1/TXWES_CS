### Question 1
Which element in a Data Flow Diagram represents a person, organization, or external system that sends or receives data but is outside the boundary of the system?

*   A) Process
*   B) Data Store
*   C) External Entity (Terminator)
*   D) Data Flow Link

---

### Answer Key
*   **Correct Option:** **C**

---

### Explanation
External entities act as sources or destinations of information crossing system boundaries.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    Data stores represent persistent tables or files inside the system.
