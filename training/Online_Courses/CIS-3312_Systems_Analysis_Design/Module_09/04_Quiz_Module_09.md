# Quiz: Module 09 - User Interface Design
## Course: CIS-3312_Systems_Analysis_Design (IIBA Entry Certificate in Business Analysis (ECBA))

---

### Question 1
What is the primary objective of User Interface design?

*   A) To write sql queries
*   B) To make interactions user-friendly, efficient, and intuitive for final users
*   C) To minimize CPU load
*   D) To compile web server configurations

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
UI/UX design is concerned with usability, accessibility, and facilitating user tasks efficiently.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    It targets human interaction interfaces rather than backend logic compilation.
