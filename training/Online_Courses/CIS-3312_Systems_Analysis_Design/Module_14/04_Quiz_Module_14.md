**Question 1**
Which conversion strategy is the lowest risk because both the old and new systems are run simultaneously for a period of time?
*   A) Direct Cutover
*   B) Parallel Conversion
*   C) Phased Conversion
*   D) Pilot Conversion
*   **Correct Answer:** B) Parallel conversion allows verification of new outputs against the old system, fallback is immediate if failures occur.
*   **Distractor Analysis:**
    *   *Why correct:* Parallel conversion allows verification of new outputs against the old system, fallback is immediate if failures occur.
    *   Direct cutover drops the old system immediately, presenting high risk.
