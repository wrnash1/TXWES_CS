# Quiz: Module 03 - Requirement Gathering
## Course: CIS-3312_Systems_Analysis_Design (IIBA Entry Certificate in Business Analysis (ECBA))

---

### Question 1
Which item represents a non-functional system requirement?

*   A) The system must send an email receipt on checkout
*   B) The user must login using their email address
*   C) The database query must return results within 2 seconds
*   D) The system must export reports in PDF

---

### Answer Key
*   **Correct Option:** **C**

---

### Explanation
Non-functional requirements specify operational qualities (performance, security, usability) rather than specific feature tasks.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    Sending emails and logging in represent specific functional operations.
