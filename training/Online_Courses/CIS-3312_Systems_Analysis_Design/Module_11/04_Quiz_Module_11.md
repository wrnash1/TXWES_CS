### Question 1
Which form validation rule verifies that a value has actually been entered and is not left blank?

*   A) Range Check
*   B) Presence (Completeness) Check
*   C) Format Check
*   D) Consistency Check

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
Presence checks verify that required fields contain data before submissions are processed.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    Range checks verify if numbers fall inside specific boundaries.
