**Question 1**
Which UML concept involves grouping data fields and the operations that modify them into a single class container to restrict direct access?
*   A) Inheritance
*   B) Encapsulation
*   C) Polymorphism
*   D) Abstraction
*   **Correct Answer:** B) Encapsulation protects object state by hiding internal data and requiring updates through public methods.
*   **Distractor Analysis:**
    *   *Why correct:* Encapsulation protects object state by hiding internal data and requiring updates through public methods.
    *   Polymorphism handles interface execution variance. Inheritance defines subclass lines.
