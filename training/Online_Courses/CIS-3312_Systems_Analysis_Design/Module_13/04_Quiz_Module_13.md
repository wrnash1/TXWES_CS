# Quiz: Module 13 - System Integration & Testing

### Question 1
Which testing type is conducted by actual business users in their operational environment to verify the system meets business objectives?

*   A) Unit Testing
*   B) Alpha Testing
*   C) User Acceptance Testing (UAT)
*   D) Regression Testing

---

### Answer Key
*   **Correct Option:** **C**

---

### Explanation
UAT validates operational readiness and is the final step before the system is signed off for production release.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    Alpha testing is internal testing by the development team.
