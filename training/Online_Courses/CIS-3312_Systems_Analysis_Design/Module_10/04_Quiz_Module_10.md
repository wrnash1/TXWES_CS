**Question 1**
What is the primary requirement for a database table to conform to Third Normal Form (3NF)?
*   A) It must be in 2NF and contain no transitive dependencies (no non-key column depends on another non-key column)
*   B) It must contain no null values
*   C) It must use integer primary keys
*   D) It must contain multiple tables
*   **Correct Answer:** A) 3NF removes dependencies between non-primary key columns, eliminating redundant data modification anomalies.
*   **Distractor Analysis:**
    *   *Why correct:* 3NF removes dependencies between non-primary key columns, eliminating redundant data modification anomalies.
    *   Null values are allowed in 3NF under appropriate designs.
