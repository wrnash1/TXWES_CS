# Quiz: Module 12 - Data Analysis Methods
## Course: CIS-4336_Data_Analytics (CompTIA Data+)

---

### Question 1
Which analysis method groups users based on a shared characteristic or start date to track behavior over time?

*   A) Churn Analysis
*   B) Cohort Analysis
*   C) Outlier Analysis
*   D) Regression Analysis

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
Cohort analysis tracks defined groups over time to identify usage or drop-off trends.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    Churn only tracks cancellations.
