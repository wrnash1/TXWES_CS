# Quiz: Module 02 - Database Structures & Schemas
## Course: CIS-4336_Data_Analytics (CompTIA Data+)

---

### Question 1
In database design, which key uniquely identifies each row within its own table?

*   A) Foreign Key
*   B) Primary Key
*   C) Candidate Key
*   D) Composite Key

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
A Primary Key enforces entity integrity by uniquely identifying table rows.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    Foreign keys link rows in separate tables.
