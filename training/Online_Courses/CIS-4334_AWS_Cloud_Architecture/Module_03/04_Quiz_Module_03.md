### Question 1
What VPC component is required to route traffic from a public subnet out to the public internet?

*   A) NAT Gateway
*   B) Internet Gateway (IGW)
*   C) Customer Gateway
*   D) Direct Connect

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
An Internet Gateway links the VPC to the public internet, enabling bidirectional communication.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    NAT Gateway provides outbound-only internet access for private subnets.
