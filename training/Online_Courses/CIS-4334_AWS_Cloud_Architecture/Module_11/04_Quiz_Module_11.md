### Question 1
Which service should you check to audit who made an API call to terminate an EC2 instance?

*   A) Amazon CloudWatch
*   B) AWS CloudTrail
*   C) AWS Systems Manager
*   D) Amazon Inspector

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
CloudTrail records all API activity, user logins, and console actions across AWS accounts.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    CloudWatch collects metrics and performance logs.
