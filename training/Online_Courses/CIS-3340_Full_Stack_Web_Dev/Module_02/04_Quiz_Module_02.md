### Question 1
Which CSS property converts an element into a grid container?

*   A) display: grid
*   B) layout: grid
*   C) grid-template: true
*   D) position: relative

---

### Answer Key
*   **Correct Option:** **A**

---

### Explanation
Setting display: grid instructs the rendering engine to compute nested children as grid items.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    display is the core CSS layout configuration property.
