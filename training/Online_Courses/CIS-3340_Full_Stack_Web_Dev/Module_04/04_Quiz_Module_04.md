### Question 1
Which DOM query method retrieves all page elements matching a class identifier?

*   A) document.getElementById()
*   B) document.querySelector()
*   C) document.querySelectorAll()
*   D) document.classList()

---

### Answer Key
*   **Correct Option:** **C**

---

### Explanation
querySelectorAll returns a NodeList of all page elements matching the provided CSS selector.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    querySelector only returns the first matching node.
