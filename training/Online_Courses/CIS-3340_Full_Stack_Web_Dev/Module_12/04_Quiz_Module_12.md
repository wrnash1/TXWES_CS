### Question 1
Which React Hook is used to add local state variables to functional components?

*   A) useEffect
*   B) useContext
*   C) useState
*   D) useStateVariable

---

### Answer Key
*   **Correct Option:** **C**

---

### Explanation
The useState hook returns a state value and a setter function to trigger re-renders.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    useEffect handles side effects. useContext handles global context.
