### Question 1
Which data format does MongoDB use natively to store documents in collections?

*   A) XML
*   B) CSV
*   C) BSON (Binary JSON)
*   D) SQL Table Structure

---

### Answer Key
*   **Correct Option:** **C**

---

### Explanation
MongoDB processes data objects as BSON, an optimized binary representation of JSON files.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    BSON supports more data types (such as dates) than plain JSON.
