### Question 1
Which HTTP status code class indicates a server-side processing error occurred?

*   A) 2xx
*   B) 3xx
*   C) 4xx
*   D) 5xx

---

### Answer Key
*   **Correct Option:** **D**

---

### Explanation
5xx status codes (e.g. 500 Internal Server Error) represent backend processing failures.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    4xx is for client-side input errors (e.g. 404 Not Found).
