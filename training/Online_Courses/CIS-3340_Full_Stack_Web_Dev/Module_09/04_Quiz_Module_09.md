### Question 1
Which SQL constraint uniquely identifies each record in a database table?

*   A) FOREIGN KEY
*   B) UNIQUE INDEX
*   C) PRIMARY KEY
*   D) DEFAULT

---

### Answer Key
*   **Correct Option:** **C**

---

### Explanation
The PRIMARY KEY constraint enforces unique, non-null values for the primary database identifier column.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    FOREIGN KEY links rows to parent tables.
