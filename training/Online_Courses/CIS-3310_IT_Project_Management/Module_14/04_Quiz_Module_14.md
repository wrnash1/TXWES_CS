# Quiz: Module 14 - Project Change Control
## Course: CIS-3310_IT_Project_Management (CompTIA Project+ / PMI CAPM)

---

### Question 1
What is the primary role of a Change Control Board (CCB) in project management?

*   A) To write programming code
*   B) To review, evaluate, and approve or reject requested project scope modifications
*   C) To buy software licenses
*   D) To hire developers

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
The CCB is a formal group of stakeholders that verifies changes before they are integrated into baselines.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    CCB handles scope governance, not raw development.
