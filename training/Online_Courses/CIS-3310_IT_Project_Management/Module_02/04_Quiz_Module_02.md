# Quiz: Module 02 - Project Charter Development
## Course: CIS-3310_IT_Project_Management (CompTIA Project+ / PMI CAPM)

---

### Question 1
Which document authorizes the formal existence of a project and gives the project manager authority to apply resources?

*   A) Project Scope Statement
*   B) Project Charter
*   C) Work Breakdown Structure
*   D) Statement of Work (SOW)

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
The Project Charter is signed by sponsors to initiate the project and authorize resources.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    Scope statement defines deliverables. WBS is a decomposition tree.
