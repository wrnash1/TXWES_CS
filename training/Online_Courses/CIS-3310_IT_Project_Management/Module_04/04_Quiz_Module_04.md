**Question 1**
Which dependency type describes a scenario where Task B cannot start until Task A has completed?
*   A) Start-to-Start (SS)
*   B) Finish-to-Start (FS)
*   C) Finish-to-Finish (FF)
*   D) Start-to-Finish (SF)
*   **Correct Answer:** B) Finish-to-Start is the most common scheduling linkage; preceding activity must end before successor begins.
*   **Distractor Analysis:**
    *   *Why correct:* Finish-to-Start is the most common scheduling linkage; preceding activity must end before successor begins.
    *   Start-to-Start requires both tasks to begin concurrently.
