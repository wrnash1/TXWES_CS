---

### Question 1
Which behavioral design pattern defines a one-to-many dependency between objects so that when one object changes state, all its dependents are notified?

*   A) Adapter Pattern
*   B) Decorator Pattern
*   C) Observer Pattern
*   D) Strategy Pattern

---

### Answer Key
*   **Correct Option:** **C**

---

### Explanation
The Observer pattern enables decoupling pub-sub mechanisms where subjects notify observers without tight linkages.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    Adapter links mismatched interfaces. Decorator adds behavior dynamically.
