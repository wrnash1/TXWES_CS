### Question 1
In Gitflow workflow, which branch contains production-ready code that is deployed to live systems?

*   A) develop
*   B) feature
*   C) main (master)
*   D) hotfix

---

### Answer Key
*   **Correct Option:** **C**

---

### Explanation
The main/master branch holds the stable, tested, production-released codebase.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    develop branch aggregates feature branches under active development.
