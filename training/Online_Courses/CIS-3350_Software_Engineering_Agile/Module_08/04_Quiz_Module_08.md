**Question 1**
Which level of testing focuses on validating that individual functions, methods, or classes behave correctly in isolation?
*   A) Unit Testing
*   B) Integration Testing
*   C) System Testing
*   D) Acceptance Testing
*   **Correct Answer:** A) Unit testing tests smallest testable parts (units) of an application independently from database or network APIs.
*   **Distractor Analysis:**
    *   *Why correct:* Unit testing tests smallest testable parts (units) of an application independently from database or network APIs.
    *   Integration testing verifies interface communication between modules.
