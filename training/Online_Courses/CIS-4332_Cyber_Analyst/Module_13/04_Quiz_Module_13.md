### Question 1
Which data source should be collected FIRST during forensic collection due to its volatility?

*   A) HDD storage
*   B) CPU Registers and RAM
*   C) Log files on disk
*   D) Print server spool queue

---

### Answer Key
*   **Correct Option:** **B**

---

### Explanation
Memory and processor state volatile data is lost immediately on shutdown, placing them first in the order of volatility.

---

### Distractor Analysis
*   **Why the incorrect options are wrong:**
    Disk storage can survive power loss.
