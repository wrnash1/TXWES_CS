# Video Script: CIS-4327_Database_Admin (Google Cloud Associate Database Engineer)
## Module 07 - Terraform

---

**Audio:** "Clicking through the Google Cloud Console is fine for learning, but it is terrible for production. If you accidentally delete a database, it takes hours to remember all the settings to recreate it. Instead, we use Infrastructure as Code, specifically Terraform. You write a text file defining your Cloud SQL instance, run `terraform apply`, and the API builds it perfectly every time."
