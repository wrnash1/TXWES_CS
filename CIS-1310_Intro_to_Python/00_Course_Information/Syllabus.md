## Course Overview

### Course Description
Introduction to Python programming, variables, control flow, loops, functions, data structures, and Object-Oriented Programming (OOP).

### Course Objectives / Student Learning Outcomes
By the end of this course, students will be able to:
1. Explain and configure core principles of **PCAP (Certified Associate in Python Programming)** in a variety of business and technical scenarios.
2. Formulate, execute, and verify terminal-based commands and administrative configurations matching production-level operations.
3. Critically analyze system failures or security vulnerabilities, and propose mitigation strategies.
4. Prepare for and demonstrate competency aligned with the official **PCAP (Certified Associate in Python Programming)** certification exam blueprint.

## Course Calendars & Blueprint
Below is the week-by-week layout of topics and assignments:

*   **Module 01:** Python Basics & Local Environment
*   **Module 02:** Literals, Operators, and Expressions
*   **Module 03:** Variables and Basic I/O
*   **Module 04:** Control Flow - Conditional Statements
*   **Module 05:** Loops - Iteration with While and For
*   **Module 06:** Bitwise Operations and Lists
*   **Module 07:** Advanced List Operations
*   **Module 08:** Functions and Parameter Passing
*   **Module 09:** Scopes, Namespaces, and Recursion
*   **Module 10:** Tuples and Dictionaries
*   **Module 11:** String Methods and Operations
*   **Module 12:** Exception Handling
*   **Module 13:** Modules and Packages
*   **Module 14:** Object-Oriented Programming (OOP) Basics
*   **Module 15:** Advanced OOP: Inheritance and Polymorphism
*   **Module 16:** Final Exam Prep & Certification Exam (PCAP (Certified Associate in Python Programming))
