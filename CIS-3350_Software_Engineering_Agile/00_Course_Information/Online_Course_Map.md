# Online Course Map: CIS-3350 – Software Engineering and Agile

## Texas Wesleyan University | 16-Week Schedule

---

## How to Use This Map

This document shows the full 16-week course arc organized by theme. Each module links to its five deliverables: Video Script, Reading Guide, Lab, Quiz, and Discussion. Use this map to see how modules connect, plan study time around exam weeks, and understand how course themes build on one another.

PSM I certification exam scheduling: students are encouraged to schedule their exam during or after Week 16. Consistent 90%+ scores on the free Scrum.org Open Assessment (linked in Module 16) is the readiness benchmark.

---

## Theme 1: Foundations (Weeks 1–3)

These modules establish the vocabulary and philosophical framework for the entire course. Every subsequent module builds on these concepts.

### Week 1 — Module 01: Software Engineering Overview and SDLC Models

* Core concepts: SDLC phases, Waterfall, Spiral, Iterative, Agile models
* PSM I connection: Why Scrum exists as a response to the limitations of plan-driven models
* Lab focus: SDLC comparison matrix and risk identification exercise
* Key reading: Scrum Guide "Scrum Theory" section; Agile Manifesto 12 Principles

### Week 2 — Module 02: Agile Manifesto and the 12 Principles

* Core concepts: Four Agile values, 12 principles, sustainable pace, customer collaboration
* PSM I connection: Manifesto values are tested by paraphrase; know all four value pairs
* Lab focus: Mapping 12 principles to Scrum events; stakeholder scenario analysis
* Key reading: agilemanifesto.org (values page and principles page — both required)

### Week 3 — Module 03: Scrum Framework — Roles, Events, Artifacts

* Core concepts: Three accountabilities, five events with timeboxes, three artifacts with commitments
* PSM I connection: Highest-density exam content — memorize all timeboxes and artifact-commitment pairs
* Lab focus: Scrum accountability map; event-timebox table; artifact-commitment pairs
* Key reading: Complete Scrum Guide (2020) — entire document

---

## Theme 2: Scrum in Practice (Weeks 4–6)

These modules shift from Scrum theory to hands-on event facilitation and backlog management.

### Week 4 — Module 04: Scrum in Practice — Sprint Planning and Daily Scrum

* Core concepts: Sprint Goal, Sprint Backlog ownership, Daily Scrum purpose and attendees
* PSM I connection: Daily Scrum is for Developers only; Sprint Goal is the Sprint Backlog commitment
* Lab focus: Simulated Sprint Planning; mock Daily Scrum; anti-pattern identification
* Key reading: Scrum Guide "Sprint Planning" and "Daily Scrum" sections

### Week 5 — Module 05: Sprint Review and Retrospective

* Core concepts: Sprint Review vs. Retrospective purpose and attendees; Increment and Definition of Done
* PSM I connection: Sprint Review is not a demo or gate; Retrospective produces at least one improvement
* Lab focus: Simulated Sprint Review; Start-Stop-Continue Retrospective; event classification exercise
* Key reading: Scrum Guide "Sprint Review," "Sprint Retrospective," and "Increment" sections

### Week 6 — Module 06: Product Backlog — Creation and Refinement

* Core concepts: Product Goal, backlog ordering, refinement as ongoing activity (not a Scrum event)
* PSM I connection: Refinement is not the sixth Scrum event; Product Owner alone orders the backlog
* Lab focus: Building an initial Product Backlog; refinement session; Product Goal drafting
* Key reading: Scrum Guide "Product Backlog" and "Product Goal" sections

---

## Theme 3: Agile Engineering Practices (Weeks 7–9)

These modules cover the technical and estimation practices that make Scrum's Sprint commitments achievable.

### Week 7 — Module 07: User Stories and Acceptance Criteria

* Core concepts: User story format, INVEST criteria, acceptance criteria, story splitting
* PSM I connection: User stories are not required by the Scrum Guide; acceptance criteria vs. Definition of Done
* Lab focus: Writing user stories; Given-When-Then acceptance criteria; INVEST scoring
* Key reading: Agile Alliance user story glossary; Cucumber BDD documentation

### Week 8 — Module 08: Estimation — Story Points and Planning Poker

* Core concepts: Relative estimation, Fibonacci scale, Planning Poker mechanics, velocity
* PSM I connection: Velocity is a planning tool, not a performance metric; estimates belong to Developers
* Lab focus: Planning Poker session; velocity calculation; anti-pattern identification
* Key reading: Agile Alliance story points glossary; Mountain Goat Software Planning Poker guide

**Midterm Exam (after Week 8) — Covers Modules 01–08**

### Week 9 — Module 09: Kanban and Lean Principles

* Core concepts: Kanban board, WIP limits, cycle time, Lean waste, pull systems
* PSM I connection: Kanban vs. Scrum structural differences; Scrumban and hybrid considerations
* Lab focus: Building a Kanban board; cycle time calculation; Lean waste identification
* Key reading: Kanban Guide for Scrum Teams (Scrum.org)

---

## Theme 4: Software Engineering Fundamentals (Weeks 10–11)

These modules cover classical software engineering techniques that complement Agile practices.

### Week 10 — Module 10: Requirements Engineering and Use Cases

* Core concepts: Functional vs. non-functional requirements, use case format, requirements traceability
* PSM I connection: Product Backlog replaces requirements documents; NFRs belong in the Definition of Done
* Lab focus: Requirements elicitation; use case writing; requirements-to-backlog mapping
* Key reading: Agile Alliance use case glossary; IEEE 830 requirements overview

### Week 11 — Module 11: Software Design Patterns

* Core concepts: Gang of Four pattern categories (Creational, Structural, Behavioral); Singleton, Factory Method, Observer, Strategy
* PSM I connection: Technical excellence enables sustainable Sprint velocity; patterns reduce coupling
* Lab focus: Pattern identification in code; Singleton implementation; Observer implementation
* Key reading: Refactoring.Guru design patterns (Singleton, Factory Method, Observer, Strategy pages)

---

## Theme 5: Quality and Automation (Weeks 12–13)

These modules establish the technical practices that enable a reliable Definition of Done every Sprint.

### Week 12 — Module 12: Test-Driven Development (TDD) and BDD

* Core concepts: Red-Green-Refactor cycle, Given-When-Then BDD, unit tests, test coverage
* PSM I connection: TDD builds automated test coverage that enforces the Definition of Done
* Lab focus: Red-Green-Refactor practice cycles; BDD scenario writing; pytest coverage reporting
* Key reading: Agile Alliance TDD and BDD glossary entries

### Week 13 — Module 13: Continuous Integration and DevOps Basics

* Core concepts: CI, Continuous Delivery, Continuous Deployment, CI/CD pipeline stages
* PSM I connection: CI enforces the DoD's automated test requirements on every commit
* Lab focus: CI simulation script; pipeline diagram; pipeline failure analysis
* Key reading: Martin Fowler's Continuous Integration article

---

## Theme 6: Scaling and Metrics (Weeks 14–15)

These modules extend Scrum beyond single teams and introduce evidence-based measurement.

### Week 14 — Module 14: Scaled Agile — SAFe and LeSS Overview

* Core concepts: SAFe ART structure, PI Planning, LeSS minimalism, Scrum of Scrums
* PSM I connection: Scaling should extend Scrum, not replace it; PI Planning vs. Sprint Planning
* Lab focus: SAFe-to-Scrum role mapping; LeSS structure design; scaling challenge analysis
* Key reading: LeSS framework overview (less.works); SAFe overview (scaledagileframework.com)

### Week 15 — Module 15: Software Project Metrics and Velocity Tracking

* Core concepts: Velocity, Sprint Burndown, Release Burndown, Cumulative Flow Diagram, lead time
* PSM I connection: Metrics serve transparency — not surveillance; velocity is not cross-team comparable
* Lab focus: Velocity calculation and charting; release burndown projection; metrics misuse identification
* Key reading: Evidence-Based Management Guide (Scrum.org)

---

## Theme 7: Integration and Certification Prep (Week 16)

### Week 16 — Module 16: Final Exam Prep and PSM I Certification

* Core concepts: Empiricism (Transparency, Inspection, Adaptation), Scrum values, complete framework review
* PSM I connection: Full PSM I exam readiness; Open Assessment practice; exam strategy
* Lab focus: Scrum.org Open Assessment; self-assessment confidence matrix; scenario question practice
* Key reading: Complete Scrum Guide (2020) — full re-read from start to finish

**Final Exam (Week 16) — Covers Modules 01–16, PSM I-style scenario questions**
