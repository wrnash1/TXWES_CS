# Course Administration Pack: CIS-2315 Data Structures & Algorithms
**Target Certification:** Technical Interview Readiness (LeetCode / HackerRank)

## Course Description
This course covers the essential data structures and algorithms required to succeed in technical coding interviews at top technology companies. Students will develop fluency with Big-O analysis, fundamental data structures (arrays, linked lists, trees, graphs, hash tables), and core algorithmic techniques (sorting, searching, recursion, dynamic programming, and greedy methods). It is aligned with the problem types and evaluation criteria used on LeetCode, HackerRank, and similar platforms.

## Required Materials
1. **Zero Textbook Cost (ZTC):** All materials are free in Canvas. Primary readings draw from open-access resources including [Visualgo](https://visualgo.net), [NeetCode.io](https://neetcode.io), and the [LeetCode Explore](https://leetcode.com/explore/) section.
2. A computer with Python or Java installed and access to LeetCode.com (free tier).

## Grading Policy
*   Algorithm Quizzes: 30%
*   Coding Challenge Labs: 40%
*   Final Coding Interview Assessment: 30%
