Part 1: Install Cisco Packet Tracer

Cisco Packet Tracer is a network simulation tool that lets you build, configure, and troubleshoot virtual networks without physical hardware. It is free from Cisco's NetAcad platform.

Step 1: Create a Free Cisco NetAcad Account

  1. Go to www.netacad.com
  2. Click Sign Up (top right)
  3. Select Continue as a Learner
  4. Fill in your name, email, and create a password
  5. Verify your email address (check spam if you don't see it)

Use your personal email for this account — you'll keep it after graduation.

Step 2: Download Cisco Packet Tracer

  1. Log in at netacad.com
  2. Click your profile icon (top right) → My NetAcad
  3. Search for "Packet Tracer" in the course catalog
  4. Enroll in the free "Introduction to Packet Tracer" course (this gives you the download)
  5. Go to Resources within the course and download the installer for your operating system:
    • Windows: .exe installer
    • macOS: .dmg file
    • Linux: .deb or .rpm package
  6. Run the installer and follow the prompts (accept defaults)

Step 3: Verify Packet Tracer Launches Correctly

  1. Open Cisco Packet Tracer from your Start Menu / Applications folder
  2. Log in with your NetAcad account credentials when prompted
  3. The main workspace should open with a toolbar on the left and a blank canvas
  4. Drag a PC and a switch onto the canvas as a quick test
  5. If they appear, Packet Tracer is working correctly
Success check: You should see the Packet Tracer workspace with a device toolbar on the lower-left. If you can drag a device onto the canvas, you're ready for Module 01's lab.

Part 2: Install Oracle VirtualBox

Oracle VirtualBox is a free virtual machine manager that lets you run a complete operating system (Windows Server, Linux) inside a window on your computer. It is used in select modules for OS and server configuration labs.

Step 1: Check Your Hardware

Before installing, confirm your computer meets the requirements:

  • RAM: 8 GB minimum (16 GB strongly recommended for comfortable use)
  • Disk Space: 50 GB free (VM images are large)
  • Processor: Any modern Intel or AMD processor from the last 6 years
  • Virtualization: Must be enabled in BIOS (Intel VT-x or AMD-V)

To check RAM on Windows: Press Win + R, type dxdiag, press Enter. Look for "Memory" in the System tab.

Step 2: Enable Virtualization in BIOS (if not already enabled)

Most computers have virtualization enabled by default. If VirtualBox gives you a warning about it:

  1. Restart your computer
  2. Press the BIOS key during startup (usually F2, F10, Del, or Esc — varies by manufacturer)
  3. Look for Virtualization Technology, Intel VT-x, or AMD-V in the CPU or Advanced settings
  4. Set it to Enabled
  5. Save and exit (usually F10)

Not sure which key? Search: "[your laptop brand] enable virtualization BIOS"

Step 3: Download and Install VirtualBox

  1. Go to virtualbox.org/wiki/Downloads
  2. Under "VirtualBox platform packages" click the link for your OS:
    • Windows: Windows hosts
    • macOS Intel: macOS / Intel hosts
    • macOS Apple Silicon (M1/M2/M3): macOS / Apple Silicon hosts (use the ARM version)
    • Linux: choose your distribution
  3. Also download the VirtualBox Extension Pack (same page, click "All supported platforms")
  4. Run the VirtualBox installer first, accept all defaults
  5. After installation, open VirtualBox and go to File → Tools → Extension Pack Manager → Install to add the Extension Pack

Step 4: Verify VirtualBox Launches

  1. Open Oracle VirtualBox from your Start Menu / Applications
  2. The main VirtualBox Manager window opens with an empty VM list
  3. Click New to confirm the VM creation wizard opens (you don't need to create one now)
  4. Cancel the wizard and close
Success check: VirtualBox Manager opens without errors and you can see the "New" button. VM images for specific labs will be provided in the module instructions when needed.

Troubleshooting VirtualBox

ProblemSolution
"VT-x/AMD-V hardware acceleration is not available"Enable virtualization in BIOS (Step 2 above).
Installation fails on Windows (error 0x80004005)Run the installer as Administrator: right-click → "Run as administrator."
VirtualBox won't install on macOS (Sequoia / Ventura)Go to System Settings → Privacy & Security → allow the Oracle kernel extension.
VM runs very slowlyIncrease the VM's RAM in Settings → System. Close other applications. Enable 3D acceleration if available.
Mac with Apple Silicon (M1/M2/M3)Download the ARM version from VirtualBox downloads. Some Windows VM images may not be available — contact Professor Nash for alternative lab instructions.
