APA 7 Citation Guide

Texas Wesleyan University | Quick Reference for This Course

Several assignments in this course (Discussions, and some Lab written responses) ask you to reference outside sources — vendor documentation, RFCs, NIST/CompTIA materials, or other credible technical resources. Texas Wesleyan uses APA 7th Edition formatting. This page covers the basics you'll need for this course; it is not a complete APA manual.

In-Text Citations

When you reference a source within a sentence, cite the author (or organization) and year:

According to NIST (2020), a strong password policy should prioritize length over complexity.

If quoting directly, include a page or paragraph number where available:

"Length is the primary factor in password strength" (NIST, 2020, para. 4).

If a source has no clear individual author (common for vendor/standards documentation), use the organization name as the author:

The OSI model defines seven distinct layers of network communication (Cisco, 2023).

Reference List Entries

Every source cited in-text must appear in a Reference list at the end of your post or document. Common formats you'll use in this course:

Website / Organization Page:

Organization Name. (Year). Title of page. Site Name. URL

Example:

Cisco. (2023). Understanding the OSI model. Cisco Networking Academy. https://www.netacad.com/

Government / Standards Document:

Agency Name. (Year). Title of document (Publication No. if available). URL

Example:

National Institute of Standards and Technology. (2020). Digital identity guidelines (SP 800-63B). https://pages.nist.gov/800-63-3/sp800-63b.html

Online Video:

Creator Name or Channel. (Year, Month Day). Title of video [Video]. Platform. URL

Example:

Messer, P. (2023, March 1). OSI model — CompTIA Network+ N10-009 [Video]. YouTube. https://www.youtube.com

Common Mistakes to Avoid

  • Don't cite a source in your Reference list that you never actually mentioned in your post — every reference must be cited in-text somewhere.
  • Don't use a bare URL as your only citation — always include an author/organization and year where you can find one.
  • Don't confuse APA with MLA — APA uses (Author, Year) in-text; MLA uses (Author Page).
