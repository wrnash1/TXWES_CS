# Module 03: Transaction Management, Concurrency & Recovery — Reading Guide & Lecture Notes
**Course:** CSC-6365 — Advanced Database Systems and Data Architectures  
**Texas Wesleyan University — MCS Program**  

## 1. Modular Objectives
- Critically evaluate principles governing Transaction Management, Concurrency & Recovery.
- Implement and measure empirical performance characteristics under real-world workload constraints.

## 2. Required Graduate Readings
- Selected seminal papers from IEEE Transactions on Computers and ACM Transactions on Computer Systems (TOCS).
- Core Textbook Chapters: Modern Graduate Computing Systems & Architectures.

## 3. In-Depth Lecture Notes & Conceptual Analysis
### Architectural Core: ACID Semantics, Two-Phase Locking (2PL), MVCC (Multi-Version Concurrency Control), WAL & ARIES Recovery
Graduate computing systems require understanding the trade-offs between computational overhead, network latency, and transactional correctness.
