# Module 05 Graduate Colloquium: Distributed Storage and Data Engines
**Course:** CSC-6362 | Texas Wesleyan University

### Colloquium Prompt
Critically analyze the trade-offs inherent in Distributed Hash Tables (DHT), Consistent Hashing, Google Bigtable, Spanner, and DynamoDB Architecture. Consider an enterprise operating under strict latency SLA and five-nines (99.999%) availability mandates.
1. Formulate a technical design proposal defending your chosen architectural pattern.
2. Evaluate potential edge cases and failure domains.
3. Critique the proposals of at least two peers using empirical performance arguments.
