This course operates under a **Zero Textbook Cost (ZTC)** model. No commercial textbook purchase is required. All reading materials, lab resources, and video references listed below are free and openly accessible.

## Module-by-Module Reading & Resource Map

### Module 01 — Advanced IP Routing: OSPF & EIGRP
- **IETF RFC 2328** — OSPF Version 2: https://datatracker.ietf.org/doc/html/rfc2328
- **IETF RFC 7868** — Cisco's EIGRP Informational RFC: https://datatracker.ietf.org/doc/html/rfc7868
- **Cisco IOS OSPF Configuration Guide** (free): https://www.cisco.com/c/en/us/support/index.html → search "OSPF Configuration Guide"
- **Cisco Skills for All:** "Enterprise Networking, Security, and Automation" — Module: IP Routing

### Module 02 — Campus Network Design: VLANs, STP & EtherChannel
- **IEEE 802.1Q** (VLAN Tagging) overview via Cisco docs
- **IETF RFC 7727** — Spanning Tree Protocol variants: https://datatracker.ietf.org/doc/html/rfc7727
- **Cisco Campus LAN and Wireless LAN Design Guide** (free): https://www.cisco.com/c/en/us/solutions/enterprise-networks/index.html
- **Cisco Catalyst Configuration Guide — EtherChannel** (free)

### Module 03 — WAN Technologies: MPLS, SD-WAN & VPNs
- **IETF RFC 3031** — Multiprotocol Label Switching (MPLS): https://datatracker.ietf.org/doc/html/rfc3031
- **IETF RFC 4364** — BGP/MPLS IP VPNs: https://datatracker.ietf.org/doc/html/rfc4364
- **Cisco SD-WAN Design Guide** (free): https://www.cisco.com/c/en/us/solutions/enterprise-networks/sd-wan/index.html
- **Cisco DevNet SD-WAN Learning Lab** (free): https://developer.cisco.com/learning/

### Module 04 — Enterprise Security & Infrastructure Hardening
- **IETF RFC 8446** — TLS 1.3: https://datatracker.ietf.org/doc/html/rfc8446
- **Cisco Network Security Best Practices** (free): https://www.cisco.com/c/en/us/products/security/index.html
- **CIS Benchmarks for Network Devices** (free community version): https://www.cisecurity.org/cis-benchmarks
- **NIST SP 800-77 Rev 1** — Guide to IPsec VPNs (free): https://csrc.nist.gov/

### Module 05 — QoS, High Availability & Network Automation
- **IETF RFC 2475** — DiffServ (QoS): https://datatracker.ietf.org/doc/html/rfc2475
- **IETF RFC 5798** — VRRP: https://datatracker.ietf.org/doc/html/rfc5798
- **Ansible Documentation** (free): https://docs.ansible.com/
- **Cisco DevNet — Python for Network Engineers** (free lab): https://developer.cisco.com/learning/
- **Nornir Framework** (free): https://nornir.readthedocs.io/

### Module 06 — Cloud Networking & Hybrid Architectures
- **AWS Networking Reference Architectures** (free): https://docs.aws.amazon.com/
- **Google Cloud Networking Overview** (free): https://cloud.google.com/docs/networking
- **Cisco SD-Access Design Guide** (free): https://www.cisco.com/
- **IETF RFC 8519** — YANG Data Model for Network Access Control Lists: https://datatracker.ietf.org/doc/html/rfc8519

### Module 07 — Troubleshooting, Capstone & Final
- **Cisco Network Troubleshooting Guide** (free): https://www.cisco.com/
- **Cisco Packet Tracer Student Guide** (free, via NetAcad)
- Review all prior module resources for capstone lab preparation
