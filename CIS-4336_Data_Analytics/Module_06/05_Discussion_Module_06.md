## Scenario A — A/B Test Interpretation

An e-commerce company runs an A/B test on their checkout page. Version A (current) has a conversion rate of 3.1%. Version B (new one-click checkout) has a conversion rate of 3.4%. The test ran for 30 days with 50,000 visitors per group. The p-value is 0.021.

In 175–225 words, address all three of the following:

1. State the null and alternative hypotheses for this test. At alpha = 0.05, what is the correct statistical decision? Write your decision in one complete sentence using proper hypothesis testing language — neither "accept H0" nor "accept H1."
2. The 0.3 percentage point difference is statistically significant. Is it practically significant? The company processes an average of 500,000 checkouts per month. Calculate the expected increase in monthly conversions if Version B is rolled out, and evaluate whether the practical significance justifies deploying it.
3. A product manager argues that p = 0.021 means there is only a 2.1% chance that Version A and Version B perform equally. Is this correct? Provide the precise definition of a p-value and explain why the product manager's interpretation is wrong.

## Scenario B — Correlation Misinterpretation

A city government analyst publishes a report finding a strong positive correlation (r = 0.79, p < 0.001) between the number of ice cream vendors in a neighborhood and the neighborhood's annual crime rate. The city council proposes limiting ice cream vendors in high-crime neighborhoods.

In 175–225 words, address all three of the following:

1. Evaluate the council's proposed policy using correlation vs. causation. Identify the most likely confounding variable and explain how it produces the observed correlation without any causal link between vendors and crime.
2. What evidence would be needed to establish that limiting ice cream vendors actually reduces crime? Describe the type of study design that could begin to establish causation.
3. A council member says: "r = 0.79 is very strong — that is basically proof." Explain the error in this reasoning using the definition of Pearson r and the conditions required to establish causation.

## Scenario C — Type I and Type II Error Tradeoffs

A cybersecurity company deploys an anomaly detection system to flag employee network activity as potentially malicious. The system raises an alert whenever the anomaly score exceeds the 95th percentile (alpha = 0.05). This results in 40 alerts per day, of which 38 are false alarms.

In 175–225 words, address all three of the following:

1. Classify the two types of errors this system makes. A false alarm (flagging normal activity as malicious) is which error type? A missed detection (failing to flag actual malicious activity) is which error type? Define both and identify the probability of each in this context.
2. The security team proposes tightening the threshold to the 99th percentile (alpha = 0.01) to reduce false alarms. How will this change affect the false alarm rate and the missed detection rate? Use the relationship between Type I and Type II errors to frame your answer.
3. Which error type carries a higher cost in this cybersecurity context? Defend your position in two to three sentences. Then describe one additional approach beyond changing alpha that could improve detection quality.
