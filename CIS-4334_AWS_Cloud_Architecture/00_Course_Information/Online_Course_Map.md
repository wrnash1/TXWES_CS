# Online Course Map: CIS-4334_AWS_Cloud_Architecture
**Target Certification:** AWS Certified Solutions Architect – Associate (SAA-C03)

## 16-Week Breakdown

*   **Modules 1–4: Foundations** — Global infrastructure, IAM security, EC2 compute, and S3 storage. Establishes the core building blocks of every AWS architecture.
*   **Modules 5–8: Networking and Data** — VPC design, managed relational and NoSQL databases, and serverless computing with Lambda. Covers the most heavily tested service categories on the SAA-C03 exam.
*   **Modules 9–12: Delivery, Messaging, and Automation** — Global content delivery (CloudFront, Route 53), event-driven messaging (SQS, SNS), container orchestration (ECS, EKS, Fargate), and Infrastructure as Code (CloudFormation, Elastic Beanstalk).
*   **Modules 13–15: Security, Observability, and Architecture Review** — Advanced security services (KMS, WAF, Shield, GuardDuty), monitoring and governance (CloudWatch, CloudTrail, AWS Config), and the AWS Well-Architected Framework 6-Pillar review.
*   **Module 16:** Final Exam Prep and AWS Solutions Architect – Associate (SAA-C03) Certification Exam.
