# Online Course Map: CIS-4331_Azure_Cloud

**Target Certification:** Microsoft Azure Fundamentals (AZ-900)

## 16-Week Breakdown

* **Module 01:** Cloud Concepts — IaaS, PaaS, SaaS, deployment models, shared responsibility, CAPEX vs. OPEX
* **Module 02:** Azure Physical Architecture — Regions, Region Pairs, Availability Zones, Resource Groups, ARM
* **Module 03:** Azure Compute — Virtual Machines, VM Scale Sets, Azure App Service
* **Module 04:** Azure Containers — Azure Container Instances, Azure Kubernetes Service, serverless computing
* **Module 05:** Azure Networking — VNets, subnets, NSGs, VPN Gateway, ExpressRoute, Azure Bastion
* **Module 06:** Azure Storage — Blob tiers (Hot/Cool/Cold/Archive), Azure Files, Disk Storage, replication types
* **Module 07:** Azure Database Services — Azure SQL Database, Azure Cosmos DB, Azure Database for MySQL/PostgreSQL
* **Module 08:** Microsoft Entra ID Basics — Tenant structure, users, groups, hybrid identity, Entra Connect
* **Module 09:** Entra Authentication and MFA — Multi-Factor Authentication, Conditional Access, Single Sign-On
* **Module 10:** Azure RBAC and Subscriptions — Role-Based Access Control, scope hierarchy, built-in roles
* **Module 11:** Azure Security Tools — Microsoft Defender for Cloud, Azure Key Vault, Microsoft Sentinel
* **Module 12:** Azure Governance and Compliance — Azure Policy, Azure Blueprints, resource locks, tags
* **Module 13:** Azure Monitoring and Diagnostics — Azure Monitor, Log Analytics, Azure Advisor, Service Health
* **Module 14:** Azure Cost Management — Pricing Calculator, TCO Calculator, budgets, Reservations
* **Module 15:** Azure Resource Manager and CLI — ARM templates, Azure CLI, Azure Cloud Shell, PowerShell
* **Module 16:** Final Exam Prep and AZ-900 Certification — Full domain review, practice assessment, exam registration
