## Question 1

An organization is implementing a new incident management practice. Before designing any new workflows, the IT director asks the team to spend two weeks documenting how incidents are currently handled, what tools are currently used, and what is working well. Which Guiding Principle is the IT director applying?

* A) Focus on Value
* B) Start Where You Are
* C) Collaborate and Promote Visibility
* D) Think and Work Holistically

Correct answer: B

Distractor analysis: B is correct because assessing the current state before building or redesigning is the core of Start Where You Are — the principle directs organizations not to discard existing capability without first understanding what they have. A is incorrect because Focus on Value is about connecting actions to stakeholder outcomes, not specifically about assessing the current state. C is incorrect because Collaborate and Promote Visibility is about involving stakeholders and sharing information, not about baselining current practices. D is incorrect because Think and Work Holistically is about considering system-wide impacts, not specifically about pre-assessment.

## Question 2

A software company decides to automate its employee onboarding request process. However, the process currently has 35 steps, many of which are redundant. The ITSM consultant advises: "Before you automate this, you need to simplify it first." Which Guiding Principle does this advice reflect?

* A) Keep It Simple and Practical
* B) Optimize and Automate
* C) Progress Iteratively with Feedback
* D) Start Where You Are

Correct answer: B

Distractor analysis: B is correct because Optimize and Automate explicitly directs organizations to optimize processes before automating them — automating a broken process just produces faster failures. A is incorrect because Keep It Simple and Practical applies to the simplification step specifically, but the consultant's advice is about the correct sequence: optimize first, then automate — which is the Optimize and Automate principle. C is incorrect because Progress Iteratively with Feedback is about incremental delivery, not about the sequence of optimization and automation. D is incorrect because Start Where You Are is about baseline assessment before building new, not about automation sequencing.

## Question 3

An IT team is rolling out a new configuration management database. After three months of isolated work, they reveal the finished design to the operations team and the service desk. Both teams immediately identify that the data model does not match how they categorize services, requiring significant rework. Which Guiding Principle was most neglected?

* A) Start Where You Are
* B) Think and Work Holistically
* C) Collaborate and Promote Visibility
* D) Keep It Simple and Practical

Correct answer: C

Distractor analysis: C is correct because the team worked in isolation for three months without involving the operations team and service desk, failing to collaborate or make their work visible — both core elements of Collaborate and Promote Visibility. A is incorrect because the scenario does not indicate the team failed to assess the current state; the failure was in not involving stakeholders during design. B is incorrect because while holistic thinking is related, the specific failure mode — three months of isolated design without stakeholder involvement — most precisely describes a Collaborate and Promote Visibility violation. D is incorrect because the issue is not about complexity; it is about involving the right people.

## Question 4

An organization's IT service desk receives 200 calls per day. Analysis shows that 65% of those calls are password resets that follow an identical, fully predictable resolution path. The service desk manager proposes implementing a self-service password reset tool to handle these calls automatically. Which Guiding Principle most directly supports this proposal?

* A) Focus on Value
* B) Keep It Simple and Practical
* C) Optimize and Automate
* D) Progress Iteratively with Feedback

Correct answer: C

Distractor analysis: C is correct because automating repetitive, predictable, rule-based tasks like password resets is precisely what Optimize and Automate recommends — freeing human attention for work that requires judgment. A is incorrect because while Focus on Value is relevant (the proposal does contribute to value), it is not the principle most specifically describing the automation rationale. B is incorrect because Keep It Simple and Practical is about reducing unnecessary complexity, not specifically about automation. D is incorrect because Progress Iteratively with Feedback describes how to implement the change, not whether to implement it.

## Question 5

A hospital IT department is redesigning its change enablement process. The project lead decides to include the development team, the operations team, the security team, the service desk manager, and two clinical end-users in the redesign workshops. Which Guiding Principle is being applied?

* A) Think and Work Holistically
* B) Collaborate and Promote Visibility
* C) Progress Iteratively with Feedback
* D) Focus on Value

Correct answer: B

Distractor analysis: B is correct because involving multiple stakeholders from across the organization in a design process is a direct application of Collaborate and Promote Visibility — inclusion is generally better than exclusion, and decisions made with appropriate involvement produce better results. A is incorrect because Think and Work Holistically is about considering system-wide impacts, not specifically about who to include in meetings. C is incorrect because Progress Iteratively with Feedback is about incremental delivery and feedback loops, not about stakeholder inclusion in design workshops. D is incorrect because Focus on Value is about connecting actions to stakeholder outcomes, not about participation decisions.

## Question 6

A company discovers it produces 14 different monthly IT performance reports. Upon investigation, the IT director finds that 9 of the 14 reports are never acted upon and that 3 of them contain data so outdated by publication time that they are misleading. She decides to discontinue the 9 unused reports and redesign the 3 misleading ones. Which Guiding Principle is most directly being applied?

* A) Optimize and Automate
* B) Collaborate and Promote Visibility
* C) Start Where You Are
* D) Keep It Simple and Practical

Correct answer: D

Distractor analysis: D is correct because eliminating activities that do not provide value or produce useful outcomes is the core of Keep It Simple and Practical — the principle explicitly directs organizations to remove complexity that does not contribute to outcomes. A is incorrect because Optimize and Automate is specifically about automation of tasks, not about eliminating unnecessary reporting. B is incorrect because this scenario is not about stakeholder involvement or information sharing. C is incorrect because Start Where You Are is about assessment before change; the director has already assessed the situation and is now acting on it.

## Question 7

Which statement most accurately describes the relationship between the Guiding Principles and ITIL 4 practices?

* A) The Guiding Principles replace practices for organizations that are too small to implement formal practices.
* B) The Guiding Principles are applied when implementing and operating practices, informing how decisions are made at every step.
* C) The Guiding Principles only apply during the initial implementation of practices, not during ongoing operation.
* D) The Guiding Principles are subordinate to practices — when a practice prescribes a specific action, the relevant Guiding Principle is suspended.

Correct answer: B

Distractor analysis: B is correct because the Guiding Principles are universal — they apply at every step of implementing and operating every practice. Every decision made within a practice context should be informed by the applicable Guiding Principles. A is incorrect because the Guiding Principles are not a lightweight alternative to practices; they are a separate, complementary layer that applies regardless of organization size. C is incorrect because the Guiding Principles apply continuously, not only during initial implementation. D is incorrect because the Guiding Principles are not subordinate to practices; practices are designed to be consistent with the Guiding Principles, not the other way around.

## Question 8

An IT team is implementing a new service catalog. The catalog currently has 142 service entries, many of which overlap, are outdated, or are described in technical jargon that users cannot understand. Rather than cleaning up the existing catalog, the team lead proposes starting with a fresh catalog of 15 clearly described services that cover 80% of user demand. Which two Guiding Principles are most directly reflected in this proposal?

* A) Think and Work Holistically and Collaborate and Promote Visibility
* B) Keep It Simple and Practical and Focus on Value
* C) Start Where You Are and Progress Iteratively with Feedback
* D) Optimize and Automate and Start Where You Are

Correct answer: B

Distractor analysis: B is correct because building a focused catalog of 15 clearly described services reflects Keep It Simple and Practical (reducing complexity to what is needed) and Focus on Value (the 15 services cover 80% of user demand — they are the highest-value entries). A is incorrect because neither holistic thinking nor collaboration are the primary drivers of the proposal. C is incorrect because the proposal explicitly does not build on the existing catalog, which would violate Start Where You Are; the proposal is about simplifying, not incrementally iterating. D is incorrect because the proposal is not about automation, and it is not building on the existing catalog.

## Question 9

An organization is rolling out ITIL 4 practices to its entire global IT workforce of 4,500 people across 12 countries. A consultant recommends starting with a 90-day pilot in one region of 400 employees, then reviewing results before deciding how to proceed. Which Guiding Principle does this recommendation reflect?

* A) Focus on Value
* B) Start Where You Are
* C) Progress Iteratively with Feedback
* D) Think and Work Holistically

Correct answer: C

Distractor analysis: C is correct because running a pilot in a limited scope, reviewing results, and using that feedback to inform the broader rollout is Progress Iteratively with Feedback — organizing work into manageable iterations with review checkpoints before full commitment. A is incorrect because Focus on Value is about aligning work to stakeholder outcomes, not about phased delivery approach. B is incorrect because Start Where You Are is about assessing current capabilities before redesigning, not about how to structure a global rollout. D is incorrect because Think and Work Holistically is about considering system-wide impacts, not about the sequencing of a deployment.

## Question 10

An IT department is investigating why its change management process takes an average of 22 days to approve standard changes. The investigation reveals that the process requires sequential approval from six managers, each of whom has an average 3.5-day queue before reviewing submissions. The IT director proposes redesigning the workflow so that three approvals happen in parallel, reducing the critical path from 22 days to 11. Which Guiding Principle most directly supports this redesign?

* A) Think and Work Holistically
* B) Start Where You Are
* C) Optimize and Automate
* D) Keep It Simple and Practical

Correct answer: D

Distractor analysis: D is correct because redesigning a workflow to eliminate unnecessary sequential steps that do not add value is Keep It Simple and Practical — the principle specifically directs organizations to use the minimum number of steps necessary to accomplish an objective. A is incorrect because Think and Work Holistically is about considering downstream impacts of changes across the system, not specifically about simplifying approval workflows. B is incorrect because the investigation described is consistent with Start Where You Are (assessing current state), but the redesign action itself reflects Keep It Simple and Practical. C is incorrect because the proposal is to redesign the workflow for parallel approvals, not to automate it; Optimize and Automate would apply to a subsequent automation step.
