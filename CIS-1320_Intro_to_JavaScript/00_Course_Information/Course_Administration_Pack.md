# Course Administration Pack: CIS-1320 Intro to JavaScript
**Target Certification:** JSE (Certified Associate in JavaScript Programming)

---

## Course Description
CIS-1320 Intro to JavaScript introduces students to client-side web programming using the JavaScript language, covering core syntax, data structures, DOM manipulation, event handling, and asynchronous programming patterns. Students will develop practical skills through hands-on labs and complete the course prepared to sit the OpenEDG JSE (Certified Associate in JavaScript Programming) certification exam.

---

## Required Materials
1. **Zero Textbook Cost (ZTC):** All required reading materials are provided free in Canvas. No textbook purchase required.
   - Primary text: [Eloquent JavaScript (3rd Edition)](https://eloquentjavascript.net/) — free online book by Marijn Haverbeke
   - Supplementary reference: [MDN Web Docs – JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript) — free, authoritative language reference
2. A computer with a modern web browser (Chrome or Firefox recommended) with Developer Tools (F12)
3. [Visual Studio Code](https://code.visualstudio.com/) (free) — recommended code editor; download and install before Week 1
4. A free account at [javascript.info](https://javascript.info/) is recommended for supplemental exercises

## Course Policies

### Late Work
Lab assignments submitted after the due date will be penalized 10% per day, up to a maximum of 50%. Quizzes are time-limited and may not be submitted late. Contact the instructor before the deadline if extenuating circumstances arise.

### Academic Integrity
All code submitted must be your own work. Using AI code generators, copying from classmates, or submitting solutions found online without attribution is a violation of the Texas Wesleyan University Honor Code and will result in a zero for the assignment and possible course failure.

### Accessibility
Students requiring academic accommodations should contact the Office of Disability Services and provide documentation to the instructor within the first week of class.

## Certification Information
**Exam:** JSE – Certified Associate in JavaScript Programming
**Exam Body:** OpenEDG (Python Institute)
**Exam Format:** Online, proctored; approximately 45 single- and multiple-choice questions; 65-minute time limit
**Passing Score:** 70%
**Registration:** Students register independently at [edube.org](https://edube.org/). The instructor will provide a discount voucher code before Week 14.
**Recommended Prep:** Complete all 16 module quizzes, re-read weak areas in Eloquent JavaScript, and attempt the official OpenEDG practice test at least once before the exam date.
