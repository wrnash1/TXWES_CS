# Online Course Map: CIS-1320 Intro to JavaScript
**Target Certification:** JSE (Certified Associate in JavaScript Programming)
**Delivery:** Fully Online — Asynchronous
**Credit Hours:** 3
**Total Modules:** 16 (one per week)

---

## 16-Week Breakdown

### Unit 1 — JavaScript Foundations (Weeks 1–4)
* **Module 1:** JavaScript Introduction & Execution — How JS runs in the browser, the `<script>` tag, the JS engine, `console.log`, and execution contexts
* **Module 2:** Variables, Constants, and Scope — `var`, `let`, `const`, block scope, hoisting, and global variables
* **Module 3:** Data Types & Operators — Primitive types, type coercion, strict equality (`===`), `typeof`, and null vs undefined
* **Module 4:** Control Flow & Conditionals — `if/else`, `switch`, ternary operator, logical operators, and truthy/falsy values

### Unit 2 — Functions and Iteration (Weeks 5–8)
* **Module 5:** Loops & Iteration — `for`, `while`, `do-while`, `break`, `continue`, and avoiding infinite loops
* **Module 6:** Functions & Arrow Functions — Function declarations, function expressions, arrow functions, parameters, return values, and default arguments
* **Module 7:** Objects & Properties — Object literals, dot and bracket notation, methods, `this` keyword, and key-value pairs
* **Module 8:** Midterm Prep & Arrays — Array literals, indexing, `push`/`pop`/`shift`/`unshift`, `array.length`, and midterm review of Units 1–2

### Unit 3 — Advanced Array Techniques and the DOM (Weeks 9–12)
* **Module 9:** Array Iteration & Callback Functions — `forEach`, `map`, `filter`, `reduce`, and the callback execution pattern
* **Module 10:** Document Object Model (DOM) Basics — The DOM tree, the `document` object, `querySelector`, `querySelectorAll`, `getElementById`, and `textContent`
* **Module 11:** DOM Manipulation & Styling — `createElement`, `appendChild`, `classList`, `setAttribute`, inline styles, and DOM hierarchy
* **Module 12:** Event Handling & Listeners — `addEventListener`, click events, the event object, `event.target`, `preventDefault`, and event bubbling

### Unit 4 — Asynchronous JavaScript and Error Handling (Weeks 13–16)
* **Module 13:** Asynchronous JavaScript — Synchronous vs asynchronous execution, the callback queue, the event loop, `setTimeout`, and `setInterval`
* **Module 14:** Promises & Async/Await — Promise states, `resolve`/`reject`, `.then`/`.catch` chaining, `async` functions, `await`, and the Fetch API
* **Module 15:** Error Handling & Debugging — `try/catch/finally`, `throw`, stack traces, breakpoints, and browser developer tools
* **Module 16:** Final Exam Prep & JSE Certification Review — Comprehensive review of all 16 modules, JSE exam strategy, and the final certification exam

## Weekly Structure
Each module follows the same Canvas structure:
1. **Video Script / Lecture Notes** — Concept overview (read or watch)
2. **Reading Guide** — Glossary, certification tips, and required OER readings
3. **Lab** — Hands-on coding activity (submitted via Canvas)
4. **Quiz** — 5 questions covering the week's topic (timed, auto-graded)
5. **Discussion** — Reflection or peer review prompt

## How to Succeed in This Course
1. **Complete the reading before the lab.** Labs require applying concepts covered in the reading guide; skipping readings significantly increases lab difficulty.
2. **Use the browser console daily.** Open DevTools (F12) and type short JavaScript experiments to test your understanding of each concept.
3. **Review quiz feedback immediately.** Canvas provides correct answer explanations after submission; use them to identify gaps before the next module builds on them.
4. **Start the JSE exam registration by Week 12.** Allow time to receive your voucher and schedule your exam slot before the course ends.
