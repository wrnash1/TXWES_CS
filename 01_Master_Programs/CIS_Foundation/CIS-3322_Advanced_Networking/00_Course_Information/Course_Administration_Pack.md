# Course Administration Pack: CIS-3322_Advanced_Networking
**Target Certification:** Cisco CCNA (200-301)

## Course Description
This course covers advanced routing, switching, wireless, network security, and automation concepts aligned directly with the Cisco CCNA 200-301 exam blueprint. Topics span the full CCNA domain framework: Network Fundamentals, Network Access (VLANs/STP/EtherChannel), IP Connectivity (OSPF, static routing, IPv6), IP Services (NAT/PAT, DHCP, DNS, QoS), Security Fundamentals (ACLs, port security, VPNs), and Automation & Programmability (SDN, REST APIs, Python basics). Students who complete this course will be prepared to sit the Cisco CCNA 200-301 exam at a Pearson VUE testing center.

## CCNA 200-301 Exam Domain Weightings
Students and instructors should align study efforts with the official exam domains:
- **Network Fundamentals:** 20%
- **Network Access:** 20%
- **IP Connectivity:** 25% *(highest weight — prioritize OSPF, routing, IPv6)*
- **IP Services:** 10%
- **Security Fundamentals:** 15%
- **Automation and Programmability:** 10%
