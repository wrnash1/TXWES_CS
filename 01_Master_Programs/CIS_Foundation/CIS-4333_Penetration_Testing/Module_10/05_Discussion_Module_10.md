# Discussion Forum: Module 10 — Web Application Exploit Methods

## Course: CIS-4333 Penetration Testing

**Certification Alignment:** CompTIA PenTest+ (PT0-002)

---

## Discussion Prompt

The OWASP Top 10 is updated periodically to reflect the most critical web application security risks based on real-world data from hundreds of organizations. The 2021 edition moved "Broken Access Control" to the number one position — up from fifth in the 2017 edition. SQL injection, once ranked first, moved to third place under the broader "Injection" category.

For this discussion, you will connect a real-world data breach or security incident to the OWASP Top 10 categories covered in this module.

### Initial Post (Due Wednesday at 11:59 PM)

In 200–250 words, address the following:

1. Select a publicly disclosed web application breach or vulnerability disclosure from the past five years. Examples include the 2021 Log4Shell vulnerability, the 2019 Capital One breach, the 2017 Equifax breach, or any CVE-assigned web application vulnerability you find in the NVD database.

2. Identify which OWASP Top 10 category (or categories) the incident maps to. Explain the technical connection — how does the root cause of the breach align with the OWASP category definition?

3. Explain what a penetration tester using the techniques from this module — Burp Suite, SQLMap, or manual injection testing — would have found during a pre-breach assessment. Which specific test or payload would have detected the vulnerability?

4. Recommend one remediation control that, if implemented before the breach, would have prevented or significantly limited the attacker's access.

Use technical terminology from the module. Cite any news articles, CVE entries, or OWASP documentation you reference.

### Peer Responses (Due Sunday at 11:59 PM)

Write a substantive reply (at least 75 words) to at least two classmates. In each reply, address one of the following:

- Add technical detail about the attack technique your classmate described. For example, if they described SQL injection, explain whether the attack was likely union-based, blind, or error-based based on the breach details.
- Evaluate the remediation your classmate recommended. Is it a root-cause fix or a compensating control? Suggest an additional layer of defense.
- Connect the breach your classmate discussed to a different OWASP Top 10 category that also applies, explaining the secondary vulnerability angle.

## Discussion Rubric (10 Points Total)

### Initial Post (6 Points)

- 5–6 pts: Clearly identifies a real breach, correctly maps it to an OWASP category with technical reasoning, explains which pentesting technique would have detected it, and provides a technically sound remediation. Meets word count. Uses module terminology accurately.
- 3–4 pts: Identifies a breach and an OWASP category but the technical connection is superficial. The pentesting detection or remediation is vague or generic.
- 0–2 pts: Post is incomplete, does not reference a real breach, or demonstrates minimal engagement with module content.

### Peer Responses (4 Points)

- 4 pts: Responds to two peers with substantive technical additions. Engages with the specific breach and vulnerability details the peer described.
- 2 pts: Responds to only one peer, or both responses are generic (e.g., "Great post! I agree with your remediation.") without technical content.
- 0 pts: No peer responses submitted by the deadline.
