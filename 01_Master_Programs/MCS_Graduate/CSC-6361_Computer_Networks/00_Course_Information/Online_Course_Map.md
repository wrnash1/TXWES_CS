## Canvas Module Structure Overview

Each of the 7 modules follows this standard structure in Canvas:

```
Module XX — [Topic Title]
  ├── 📺  Video Script Part 1 (Canvas Page — read/present as lecture)
  ├── 📺  Video Script Part 2 (Canvas Page — read/present as lecture)
  ├── 📖  Reading Guide (Canvas Page — links to OER/RFC resources)
  ├── 🧪  Lab Assignment (Canvas Assignment — .pkt file + PDF report)
  ├── 📝  Quiz (Canvas Quiz — 10 questions, 30-min limit)
  └── 💬  Discussion Board (Canvas Discussion — graded)
```
*Module 06 adds:* `📄 Research Paper (Canvas Assignment — PDF upload)`
*Module 07 replaces Lab + Quiz + Discussion with:* `🏆 Capstone Lab + Written Exam (Canvas Quiz + Assignment)`
