# 7-Week Accelerated Module Instructional Blueprint
**Texas Wesleyan University — Computing Curriculum Standard**  

## Module Architecture Overview (4-Part Standard)
Every weekly module across undergraduate foundations, MCS, and DIT programs follows a uniform, 4-part structure:



---

### Part 1: Reading Guide & Lecture Notes ()
- **Estimated Student Time:** 3–4 Hours
- **Content:** Modular learning objectives, reading list with permanent URLs/DOIs, deep technical exposition, architectural diagrams, and real-world implementation case examples.
- **QM Standard:** 2.1, 4.1, 4.2.

### Part 2: Scholarly Colloquium ()
- **Estimated Student Time:** 2–3 Hours
- **Schedule:** Initial post due Thursday (11:59 PM CT); two substantive peer critiques due Sunday (11:59 PM CT).
- **RSI Criteria:** Instructor participates dynamically in the discussion thread, posing challenge questions and guiding critical debate.
- **QM Standard:** 5.1, 5.2, 5.3.

### Part 3: Applied Laboratory / Executive Deliverable ()
- **Estimated Student Time:** 4–5 Hours
- **Format:** Step-by-step configuration, virtual lab topology (Packet Tracer / AWS / Linux Sandbox), or executive scenario decision-making document.
- **Submission:** Configuration scripts, packet capture captures, network topologies (), or technical white papers.
- **QM Standard:** 3.1, 3.2, 6.1.

### Part 4: Synthesis Assessment / Module Exam ()
- **Estimated Student Time:** 2 Hours
- **Format:** Multi-concept essay question, empirical validation report, or scenario-based comprehensive quiz with detailed pedagogical remediation feedback.
- **QM Standard:** 3.3, 3.4.
